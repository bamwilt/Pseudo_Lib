# Pseudo Lib: Objects, Graphics & Libraries

![Banner de Pseudo Lib](media/PseudoLib_banner_.png)

**Demo / Work in Progress**  
Esta es una demo de mi toolkit para **PSeInt**, con más de **2800 líneas de funciones**, diseñado para sacar el máximo provecho de PSeInt.  

![demoSpiral](media/Spiral.jpeg)

---

## Módulos Principales

1. **INPUT** – Funciones avanzadas de entrada de datos  
2. **STRING** – Manipulación y transformación de cadenas  
3. **ARRAY** – Operaciones complejas con arreglos  
4. **PRINTERS** – Salida de texto y gráficos  
5. **INT** – Funciones de enteros  
6. **MATH** – Operaciones y fórmulas matemáticas  
7. **BOOLEAN** – Utilidades para lógica booleana  
8. **CONDITIONS** – Manejo de condicionales  
9. **DEFINITIONS** – Definición y uso de constantes  
10. **COLOR** – Control de colores en consola  
11. **LOCAL DATE TIME** – Manejo de fecha y hora local  
12. **UTIL** – Estructuras complejas
13. **TUI / CANVAS** – Interfaz de texto y gráficos básicos  
14. **VEC** – Vectores y operaciones geométricas  
15. **OBJECT** – Manejo de objetos 

> También incluye módulos más pequeños: `binaryString`, `ascii`, `sleep`, `test`, entre otros.
