# object_Property_GetIndex

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Obtiene el índice de una propiedad dentro del objeto, buscando en el área de propiedades.

## Sintaxis
```
Funcion index_property <- object_Property_GetIndex(struct_Object, property_name)
```

## Parámetros
- `struct_Object`: Objeto
- `property_name`: Nombre de la propiedad

## Retorna
Índice de la propiedad, o -1 si no existe.
