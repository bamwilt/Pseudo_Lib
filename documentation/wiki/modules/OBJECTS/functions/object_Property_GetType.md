# object_Property_GetType

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Obtiene el tipo de dato de una propiedad, con soporte para propiedades anidadas.

## Sintaxis
```
Funcion property_TYPE <- object_Property_GetType(struct_Object, property_name)
```

## Parámetros
- `struct_Object`: Objeto
- `property_name`: Nombre de la propiedad

## Retorna
Tipo de la propiedad.
