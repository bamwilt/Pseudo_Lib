# object_Delete_CommonPropertiesFrom

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Elimina del objeto las propiedades que son comunes con otro objeto.

## Sintaxis
```
Funcion object_depure <- object_Delete_CommonPropertiesFrom(object_Original, object_Compartor)
```

## Parámetros
- `object_Original`: Objeto a depurar
- `object_Compartor`: Objeto de comparación

## Retorna
El objeto sin las propiedades comunes.
