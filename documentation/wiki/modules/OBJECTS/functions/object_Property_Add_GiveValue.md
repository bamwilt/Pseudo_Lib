# object_Property_Add_GiveValue

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Agrega una nueva propiedad con un valor inicial. Si la propiedad ya existe, no la agrega y registra un error.

## Sintaxis
```
Funcion object_result <- object_Property_Add_GiveValue(struct_Object, property_name, value, TYPE)
```

## Parámetros
- `struct_Object`: Objeto
- `property_name`: Nombre de la propiedad
- `value`: Valor inicial
- `TYPE`: Tipo de dato

## Retorna
El objeto con la nueva propiedad.
