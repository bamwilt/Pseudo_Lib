# object_Property_Delete

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Elimina una propiedad del objeto.

## Sintaxis
```
Funcion object_Result <- object_Property_Delete(struct_Object, property_name)
```

## Parámetros
- `struct_Object`: Objeto
- `property_name`: Nombre de la propiedad a eliminar

## Retorna
El objeto sin la propiedad.
