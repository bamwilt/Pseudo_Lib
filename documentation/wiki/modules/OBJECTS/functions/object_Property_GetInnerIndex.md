# object_Property_GetInnerIndex

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Obtiene el índice interno (posición en el almacenamiento lineal) de una propiedad.

## Sintaxis
```
Funcion property_InnerIndex <- object_Property_GetInnerIndex(struct_Object, property_name)
```

## Parámetros
- `struct_Object`: Objeto
- `property_name`: Nombre de la propiedad

## Retorna
Índice interno de la propiedad.
