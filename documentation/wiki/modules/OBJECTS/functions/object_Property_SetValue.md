# object_Property_SetValue

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Establece el valor de una propiedad existente.

## Sintaxis
```
Funcion object_Result <- object_Property_SetValue(struct_Object, property_name, property_Value)
```

## Parámetros
- `struct_Object`: Objeto
- `property_name`: Nombre de la propiedad
- `property_Value`: Nuevo valor

## Retorna
El objeto con la propiedad modificada.
