# object_Property_Exist

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Verifica si una propiedad existe en el objeto.

## Sintaxis
```
Funcion property_exists <- object_Property_Exist(struct_Object, property_name)
```

## Parámetros
- `struct_Object`: Objeto
- `property_name`: Nombre de la propiedad

## Retorna
`Verdadero` si la propiedad existe.
