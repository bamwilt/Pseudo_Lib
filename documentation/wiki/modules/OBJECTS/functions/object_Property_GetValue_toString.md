# object_Property_GetValue_toString

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Obtiene el valor de una propiedad como string, con soporte para propiedades anidadas.

## Sintaxis
```
Funcion property_Value <- object_Property_GetValue_toString(struct_Object, property_name)
```

## Parámetros
- `struct_Object`: Objeto
- `property_name`: Nombre de la propiedad

## Retorna
String del valor de la propiedad.
