# object_getAreaProperty

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Obtiene el área de propiedades del objeto, que contiene la definición de todas las propiedades (nombre y tipo).

## Sintaxis
```
Funcion area_Property <- object_getAreaProperty(struct_Object)
```

## Parámetros
- `struct_Object`: Objeto

## Retorna
String con el área de propiedades.
