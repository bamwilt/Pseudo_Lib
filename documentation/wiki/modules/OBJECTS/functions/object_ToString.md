# object_ToString

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Convierte un objeto a string, validando que sea del tipo especificado. Si no es válido, retorna un objeto vacío y registra un error.

## Sintaxis
```
Funcion result_string <- object_ToString(object_str, TYPE)
```

## Parámetros
- `object_str`: Objeto a convertir
- `TYPE`: Tipo esperado

## Retorna
String del objeto, o un objeto vacío si el tipo no coincide.
