# object_Property_SetValue_ToSeparator

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Establece el valor de una propiedad usando un separador personalizado (wrapper).

## Sintaxis
```
Funcion object_Result <- object_Property_SetValue_ToSeparator(struct_Object, property_name, property_value, separator)
```

## Parámetros
- `struct_Object`: Objeto
- `property_name`: Nombre de la propiedad
- `property_value`: Nuevo valor
- `separator`: Separador para rutas de propiedades

## Retorna
El objeto con la propiedad modificada.
