# object_isType

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Verifica si un objeto es de un tipo específico, validando que sea un objeto válido y que su nombre coincida.

## Sintaxis
```
Funcion object_IsEquals <- object_isType(object_Select, name)
```

## Parámetros
- `object_Select`: Objeto a verificar
- `name`: Nombre del tipo esperado

## Retorna
`Verdadero` si el objeto es del tipo especificado.
