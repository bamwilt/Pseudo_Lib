# object_InheritsFrom

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Agrega a un objeto las propiedades de otro que no posea (herencia de propiedades).

## Sintaxis
```
Funcion object_result <- object_InheritsFrom(object_Original, object_Hereditary)
```

## Parámetros
- `object_Original`: Objeto base
- `object_Hereditary`: Objeto del cual heredar propiedades

## Retorna
El objeto con las propiedades heredadas.
