# object_Property_Add

**Módulo:** [OBJECTS](../OBJECTS.md)

## Descripción
Agrega una nueva propiedad a un objeto con un valor nulo por defecto según su tipo.

## Sintaxis
```
Funcion object_result <- object_Property_Add(struct_Object, property_name, TYPE)
```

## Parámetros
- `struct_Object`: Objeto
- `property_name`: Nombre de la propiedad
- `TYPE`: Tipo de dato de la propiedad

## Retorna
El objeto con la nueva propiedad.
