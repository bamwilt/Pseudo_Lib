# OBJECTS

**Código:** #OBJ
**Prefijo:** `object_`
**Estado:** [+] Stable

## Descripción
Módulo que implementa un sistema de objetos con propiedades tipadas. Permite crear objetos, agregar/obtener/modificar/eliminar propiedades, herencia entre objetos y operaciones de comparación de propiedades comunes.
