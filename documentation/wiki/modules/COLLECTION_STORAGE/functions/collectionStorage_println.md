# collectionStorage_println

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Imprime el contenido del almacenamiento en la consola, añadiendo un salto de línea después de cada elemento.

## Sintaxis
```
collectionStorage_println(struct_storage)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento

## Retorna
Nada. Imprime en consola.
