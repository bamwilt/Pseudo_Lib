# collectionStorage_new

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Crea un nuevo setter de almacenamiento para colecciones, inicializando las áreas de tipo, longitud, datos y metadatos con el tipo de estructura especificado.

## Sintaxis
```
new_Setter <- collectionStorage_new(type_Struct, TYPE)
```

## Parámetros
- `type_Struct`: Texto con el nombre de la estructura
- `TYPE`: Texto con el tipo de datos a almacenar (int, float, boolean, string)

## Retorna
Texto con la estructura de almacenamiento inicializada.
