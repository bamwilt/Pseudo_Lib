# collectionStorage_GetKeys_ToString

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Obtiene todas las claves del almacenamiento como un string separado por comas.

## Sintaxis
```
result_storage <- collectionStorage_GetKeys_ToString(struct_storage)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento

## Retorna
Texto con las claves separadas por comas.
