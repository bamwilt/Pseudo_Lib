# collectionStorage_getSize

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Obtiene la cantidad de elementos almacenados en la estructura.

## Sintaxis
```
num_Keys <- collectionStorage_getSize(struct_storage)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento

## Retorna
Número con la cantidad de elementos.
