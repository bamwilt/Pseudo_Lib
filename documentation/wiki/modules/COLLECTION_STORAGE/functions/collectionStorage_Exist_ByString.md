# collectionStorage_Exist_ByString

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Verifica si una clave string existe dentro del almacenamiento.

## Sintaxis
```
result_storage <- collectionStorage_Exist_ByString(struct_storage, key)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento
- `key`: Texto con la clave a verificar

## Retorna
Lógico: verdadero si la clave existe, falso en caso contrario.
