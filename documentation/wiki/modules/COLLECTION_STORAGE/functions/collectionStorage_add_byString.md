# collectionStorage_add_byString

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Añade un valor string al almacenamiento calculando automáticamente las posiciones de inserción e incrementando el contador de elementos.

## Sintaxis
```
result_storage <- collectionStorage_add_byString(struct_storage, value_string)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento
- `value_string`: Texto con el valor a añadir

## Retorna
Texto con la estructura modificada.
