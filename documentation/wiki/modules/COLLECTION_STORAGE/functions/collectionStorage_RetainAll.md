# collectionStorage_RetainAll

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Retiene únicamente los elementos que existen en la colección especificada, eliminando todos los demás.

## Sintaxis
```
result_storage <- collectionStorage_RetainAll(struct_storage, struct_storage_Match)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento
- `struct_storage_Match`: Texto con la colección de elementos a retener

## Retorna
Texto con la estructura filtrada.
