# collectionStorage_GetKeys_ToSeparatedString

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Obtiene todas las claves del almacenamiento como un string separado por el delimitador especificado.

## Sintaxis
```
result_storage <- collectionStorage_GetKeys_ToSeparatedString(struct_storage, separator)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento
- `separator`: Texto con el separador a usar entre claves

## Retorna
Texto con las claves concatenadas y separadas.
