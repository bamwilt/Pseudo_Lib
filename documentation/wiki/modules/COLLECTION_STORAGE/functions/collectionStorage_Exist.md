# collectionStorage_Exist

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Verifica si una clave existe dentro del almacenamiento.

## Sintaxis
```
result_storage <- collectionStorage_Exist(struct_storage, key)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento
- `key`: Clave a verificar

## Retorna
Lógico: verdadero si la clave existe, falso en caso contrario.
