# collectionStorage_print

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Imprime el contenido del almacenamiento en la consola sin saltos de línea entre elementos.

## Sintaxis
```
collectionStorage_print(struct_storage)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento

## Retorna
Nada. Imprime en consola.
