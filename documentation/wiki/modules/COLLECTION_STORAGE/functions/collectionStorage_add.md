# collectionStorage_add

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Añade un valor al almacenamiento detectando automáticamente el tipo de datos desde la estructura.

## Sintaxis
```
result_storage <- collectionStorage_add(struct_storage, value)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento
- `value`: Valor a añadir (tipo inferido de la estructura)

## Retorna
Texto con la estructura modificada.
