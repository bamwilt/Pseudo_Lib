# collectionStorage_getType

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Extrae el tipo de datos almacenado en la estructura desde el área de tipo.

## Sintaxis
```
Type_keys <- collectionStorage_getType(struct_storage)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento

## Retorna
Texto con el tipo de datos (int, float, boolean, string).
