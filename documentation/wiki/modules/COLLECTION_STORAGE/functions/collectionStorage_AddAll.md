# collectionStorage_AddAll

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Añade todos los elementos de otra colección al almacenamiento actual.

## Sintaxis
```
result_storage <- collectionStorage_AddAll(struct_storage, struct_storage_Match)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento destino
- `struct_storage_Match`: Texto con la colección de elementos a añadir

## Retorna
Texto con la estructura combinada.
