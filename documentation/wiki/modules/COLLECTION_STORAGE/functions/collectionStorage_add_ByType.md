# collectionStorage_add_ByType

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Convierte un valor al tipo especificado a string y lo añade al almacenamiento.

## Sintaxis
```
result_storage <- collectionStorage_add_ByType(struct_storage, value, TYPE)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento
- `value`: Valor del tipo especificado a añadir
- `TYPE`: Texto con el tipo del valor (int, float, boolean, string)

## Retorna
Texto con la estructura modificada.
