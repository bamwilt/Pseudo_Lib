# collectionStorage_modify

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Modifica un elemento en el almacenamiento en la posición especificada, detectando automáticamente el tipo.

## Sintaxis
```
result_storage <- collectionStorage_modify(struct_storage, value, index_modify)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento
- `value`: Nuevo valor a asignar
- `index_modify`: Número con el índice interno a modificar

## Retorna
Texto con la estructura modificada.
