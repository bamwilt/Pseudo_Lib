# __private_collectionStorage_printer

**Módulo:** [COLLECTION_STORAGE](../COLLECTION_STORAGE.md)

## Descripción
Función interna que imprime los datos secuenciales del almacenamiento elemento por elemento, con opción de salto de línea.

## Sintaxis
```
__private_collectionStorage_printer(struct_storage, isnewLine)
```

## Parámetros
- `struct_storage`: Texto con la estructura de almacenamiento
- `isnewLine`: Lógico que indica si se imprime con salto de línea

## Retorna
Nada. Imprime en consola.
