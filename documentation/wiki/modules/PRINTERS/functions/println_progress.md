# println_progress

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Imprime texto con animación progresiva carácter por carácter a velocidad predeterminada, agregando un salto de línea al final.

## Sintaxis

```pseudocode
Funcion println_progress(text)
```

## Parámetros

- `text`: El texto a imprimir con animación progresiva.

## Retorna

No retorna valor.
