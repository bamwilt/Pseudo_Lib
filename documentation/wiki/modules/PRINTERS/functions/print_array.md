# print_array

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Imprime cada elemento de un arreglo en la misma línea, sin saltos entre elementos.

## Sintaxis

```pseudocode
Funcion print_array(array, index_array)
```

## Parámetros

- `array`: El arreglo a imprimir.
- `index_array`: El tamaño del arreglo.

## Retorna

No retorna valor.
