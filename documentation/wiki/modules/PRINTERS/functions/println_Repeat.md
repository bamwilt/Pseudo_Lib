# println_Repeat

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Repite la impresión de un texto una cantidad determinada de veces, cada una en una nueva línea.

## Sintaxis

```pseudocode
Funcion println_Repeat(text, numEnd)
```

## Parámetros

- `text`: El texto a repetir.
- `numEnd`: Número de repeticiones.

## Retorna

No retorna valor.
