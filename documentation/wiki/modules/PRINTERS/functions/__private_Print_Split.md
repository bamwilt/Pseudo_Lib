# __private_Print_Split

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Función interna que divide un texto usando un separador e imprime cada fragmento en una línea separada.

## Sintaxis

```pseudocode
Funcion __private_Print_Split(text, separator)
```

## Parámetros

- `text`: El texto a dividir e imprimir.
- `separator`: El separador para dividir el texto.

## Retorna

No retorna valor.
