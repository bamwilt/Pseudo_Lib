# print_array_color

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Imprime cada elemento de un arreglo en la misma línea aplicando un color ANSI a cada elemento.

## Sintaxis

```pseudocode
Funcion print_array_color(array, index_array, color)
```

## Parámetros

- `array`: El arreglo a imprimir.
- `index_array`: El tamaño del arreglo.
- `color`: El código de color ANSI a aplicar.

## Retorna

No retorna valor.
