# print_progress_with_speed_Simple

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Imprime texto carácter por carácter a una velocidad dada, sin manejo de saltos de línea.

## Sintaxis

```pseudocode
Funcion print_progress_with_speed_Simple(text, speed)
```

## Parámetros

- `text`: El texto a imprimir carácter por carácter.
- `speed`: Velocidad en milisegundos entre cada carácter.

## Retorna

No retorna valor.
