# println_array

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Imprime cada elemento de un arreglo en una línea separada.

## Sintaxis

```pseudocode
Funcion println_array(array, index_array)
```

## Parámetros

- `array`: El arreglo a imprimir.
- `index_array`: El tamaño del arreglo.

## Retorna

No retorna valor.
