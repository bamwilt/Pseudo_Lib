# print_progress

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Imprime texto con animación progresiva carácter por carácter a velocidad predeterminada.

## Sintaxis

```pseudocode
Funcion print_progress(text)
```

## Parámetros

- `text`: El texto a imprimir con animación progresiva.

## Retorna

No retorna valor.
