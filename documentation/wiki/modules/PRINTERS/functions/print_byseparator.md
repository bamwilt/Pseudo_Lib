# print_byseparator

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Imprime texto dividiéndolo en múltiples líneas usando un separador personalizado.

## Sintaxis

```pseudocode
Funcion print_byseparator(text, separator)
```

## Parámetros

- `text`: El texto a imprimir.
- `separator`: El separador que define los puntos de división.

## Retorna

No retorna valor.
