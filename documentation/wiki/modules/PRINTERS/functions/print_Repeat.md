# print_Repeat

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Repite la impresión de un texto una cantidad determinada de veces en la misma línea.

## Sintaxis

```pseudocode
Funcion print_Repeat(text, numEnd)
```

## Parámetros

- `text`: El texto a repetir.
- `numEnd`: Número de repeticiones.

## Retorna

No retorna valor.
