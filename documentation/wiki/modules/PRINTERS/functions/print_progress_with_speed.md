# print_progress_with_speed

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Imprime texto con animación progresiva a una velocidad personalizada, manejando saltos de línea.

## Sintaxis

```pseudocode
Funcion print_progress_with_speed(text, speed)
```

## Parámetros

- `text`: El texto a imprimir.
- `speed`: Velocidad en milisegundos entre cada carácter.

## Retorna

No retorna valor.
