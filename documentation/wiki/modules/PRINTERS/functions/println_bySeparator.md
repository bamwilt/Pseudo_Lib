# println_bySeparator

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Imprime texto con un separador personalizado agregando un salto de línea al final.

## Sintaxis

```pseudocode
Funcion println_bySeparator(text, separator)
```

## Parámetros

- `text`: El texto a imprimir.
- `separator`: El separador que define los puntos de división.

## Retorna

No retorna valor.
