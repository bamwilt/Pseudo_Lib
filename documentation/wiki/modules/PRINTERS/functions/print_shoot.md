# print_shoot

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Imprime texto con efecto "disparo": las líneas aparecen una por una simulando una ráfaga.

## Sintaxis

```pseudocode
Funcion print_shoot(text)
```

## Parámetros

- `text`: El texto a imprimir con efecto disparo.

## Retorna

No retorna valor.
