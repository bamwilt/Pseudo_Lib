# __private_internal_printer_formater_shoot

**Módulo:** [PRINTERS](../PRINTERS.md)

## Descripción

Función interna que formatea y ejecuta el efecto disparo. Divide el texto en líneas, las almacena en un arreglo y las imprime secuencialmente.

## Sintaxis

```pseudocode
Funcion __private_internal_printer_formater_shoot(text, isClear)
```

## Parámetros

- `text`: El texto a procesar.
- `isClear`: booleano que indica si se debe limpiar la consola antes de imprimir.

## Retorna

No retorna valor.
