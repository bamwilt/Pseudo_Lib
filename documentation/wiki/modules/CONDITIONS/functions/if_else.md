# if_else

**Módulo:** [CONDITIONS](..\CONDITIONS.md)

## Descripción

Returns one of two values based on a boolean condition. If the condition is true, returns the first value; otherwise returns the second.

## Sintaxis
```pseudocode
Funcion result <- if_else(condition, result, result2)
```

## Parámetros
- `condition`: The boolean condition to evaluate
- `result`: Value returned if condition is true
- `result2`: Value returned if condition is false

## Retorna
`result` if condition is true, `result2` otherwise.
