# error_message

**Módulo:** [CONDITIONS](..\CONDITIONS.md)

## Descripción

Logs an error message to the console with ANSI red color formatting.

## Sintaxis
```pseudocode
Funcion error_message(message)
```

## Parámetros
- `message`: The error text to display

## Retorna
Nothing. Outputs `[ERROR] // message.` in red to the console.
