# exection_Error

**Módulo:** [CONDITIONS](..\CONDITIONS.md)

## Descripción

Logs an error message and returns a null integer value.

## Sintaxis
```pseudocode
Funcion exection_Error(message_Error)
```

## Parámetros
- `message_Error`: The error message to log

## Retorna
A null integer value (from `string_NULL()`).
