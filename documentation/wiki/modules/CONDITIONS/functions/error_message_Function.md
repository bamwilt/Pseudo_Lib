# error_message_Function

**Módulo:** [CONDITIONS](..\CONDITIONS.md)

## Descripción

Logs a formatted error message that includes the method name and message, separated by "//".

## Sintaxis
```pseudocode
Funcion error_message_Function(method, message)
```

## Parámetros
- `method`: The name of the function where the error occurred
- `message`: The error description

## Retorna
Nothing. Outputs the error to the console.
