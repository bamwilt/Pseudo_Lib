# color_setColorText

**Módulo:** [COLOR](..\COLOR.md)

## Descripción

Prepends an ANSI color code to a text string, coloring the entire text.

## Sintaxis
```pseudocode
Funcion text_Color <- color_setColorText(text, color)
```

## Parámetros
- `text`: The text to color
- `color`: The ANSI color escape code to apply

## Retorna
The color code prepended to the text.
