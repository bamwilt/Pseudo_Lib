# COLOR_getcolor_forIndex

**Módulo:** [COLOR](..\COLOR.md)

## Descripción

Returns the ANSI escape code for a color index (0-7). Valid indices map to: 0=default, 1=red, 2=green, 3=yellow, 4=blue, 5=magenta, 6=cyan, 7=white.

## Sintaxis
```pseudocode
Funcion color <- COLOR_getcolor_forIndex(index)
```

## Parámetros
- `index`: Color index (0-7)

## Retorna
The ANSI escape sequence for the requested color.
