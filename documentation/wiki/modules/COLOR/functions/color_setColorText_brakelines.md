# color_setColorText_brakelines

**Módulo:** [COLOR](..\COLOR.md)

## Descripción

Wraps text with color codes, inserting the color at the beginning of each line segment separated by newlines. Validates that the color is a valid ANSI code.

## Sintaxis
```pseudocode
Funcion text_Color <- color_setColorText_brakelines(text, color)
```

## Parámetros
- `text`: The text to color
- `color`: The ANSI color escape code

## Retorna
The text with color applied to each line segment.
