# color_setColorText_multiColor

**Módulo:** [COLOR](..\COLOR.md)

## Descripción

Applies cycling colors to each character of the input text, rotating through color indices 1-7.

## Sintaxis
```pseudocode
Funcion text_Color <- color_setColorText_multiColor(text)
```

## Parámetros
- `text`: The text to colorize

## Retorna
A string where each character has a different cycling color.
