# color_text_hasColor

**Módulo:** [COLOR](..\COLOR.md)

## Descripción

Checks whether a text string contains an ANSI color escape sequence.

## Sintaxis
```pseudocode
Funcion boolean <- color_text_hasColor(text)
```

## Parámetros
- `text`: The text to inspect

## Retorna
`true` if the text contains an escape character, `false` otherwise.
