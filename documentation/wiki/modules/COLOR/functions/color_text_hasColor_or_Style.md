# color_text_hasColor_or_Style

**Módulo:** [COLOR](..\COLOR.md)

## Descripción

Checks whether a text string contains any ANSI escape sequence (color or style).

## Sintaxis
```pseudocode
Funcion boolean <- color_text_hasColor_or_Style(text)
```

## Parámetros
- `text`: The text to inspect

## Retorna
`true` if the text contains an escape character, `false` otherwise.
