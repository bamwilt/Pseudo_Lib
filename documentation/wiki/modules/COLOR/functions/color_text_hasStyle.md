# color_text_hasStyle

**Módulo:** [COLOR](..\COLOR.md)

## Descripción

Checks whether a text string contains an ANSI style escape sequence (same check as hasColor).

## Sintaxis
```pseudocode
Funcion boolean <- color_text_hasStyle(text)
```

## Parámetros
- `text`: The text to inspect

## Retorna
`true` if the text contains an escape character, `false` otherwise.
