# color_Darked

**Módulo:** [COLOR](..\COLOR.md)

## Descripción

Applies a dark (dim/bold-off) style followed by a color to the text.

## Sintaxis
```pseudocode
Funcion text_Color <- color_Darked(text, color)
```

## Parámetros
- `text`: The text to style
- `color`: The ANSI color to apply

## Retorna
The text with dark style and color prepended.
