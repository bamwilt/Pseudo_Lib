# color_Normal

**Módulo:** [COLOR](..\COLOR.md)

## Descripción

Applies the dark (dim/normal) ANSI style to text without adding a color.

## Sintaxis
```pseudocode
Funcion text_dark <- color_Normal(text)
```

## Parámetros
- `text`: The text to style

## Retorna
The text with the dark style prepended.
