# cellsCollection_Dynamic_reSize

**Módulo:** [CELLS_COLLECTION_DYNAMIC](../CELLS_COLLECTION_DYNAMIC.md)

## Descripción
Redimensiona toda la colección a una nueva longitud fija, ajustando todas las celdas existentes.

## Sintaxis
```
result_cells <- cellsCollection_Dynamic_reSize(struct_cells, new_fixed_Length)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `new_fixed_Length`: Número con la nueva longitud de celda

## Retorna
Texto con la estructura redimensionada.
