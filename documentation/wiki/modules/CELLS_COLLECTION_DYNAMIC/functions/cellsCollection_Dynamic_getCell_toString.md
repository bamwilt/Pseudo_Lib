# cellsCollection_Dynamic_getCell_toString

**Módulo:** [CELLS_COLLECTION_DYNAMIC](../CELLS_COLLECTION_DYNAMIC.md)

## Descripción
Obtiene un elemento de la colección dinámica como string.

## Sintaxis
```
result_cells <- cellsCollection_Dynamic_getCell_toString(struct_cells, index)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `index`: Número con el índice del elemento

## Retorna
Texto con el contenido del elemento.
