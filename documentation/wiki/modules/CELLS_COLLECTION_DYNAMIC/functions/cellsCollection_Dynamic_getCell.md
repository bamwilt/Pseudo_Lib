# cellsCollection_Dynamic_getCell

**Módulo:** [CELLS_COLLECTION_DYNAMIC](../CELLS_COLLECTION_DYNAMIC.md)

## Descripción
Obtiene un elemento de la colección dinámica por índice, retornándolo en su tipo nativo.

## Sintaxis
```
element_type <- cellsCollection_Dynamic_getCell(struct_cells, index)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `index`: Número con el índice del elemento

## Retorna
Valor del elemento en su tipo correspondiente.
