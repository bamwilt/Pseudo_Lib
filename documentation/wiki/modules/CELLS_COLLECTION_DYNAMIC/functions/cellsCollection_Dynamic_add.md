# cellsCollection_Dynamic_add

**Módulo:** [CELLS_COLLECTION_DYNAMIC](../CELLS_COLLECTION_DYNAMIC.md)

## Descripción
Añade un elemento a la colección con redimensión dinámica, detectando automáticamente el tipo.

## Sintaxis
```
result_cells <- cellsCollection_Dynamic_add(struct_cells, element)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element`: Elemento a añadir

## Retorna
Texto con la estructura modificada.
