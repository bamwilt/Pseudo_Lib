# cellsCollection_Dynamic_add_byString

**Módulo:** [CELLS_COLLECTION_DYNAMIC](../CELLS_COLLECTION_DYNAMIC.md)

## Descripción
Añade un string a la colección, redimensionando la celda si el string excede la longitud actual.

## Sintaxis
```
result_cells <- cellsCollection_Dynamic_add_byString(struct_cells, element_string)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element_string`: Texto con el valor a añadir

## Retorna
Texto con la estructura modificada.
