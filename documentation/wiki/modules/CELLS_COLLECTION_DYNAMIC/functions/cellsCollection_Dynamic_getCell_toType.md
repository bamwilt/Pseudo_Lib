# cellsCollection_Dynamic_getCell_toType

**Módulo:** [CELLS_COLLECTION_DYNAMIC](../CELLS_COLLECTION_DYNAMIC.md)

## Descripción
Obtiene un elemento de la colección dinámica y lo convierte al tipo especificado.

## Sintaxis
```
element_type <- cellsCollection_Dynamic_getCell_toType(struct_cells, index, TYPE)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `index`: Número con el índice del elemento
- `TYPE`: Texto con el tipo de conversión

## Retorna
Valor del elemento en el tipo especificado.
