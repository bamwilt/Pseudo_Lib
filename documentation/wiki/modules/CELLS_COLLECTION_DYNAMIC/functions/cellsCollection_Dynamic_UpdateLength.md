# cellsCollection_Dynamic_UpdateLength

**Módulo:** [CELLS_COLLECTION_DYNAMIC](../CELLS_COLLECTION_DYNAMIC.md)

## Descripción
Actualiza el valor de la longitud fija de celda en la estructura, reemplazando el valor numérico existente.

## Sintaxis
```
result_cells <- cellsCollection_Dynamic_UpdateLength(struct_cells, new_fixed_length)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `new_fixed_length`: Número con la nueva longitud

## Retorna
Texto con la estructura actualizada.
