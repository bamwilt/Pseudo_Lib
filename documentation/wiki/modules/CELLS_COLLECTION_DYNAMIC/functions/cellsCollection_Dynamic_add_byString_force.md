# cellsCollection_Dynamic_add_byString_force

**Módulo:** [CELLS_COLLECTION_DYNAMIC](../CELLS_COLLECTION_DYNAMIC.md)

## Descripción
Añade un string con parámetros precalculados, asegurando capacidad dinámica y normalizando el bloque.

## Sintaxis
```
result_cells <- cellsCollection_Dynamic_add_byString_force(struct_cells, element_string, index_start, index_insert, cell_length)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element_string`: Texto con el valor a añadir
- `index_start`: Número con el índice de inicio de datos
- `index_insert`: Número con la posición de inserción
- `cell_length`: Número con la longitud actual de celda

## Retorna
Texto con la estructura modificada.
