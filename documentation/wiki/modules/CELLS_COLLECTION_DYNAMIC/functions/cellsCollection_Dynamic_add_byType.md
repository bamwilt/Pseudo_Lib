# cellsCollection_Dynamic_add_byType

**Módulo:** [CELLS_COLLECTION_DYNAMIC](../CELLS_COLLECTION_DYNAMIC.md)

## Descripción
Añade un elemento tipado a la colección con redimensión dinámica.

## Sintaxis
```
result_cells <- cellsCollection_Dynamic_add_byType(struct_cells, element, TYPE)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element`: Elemento a añadir
- `TYPE`: Texto con el tipo del elemento

## Retorna
Texto con la estructura modificada.
