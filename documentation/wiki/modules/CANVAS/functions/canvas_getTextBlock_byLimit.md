## canvas_getTextBlock_byLimit()

[~~#CAN~~](../CANVAS.md)

**Descripción:** Obtiene un bloque de texto con limitador.

**Sintaxis:** `canvas_getTextBlock_byLimit(canvas, x, y, width, limiter)`

**Parámetros:**
- `canvas` - Canvas
- `x`, `y` - Posición inicial
- `width` - Ancho del bloque
- `limiter` - Caracter limitador

**Retorno:** String
