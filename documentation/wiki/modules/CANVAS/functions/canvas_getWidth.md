## canvas_getWidth()

[~~#CAN~~](../CANVAS.md)

**Descripción:** Obtiene el ancho del canvas.

**Sintaxis:** `canvas_getWidth(canvas)` / `canvas_getWidth(canvas, pun)`

**Parámetros:**
- `canvas` - Canvas
- `pun` - Puntero (opcional, overload B)

**Retorno:** Int / Void (overload B asigna valor a puntero)
