## canvas_getTextBlock()

[~~#CAN~~](../CANVAS.md)

**Descripción:** Obtiene un bloque de texto desde una posición con ancho específico.

**Sintaxis:** `canvas_getTextBlock(canvas, x, y, width)`

**Parámetros:**
- `canvas` - Canvas
- `x`, `y` - Posición inicial
- `width` - Ancho del bloque

**Retorno:** String
