## canvas_new_withMatrix()

[~~#CAN~~](../CANVAS.md)

**Descripción:** Crea un canvas a partir de una matriz de píxeles.

**Sintaxis:** `canvas_new_withMatrix(Wx, Wy, title, color, matrix)`

**Parámetros:**
- `Wx` - Ancho
- `Wy` - Alto
- `title` - Título
- `color` - Color
- `matrix` - Matriz de píxeles

**Retorno:** Canvas
