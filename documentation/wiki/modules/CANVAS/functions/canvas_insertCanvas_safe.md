## canvas_insertCanvas_safe()

[~~#CAN~~](../CANVAS.md)

**Descripción:** Inserta un canvas con validación de límites.

**Sintaxis:** `canvas_insertCanvas_safe(canvasMain, canvasSub, x, y)`

**Parámetros:**
- `canvasMain` - Canvas destino
- `canvasSub` - Canvas a insertar
- `x`, `y` - Posición

**Retorno:** Void
