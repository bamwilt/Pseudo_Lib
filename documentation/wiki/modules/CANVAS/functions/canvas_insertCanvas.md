## canvas_insertCanvas()

[~~#CAN~~](../CANVAS.md)

**Descripción:** Inserta un canvas dentro de otro en una posición.

**Sintaxis:** `canvas_insertCanvas(canvasMain, canvasSub, x, y)`

**Parámetros:**
- `canvasMain` - Canvas destino
- `canvasSub` - Canvas a insertar
- `x`, `y` - Posición

**Retorno:** Void
