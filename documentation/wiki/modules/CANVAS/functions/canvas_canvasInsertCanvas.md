## canvas_canvasInsertCanvas()

[~~#CAN~~](../CANVAS.md)

**Descripción:** Inserta un canvas en otro (método de estructura interna).

**Sintaxis:** `canvas_canvasInsertCanvas(canvasMain, canvasSub, x, y)`

**Parámetros:**
- `canvasMain` - Canvas destino
- `canvasSub` - Canvas a insertar
- `x`, `y` - Posición

**Retorno:** Void
