## canvas_getPixel_Canvas()

[~~#CAN~~](../CANVAS.md)

**Descripción:** Obtiene un píxel de un canvas relativo a otro canvas.

**Sintaxis:** `canvas_getPixel_Canvas(canvasMain, canvasSub, x, y)`

**Parámetros:**
- `canvasMain` - Canvas principal
- `canvasSub` - Canvas secundario
- `x`, `y` - Coordenadas

**Retorno:** Int
