# __private_collection_printer

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Función privada que imprime datos secuenciales con sus longitudes. Delega en managerData_printer_color.

## Sintaxis

```pseudocode
Funcion __private_collection_printer(sequential_data, sequential_lengths, isnewLine)
```

## Parámetros

- `sequential_data`: Datos secuenciales
- `sequential_lengths`: Longitudes de cada dato
- `isnewLine`: Indica si se imprime con saltos de línea

## Retorna

No retorna valor.
