# collection_getContent_Between_lastSymbols

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el contenido entre la última ocurrencia de dos símbolos delimitadores.

## Sintaxis

```pseudocode
Funcion type_area <- collection_getContent_Between_lastSymbols(collection, symbol_start, symbol_end)
```

## Parámetros

- `collection`: Colección a consultar
- `symbol_start`: Símbolo delimitador inicial
- `symbol_end`: Símbolo delimitador final

## Retorna

String con el contenido entre las últimas ocurrencias.
