# symbol_ExtraData

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Retorna el símbolo que marca el inicio de datos extra en la colección.

## Sintaxis

```pseudocode
Funcion result_string <- symbol_ExtraData
```

## Parámetros

Ninguno.

## Retorna

String con el carácter de control 0x03 (end of text).
