# collection_getIndex_FromNumElement_Separator

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el índice del separador (personalizado) para el número de elemento especificado.

## Sintaxis

```pseudocode
Funcion index_separator <- collection_getIndex_FromNumElement_Separator(text, num, separator)
```

## Parámetros

- `text`: Texto a analizar
- `num`: Número de elemento
- `separator`: Separador personalizado

## Retorna

Índice del separador.
