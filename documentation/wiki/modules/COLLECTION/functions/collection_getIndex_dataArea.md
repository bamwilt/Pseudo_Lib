# collection_getIndex_dataArea

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el índice del símbolo de área de datos en la colección.

## Sintaxis

```pseudocode
Funcion index_DataArea <- collection_getIndex_dataArea(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección a consultar

## Retorna

Índice entero del símbolo dataArea.
