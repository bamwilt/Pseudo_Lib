# symbol_typeArea

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Retorna el símbolo que delimita el área de tipo en la estructura de colección.

## Sintaxis

```pseudocode
Funcion symbol_area <- symbol_typeArea
```

## Parámetros

Ninguno.

## Retorna

String con el carácter de control 0x1D (group separator).
