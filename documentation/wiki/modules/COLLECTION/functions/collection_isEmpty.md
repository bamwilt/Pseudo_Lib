# collection_isEmpty

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Verifica si una colección está vacía.

## Sintaxis

```pseudocode
Funcion isEmpty <- collection_isEmpty(struct_collection)
```

## Parámetros

- `struct_collection`: Colección a evaluar

## Retorna

Verdadero si el área de datos está vacía.
