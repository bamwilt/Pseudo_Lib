# collection_getContent_TypeArea_End_Of_Text

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el tipo entre el símbolo de tipo y un texto final especificado.

## Sintaxis

```pseudocode
Funcion type_area <- collection_getContent_TypeArea_End_Of_Text(collection, text_end)
```

## Parámetros

- `collection`: Colección a consultar
- `text_end`: Texto delimitador final

## Retorna

String con el tipo contenido entre los delimitadores.
