# symbol_dataArea

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Retorna el símbolo que delimita el área de datos en la estructura de colección.

## Sintaxis

```pseudocode
Funcion symbol_area <- symbol_dataArea
```

## Parámetros

Ninguno.

## Retorna

String con el carácter de control 0x07 (campana).
