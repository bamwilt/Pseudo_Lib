# collection_replaceRange_between_lastSymbols

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Reemplaza el contenido entre las últimas ocurrencias de dos símbolos.

## Sintaxis

```pseudocode
Funcion symbol_areaContent <- collection_replaceRange_between_lastSymbols(collection, data_String, symbol_start, symbol_end)
```

## Parámetros

- `collection`: Colección a modificar
- `data_String`: Nuevo contenido
- `symbol_start`: Símbolo inicial
- `symbol_end`: Símbolo final

## Retorna

Colección modificada.
