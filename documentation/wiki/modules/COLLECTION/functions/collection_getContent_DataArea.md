# collection_getContent_DataArea

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el contenido del área de datos de una colección.

## Sintaxis

```pseudocode
Funcion data_Area <- collection_getContent_DataArea(collection)
```

## Parámetros

- `collection`: Colección a consultar

## Retorna

String con el contenido del área de datos.
