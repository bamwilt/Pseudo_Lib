# collection_getContent_TypeArea

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el contenido del área de tipo de una colección.

## Sintaxis

```pseudocode
Funcion type_area <- collection_getContent_TypeArea(collection)
```

## Parámetros

- `collection`: Colección a consultar

## Retorna

String con el tipo de la colección.
