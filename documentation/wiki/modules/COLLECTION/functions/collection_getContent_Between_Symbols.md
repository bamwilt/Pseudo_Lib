# collection_getContent_Between_Symbols

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el contenido entre dos símbolos delimitadores en una colección.

## Sintaxis

```pseudocode
Funcion type_area <- collection_getContent_Between_Symbols(collection, symbol_start, symbol_end)
```

## Parámetros

- `collection`: Colección a consultar
- `symbol_start`: Símbolo delimitador inicial
- `symbol_end`: Símbolo delimitador final

## Retorna

String con el contenido entre los símbolos.
