# collection_getIndex_typeArea

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el índice del símbolo de área de tipo en la colección.

## Sintaxis

```pseudocode
Funcion index_TypeArea <- collection_getIndex_typeArea(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección a consultar

## Retorna

Índice entero del símbolo typeArea.
