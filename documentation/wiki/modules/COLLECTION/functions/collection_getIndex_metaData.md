# collection_getIndex_metaData

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el índice del símbolo de metaData en la colección.

## Sintaxis

```pseudocode
Funcion index_MetaData <- collection_getIndex_metaData(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección a consultar

## Retorna

Índice entero del símbolo metaData.
