# collection_getContent_fromSymbol

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el contenido de la colección a partir de un símbolo dado.

## Sintaxis

```pseudocode
Funcion type_Area <- collection_getContent_fromSymbol(collection, symbol)
```

## Parámetros

- `collection`: Colección a consultar
- `symbol`: Símbolo delimitador

## Retorna

Contenido a partir del símbolo.
