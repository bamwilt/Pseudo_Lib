# symbol_Separator

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Retorna el separador interno usado en las colecciones serializadas.

## Sintaxis

```pseudocode
Funcion result_string <- symbol_Separator
```

## Parámetros

Ninguno.

## Retorna

String con el carácter de control 0x1F (unit separator).
