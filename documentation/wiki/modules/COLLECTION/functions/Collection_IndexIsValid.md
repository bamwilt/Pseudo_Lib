# Collection_IndexIsValid

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Verifica si un índice es válido dentro de una estructura de tamaño conocido.

## Sintaxis

```pseudocode
Funcion index_isValid <- Collection_IndexIsValid(struct_Size, index_element)
```

## Parámetros

- `struct_Size`: Tamaño de la estructura
- `index_element`: Índice a validar

## Retorna

Verdadero si el índice está entre 0 y struct_Size-1.
