# collection_updateRange

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Reemplaza un rango de la colección con un nuevo string.

## Sintaxis

```pseudocode
Funcion collection_result <- collection_updateRange(struct_collection, index_start, index_end, data_string)
```

## Parámetros

- `struct_collection`: Colección original
- `index_start`: Índice inicial
- `index_end`: Índice final
- `data_string`: Nuevo string a insertar

## Retorna

Colección con el rango reemplazado.
