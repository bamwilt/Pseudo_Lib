# collection_new

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Crea una nueva colección estructurada con tipo de estructura y tipo de datos.

## Sintaxis

```pseudocode
Funcion data_collection <- collection_new(STRUCT_TYPE, TYPE)
```

## Parámetros

- `STRUCT_TYPE`: Tipo de estructura (ej. TYPE_OBJECT)
- `TYPE`: Tipo de datos contenido

## Retorna

String con la colección serializada.
