# collection_getLastIndex_FromNumElement

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el último índice del separador para el número de elemento especificado.

## Sintaxis

```pseudocode
Funcion index_separator <- collection_getLastIndex_FromNumElement(text, num)
```

## Parámetros

- `text`: Texto a analizar
- `num`: Número de elemento

## Retorna

Último índice del separador para ese elemento.
