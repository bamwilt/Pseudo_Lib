# collection_getIndex_FromNumElement

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el índice del separador correspondiente al número de elemento especificado.

## Sintaxis

```pseudocode
Funcion index_separator <- collection_getIndex_FromNumElement(text, num)
```

## Parámetros

- `text`: Texto a analizar
- `num`: Número de elemento (0-based)

## Retorna

Índice del separador del elemento.
