# collection_getElement_AtIndex_withSeparator

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene un elemento en un índice usando un separador personalizado.

## Sintaxis

```pseudocode
Funcion str_element <- collection_getElement_AtIndex_withSeparator(text, index, separator)
```

## Parámetros

- `text`: Texto de la colección
- `index`: Índice del elemento
- `separator`: Separador personalizado

## Retorna

String del elemento.
