# collection_replaceRange_between_symbols

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Reemplaza el contenido entre dos símbolos en la colección.

## Sintaxis

```pseudocode
Funcion symbol_areaContent <- collection_replaceRange_between_symbols(collection, data_String, symbol_start, symbol_end)
```

## Parámetros

- `collection`: Colección a modificar
- `data_String`: Nuevo contenido
- `symbol_start`: Símbolo inicial
- `symbol_end`: Símbolo final

## Retorna

Colección con el contenido reemplazado.
