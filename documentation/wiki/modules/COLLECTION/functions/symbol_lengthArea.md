# symbol_lengthArea

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Retorna el símbolo que delimita el área de longitudes en la estructura.

## Sintaxis

```pseudocode
Funcion symbol_area <- symbol_lengthArea
```

## Parámetros

Ninguno.

## Retorna

String con el carácter de control 0x12 (DC2).
