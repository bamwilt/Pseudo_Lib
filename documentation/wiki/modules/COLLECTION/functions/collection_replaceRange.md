# collection_replaceRange

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Reemplaza un rango específico en la colección con un nuevo string.

## Sintaxis

```pseudocode
Funcion collection_out <- collection_replaceRange(collection, data_String, index_start, index_end)
```

## Parámetros

- `collection`: Colección original
- `data_String`: Nuevo string
- `index_start`: Índice inicial
- `index_end`: Índice final

## Retorna

Colección con el rango reemplazado.
