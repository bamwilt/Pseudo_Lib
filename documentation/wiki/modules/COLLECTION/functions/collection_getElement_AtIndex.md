# collection_getElement_AtIndex

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene un elemento de la colección en la posición especificada.

## Sintaxis

```pseudocode
Funcion str_element <- collection_getElement_AtIndex(text, index)
```

## Parámetros

- `text`: Texto de la colección
- `index`: Índice del elemento

## Retorna

String del elemento en la posición indicada.
