# symbol_metaData

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Retorna el símbolo que delimita el área de metadatos en la estructura de colección.

## Sintaxis

```pseudocode
Funcion symbol_area <- symbol_metaData
```

## Parámetros

Ninguno.

## Retorna

String con el carácter de control 0x1E (record separator).
