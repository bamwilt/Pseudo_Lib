# collection_getNameCollection

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el nombre (prefijo alfabético) de una colección.

## Sintaxis

```pseudocode
Funcion name_Collection <- collection_getNameCollection(collection)
```

## Parámetros

- `collection`: Colección a consultar

## Retorna

Nombre alfabético de la colección.
