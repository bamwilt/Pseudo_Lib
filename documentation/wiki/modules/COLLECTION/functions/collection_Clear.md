# collection_Clear

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Limpia el contenido de una colección, manteniendo su estructura y tipo.

## Sintaxis

```pseudocode
Funcion clear_Collection <- collection_Clear(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección a limpiar

## Retorna

Colección vacía con la misma estructura y tipo.
