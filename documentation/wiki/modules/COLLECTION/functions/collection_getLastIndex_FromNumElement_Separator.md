# collection_getLastIndex_FromNumElement_Separator

**Módulo:** [COLLECTION](../COLLECTION.md)

## Descripción

Obtiene el último índice del separador (personalizado) para el número de elemento.

## Sintaxis

```pseudocode
Funcion index_separator <- collection_getLastIndex_FromNumElement_Separator(text, num_separator, separator)
```

## Parámetros

- `text`: Texto a analizar
- `num_separator`: Número de separador
- `separator`: Separador personalizado

## Retorna

Último índice del separador.
