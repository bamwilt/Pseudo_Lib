# util_set_Delete

**Módulo:** [SET](../SET.md)

## Descripción
Elimina un elemento del conjunto.

## Sintaxis
```
Funcion result_storage <- util_set_Delete(struct_set, key_new)
```

## Parámetros
- `struct_set`: Estructura del conjunto
- `key_new`: Elemento a eliminar

## Retorna
El conjunto actualizado sin el elemento.
