# util_set_new

**Módulo:** [SET](../SET.md)

## Descripción
Crea un nuevo conjunto vacío del tipo especificado.

## Sintaxis
```
Funcion new_Set <- util_set_new(TYPE)
```

## Parámetros
- `TYPE`: Tipo de dato que almacenará el conjunto (int, float, boolean, string)

## Retorna
Una nueva estructura de conjunto vacío.
