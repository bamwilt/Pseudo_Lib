# util_set_Add

**Módulo:** [SET](../SET.md)

## Descripción
Agrega un nuevo elemento al conjunto. Si el elemento ya existe, no se realiza ninguna acción.

## Sintaxis
```
Funcion result_storage <- util_set_Add(struct_set, key_new)
```

## Parámetros
- `struct_set`: Estructura del conjunto
- `key_new`: Elemento a agregar

## Retorna
El conjunto actualizado con el nuevo elemento.
