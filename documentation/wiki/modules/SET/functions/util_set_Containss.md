# util_set_Containss

**Módulo:** [SET](../SET.md)

## Descripción
Verifica si un elemento existe dentro del conjunto.

## Sintaxis
```
Funcion keyExist <- util_set_Containss(struct_set, key_match)
```

## Parámetros
- `struct_set`: Estructura del conjunto
- `key_match`: Elemento a buscar

## Retorna
`Verdadero` si el elemento existe, `Falso` en caso contrario.
