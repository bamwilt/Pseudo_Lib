# binarystring_XOR

**Módulo:** [BINARY_STRING](..\BINARY_STRING.md)

## Descripción

Performs a bitwise XOR operation between two binary strings.

## Sintaxis
```pseudocode
Funcion binarystring_Result <- binarystring_XOR(binaryString1, binaryString2)
```

## Parámetros
- `binaryString1`: First binary string
- `binaryString2`: Second binary string

## Retorna
A binary string where each bit is the XOR of the corresponding bits.
