# binarystring_SUM

**Módulo:** [BINARY_STRING](..\BINARY_STRING.md)

## Descripción

Adds two binary strings using bitwise operations (XOR for sum, AND+shift for carry).

## Sintaxis
```pseudocode
Funcion binarystring_result <- binarystring_SUM(binaryString1, binaryString2)
```

## Parámetros
- `binaryString1`: First binary addend
- `binaryString2`: Second binary addend

## Retorna
A binary string representing the sum.
