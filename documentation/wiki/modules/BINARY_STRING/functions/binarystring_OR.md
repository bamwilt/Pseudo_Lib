# binarystring_OR

**Módulo:** [BINARY_STRING](..\BINARY_STRING.md)

## Descripción

Performs a bitwise OR operation between two binary strings.

## Sintaxis
```pseudocode
Funcion binarystring_Result <- binarystring_OR(binaryString1, binaryString2)
```

## Parámetros
- `binaryString1`: First binary string
- `binaryString2`: Second binary string

## Retorna
A binary string where each bit is the OR of the corresponding bits.
