# bitChar_AND

**Módulo:** [BINARY_STRING](..\BINARY_STRING.md)

## Descripción

Computes the logical AND of two single-bit characters.

## Sintaxis
```pseudocode
Funcion bitChar_Result <- bitChar_AND(bit_char1, bit_char2)
```

## Parámetros
- `bit_char1`: A single character, "0" or "1"
- `bit_char2`: A single character, "0" or "1"

## Retorna
`"1"` if both inputs are `"1"`, otherwise `"0"`.
