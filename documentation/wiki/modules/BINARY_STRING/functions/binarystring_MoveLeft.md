# binarystring_MoveLeft

**Módulo:** [BINARY_STRING](..\BINARY_STRING.md)

## Descripción

Shifts a binary string to the left by appending a given number of zeros.

## Sintaxis
```pseudocode
Funcion binarystring_result <- binarystring_MoveLeft(binaryString, num_movements)
```

## Parámetros
- `binaryString`: The binary string to shift
- `num_movements`: Number of positions to shift left

## Retorna
The binary string with `num_movements` zeros appended to the right.
