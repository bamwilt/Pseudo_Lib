# binarystring_TwosComplement

**Módulo:** [BINARY_STRING](..\BINARY_STRING.md)

## Descripción

Computes the two's complement of a binary string by inverting all bits (NOT) and adding 1.

## Sintaxis
```pseudocode
Funcion binarystring_result <- binarystring_TwosComplement(binaryString)
```

## Parámetros
- `binaryString`: The binary string to convert

## Retorna
The two's complement binary string.
