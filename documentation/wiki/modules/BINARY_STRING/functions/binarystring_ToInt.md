# binarystring_ToInt

**Módulo:** [BINARY_STRING](..\BINARY_STRING.md)

## Descripción

Converts a binary string (e.g., "1011") to its integer equivalent.

## Sintaxis
```pseudocode
Funcion int_num <- binarystring_ToInt(binaryString)
```

## Parámetros
- `binaryString`: The binary string to convert (composed of '0' and '1')

## Retorna
The integer value represented by the binary string.
