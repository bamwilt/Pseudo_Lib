# bitChar_NOT

**Módulo:** [BINARY_STRING](..\BINARY_STRING.md)

## Descripción

Computes the logical NOT of a single-bit character.

## Sintaxis
```pseudocode
Funcion bitChar_Result <- bitChar_NOT(bit_char1)
```

## Parámetros
- `bit_char1`: A single character, "0" or "1"

## Retorna
`"0"` if input is `"1"`, `"1"` if input is `"0"`.
