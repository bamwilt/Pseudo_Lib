# bitChar_XOR

**Módulo:** [BINARY_STRING](..\BINARY_STRING.md)

## Descripción

Computes the logical XOR of two single-bit characters.

## Sintaxis
```pseudocode
Funcion bitChar_Result <- bitChar_XOR(bit_char1, bit_char2)
```

## Parámetros
- `bit_char1`: A single character, "0" or "1"
- `bit_char2`: A single character, "0" or "1"

## Retorna
`"1"` if the inputs differ, `"0"` if they are equal.
