# binarystring_MoveRight

**Módulo:** [BINARY_STRING](..\BINARY_STRING.md)

## Descripción

Shifts a binary string to the right by removing a given number of trailing characters.

## Sintaxis
```pseudocode
Funcion binarystring_result <- binarystring_MoveRight(binaryString, num_movements)
```

## Parámetros
- `binaryString`: The binary string to shift
- `num_movements`: Number of positions to shift right

## Retorna
The binary string with the last `num_movements` characters removed.
