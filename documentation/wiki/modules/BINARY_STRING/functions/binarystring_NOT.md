# binarystring_NOT

**Módulo:** [BINARY_STRING](..\BINARY_STRING.md)

## Descripción

Performs a bitwise NOT (one's complement) on a binary string, inverting all bits.

## Sintaxis
```pseudocode
Funcion binarystring_Result <- binarystring_NOT(binaryString1)
```

## Parámetros
- `binaryString1`: The binary string to invert

## Retorna
A binary string with all bits flipped (0 becomes 1, 1 becomes 0).
