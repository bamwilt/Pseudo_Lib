# bitChar_OR

**Módulo:** [BINARY_STRING](..\BINARY_STRING.md)

## Descripción

Computes the logical OR of two single-bit characters.

## Sintaxis
```pseudocode
Funcion bitChar_Result <- bitChar_OR(bit_char1, bit_char2)
```

## Parámetros
- `bit_char1`: A single character, "0" or "1"
- `bit_char2`: A single character, "0" or "1"

## Retorna
`"0"` if both inputs are `"0"`, otherwise `"1"`.
