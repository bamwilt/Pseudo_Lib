# sleep

**Módulo:** [SLEEP](../SLEEP.md)

## Descripción

Pausa la ejecución del algoritmo durante una cantidad específica de milisegundos.

## Sintaxis

```pseudocode
Funcion sleep(ms)
```

## Parámetros

- `ms`: Cantidad de milisegundos a esperar.

## Retorna

No retorna valor.
