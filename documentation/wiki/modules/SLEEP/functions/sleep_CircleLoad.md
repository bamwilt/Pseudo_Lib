# sleep_CircleLoad

**Módulo:** [SLEEP](../SLEEP.md)

## Descripción

Muestra una animación circular de carga (`|`, `/`, `-`, `\`) durante un tiempo determinado.

## Sintaxis

```pseudocode
Funcion sleep_CircleLoad(s)
```

## Parámetros

- `s`: Factor de duración de la animación.

## Retorna

No retorna valor.
