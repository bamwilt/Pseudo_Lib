# sleep_Animation

**Módulo:** [SLEEP](../SLEEP.md)

## Descripción

Controlador de animaciones personalizadas. Muestra una secuencia de textos en bucle a una velocidad determinada, con opciones de padding y limpieza de pantalla.

## Sintaxis

```pseudocode
Funcion sleep_Animation(s, speed, text_array_Sequence, Size, padding_x, padding_y, EnableClear)
```

## Parámetros

- `s`: Factor de duración de la animación.
- `speed`: Velocidad en milisegundos entre cada fotograma.
- `text_array_Sequence`: Arreglo de textos que forman la secuencia de animación.
- `Size`: Tamaño del arreglo de secuencia.
- `padding_x`: Espaciado horizontal (número de espacios a la izquierda).
- `padding_y`: Espaciado vertical (número de líneas en blanco arriba).
- `EnableClear`: booleano que indica si se debe limpiar la consola entre fotogramas.

## Retorna

No retorna valor.
