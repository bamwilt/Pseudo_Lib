# sleep_if_message

**Módulo:** [SLEEP](../SLEEP.md)

## Descripción

Pausa la ejecución condicionalmente: si la condición es Verdadera, muestra un mensaje informativo y luego espera la cantidad de segundos especificada.

## Sintaxis

```pseudocode
Funcion sleep_if_message(s, condition, message_date)
```

## Parámetros

- `s`: Cantidad de segundos a esperar.
- `condition`: Condición booleana que determina si se ejecuta la pausa.
- `message_date`: Mensaje informativo a mostrar antes de la pausa.

## Retorna

No retorna valor.
