# sleep_message

**Módulo:** [SLEEP](../SLEEP.md)

## Descripción

Muestra un mensaje informativo y luego pausa la ejecución por la cantidad de segundos especificada.

## Sintaxis

```pseudocode
Funcion sleep_message(s, message_date)
```

## Parámetros

- `s`: Cantidad de segundos a esperar.
- `message_date`: Mensaje informativo a mostrar.

## Retorna

No retorna valor.
