# sleep_And_Clear

**Módulo:** [SLEEP](../SLEEP.md)

## Descripción

Pausa la ejecución por una cantidad de milisegundos y luego limpia la consola.

## Sintaxis

```pseudocode
Funcion sleep_And_Clear(ms)
```

## Parámetros

- `ms`: Cantidad de milisegundos a esperar antes de limpiar.

## Retorna

No retorna valor.
