# sleep_Second_And_Clear

**Módulo:** [SLEEP](../SLEEP.md)

## Descripción

Pausa la ejecución por una cantidad de segundos y luego limpia la consola.

## Sintaxis

```pseudocode
Funcion sleep_Second_And_Clear(s)
```

## Parámetros

- `s`: Cantidad de segundos a esperar antes de limpiar.

## Retorna

No retorna valor.
