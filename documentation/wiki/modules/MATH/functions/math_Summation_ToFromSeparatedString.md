# math_Summation_ToFromSeparatedString

**Módulo:** [MATH](..\MATH.md)

## Descripción

Extracts numeric values from a string and computes their sum. Non-numeric characters are used as delimiters.

## Sintaxis
```pseudocode
Funcion num_range <- math_Summation_ToFromSeparatedString(separatedString, separator)
```

## Parámetros
- `separatedString`: A string containing numbers and delimiters
- `separator`: Separator character (not used directly; non-numeric chars delimit)

## Retorna
The sum of all numeric values found in the string.
