# math_log

**Módulo:** [MATH](..\MATH.md)

## Descripción

Computes the logarithm of a number with an arbitrary base using the identity log_base(x) = ln(x) / ln(base).

## Sintaxis
```pseudocode
Funcion logx <- math_log(x, base)
```

## Parámetros
- `x`: The value
- `base`: The logarithm base

## Retorna
The logarithm of `x` to the given `base`.
