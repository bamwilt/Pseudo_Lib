# math_pow_float

**Módulo:** [MATH](..\MATH.md)

## Descripción

Computes exponentiation for real exponents using the identity x^y = exp(y * ln(x)).

## Sintaxis
```pseudocode
Funcion num_pow <- math_pow_float(base, exponente)
```

## Parámetros
- `base`: The base (must be positive)
- `exponente`: The real exponent

## Retorna
`base` raised to the power of `exponente`.
