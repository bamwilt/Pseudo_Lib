# math_truncate

**Módulo:** [MATH](..\MATH.md)

## Descripción

Truncates a number by removing its decimal part (rounds toward zero).

## Sintaxis
```pseudocode
Funcion num_trunc <- math_truncate(num)
```

## Parámetros
- `num`: The number to truncate

## Retorna
The integer part of `num`, discarding the fractional portion.
