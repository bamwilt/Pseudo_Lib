# math_min_float

**Módulo:** [MATH](..\MATH.md)

## Descripción

Returns the lesser of two floating-point values.

## Sintaxis
```pseudocode
Funcion result <- math_min_float(value, limit)
```

## Parámetros
- `value`: First float
- `limit`: Second float

## Retorna
The smaller of `value` and `limit`.
