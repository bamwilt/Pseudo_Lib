# math_sqrt

**Módulo:** [MATH](..\MATH.md)

## Descripción

Computes the square root of a number using the Babylonian method (6 iterations).

## Sintaxis
```pseudocode
Funcion num_sqrt <- math_sqrt(S)
```

## Parámetros
- `S`: The number to find the square root of

## Retorna
The approximate square root of `S`.
