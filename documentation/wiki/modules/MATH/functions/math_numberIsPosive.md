# math_numberIsPosive

**Módulo:** [MATH](..\MATH.md)

## Descripción

Checks whether a number is non-negative (positive or zero).

## Sintaxis
```pseudocode
Funcion isPositive <- math_numberIsPosive(num)
```

## Parámetros
- `num`: The number to check

## Retorna
`true` if `num >= 0`, `false` otherwise.
