# math_max_Float

**Módulo:** [MATH](..\MATH.md)

## Descripción

Returns the greater of two floating-point values.

## Sintaxis
```pseudocode
Funcion result <- math_max_Float(value, limit)
```

## Parámetros
- `value`: First float
- `limit`: Second float

## Retorna
The larger of `value` and `limit`.
