# math_div

**Módulo:** [MATH](..\MATH.md)

## Descripción

Performs safe division. If the divisor is zero, it logs an error and uses 1 as the divisor instead.

## Sintaxis
```pseudocode
Funcion num_div <- math_div(dividend, divisor)
```

## Parámetros
- `dividend`: The number to be divided
- `divisor`: The divisor

## Retorna
The quotient of `dividend / divisor`.
