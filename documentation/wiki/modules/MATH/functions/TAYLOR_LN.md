# TAYLOR_LN

**Módulo:** [MATH](..\MATH.md)

## Descripción

Returns the constant identifier string `"TAYLOR_LN"` used to select the natural logarithm Taylor series in the Taylor engine.

## Sintaxis
```pseudocode
Funcion id <- TAYLOR_LN
```

## Parámetros
None.

## Retorna
The string `"TAYLOR_LN"`.
