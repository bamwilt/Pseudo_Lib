# math_bilinear_map

**Módulo:** [MATH](..\MATH.md)

## Descripción

Maps x to (x-1)/(x+1), used internally for the natural logarithm Taylor series computation.

## Sintaxis
```pseudocode
Funcion x_bounds <- math_bilinear_map(x)
```

## Parámetros
- `x`: Input value

## Retorna
`(x - 1) / (x + 1)`.
