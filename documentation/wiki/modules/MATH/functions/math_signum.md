# math_signum

**Módulo:** [MATH](..\MATH.md)

## Descripción

Returns the sign of a number: 1 for positive, -1 for negative, 0 for zero.

## Sintaxis
```pseudocode
Funcion num_Signum <- math_signum(num)
```

## Parámetros
- `num`: The input number

## Retorna
`1` if `num > 0`, `-1` if `num < 0`, `0` if `num == 0`.
