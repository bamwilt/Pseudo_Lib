# math_ln

**Módulo:** [MATH](..\MATH.md)

## Descripción

Computes the natural logarithm of a positive number using the bilinear map and Taylor series.

## Sintaxis
```pseudocode
Funcion num_ln <- math_ln(x)
```

## Parámetros
- `x`: A positive number (x > 0)

## Retorna
The natural logarithm of `x`. Returns `number_NULL()` if x <= 0 and logs an error.
