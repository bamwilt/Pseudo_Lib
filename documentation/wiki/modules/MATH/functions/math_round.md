# math_round

**Módulo:** [MATH](..\MATH.md)

## Descripción

Rounds a number to the nearest integer. Uses standard rounding (0.5 rounds up for positive, down for negative).

## Sintaxis
```pseudocode
Funcion number_Round <- math_round(number)
```

## Parámetros
- `number`: The number to round

## Retorna
The nearest integer to `number`.
