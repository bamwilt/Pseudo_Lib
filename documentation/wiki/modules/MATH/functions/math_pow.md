# math_pow

**Módulo:** [MATH](..\MATH.md)

## Descripción

Computes exponentiation using the exponentiation-by-squaring algorithm for integer exponents.

## Sintaxis
```pseudocode
Funcion num_pow <- math_pow(x, exponent)
```

## Parámetros
- `x`: The base
- `exponent`: The integer exponent (must be non-negative)

## Retorna
`x` raised to the power of `exponent`.
