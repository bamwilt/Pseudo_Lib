# math_serie_taylor

**Módulo:** [MATH](..\MATH.md)

## Descripción

Evaluates a Taylor series for a given function up to convergence (80 iterations max, using EPSILON threshold).

## Sintaxis
```pseudocode
Funcion num_taylor <- math_serie_taylor(x, name_function)
```

## Parámetros
- `x`: The input value
- `name_function`: The function identifier (TAYLOR_SIN, TAYLOR_COS, TAYLOR_EXP, TAYLOR_LN)

## Retorna
The sum of the Taylor series approximation.
