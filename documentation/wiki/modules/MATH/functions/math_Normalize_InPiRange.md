# math_Normalize_InPiRange

**Módulo:** [MATH](..\MATH.md)

## Descripción

Normalizes an angle into the range [-PI, PI] using modular arithmetic.

## Sintaxis
```pseudocode
Funcion x_norm <- math_Normalize_InPiRange(x)
```

## Parámetros
- `x`: Angle in radians

## Retorna
The normalized angle within [-PI, PI].
