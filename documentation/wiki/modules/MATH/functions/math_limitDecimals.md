# math_limitDecimals

**Módulo:** [MATH](..\MATH.md)

## Descripción

Limits a floating-point number to a specified number of decimal places by truncation.

## Sintaxis
```pseudocode
Funcion float_lim <- math_limitDecimals(num, limitFloat)
```

## Parámetros
- `num`: The number to limit
- `limitFloat`: Maximum number of decimal places

## Retorna
The number with at most `limitFloat` decimal digits.
