## SpriteString_toCanvas_Size()

[~~#SPR~~](../SPRITE.md)

**Descripción:** Convierte un sprite a canvas con tamaño definido.

**Sintaxis:** `SpriteString_toCanvas_Size(sprite, Cx, Cy)`

**Parámetros:**
- `sprite` - Sprite
- `Cx` - Ancho del canvas destino
- `Cy` - Alto del canvas destino

**Retorno:** Canvas
