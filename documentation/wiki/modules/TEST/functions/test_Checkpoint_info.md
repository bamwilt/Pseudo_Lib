# test_Checkpoint_info

**Módulo:** [TEST](../TEST.md)

## Descripción

Crea un punto de control con información adicional. Muestra un marcador visual, un mensaje informativo y espera una tecla para continuar.

## Sintaxis

```pseudocode
Funcion test_Checkpoint_info(id, info_string)
```

## Parámetros

- `id`: Identificador numérico del punto de control.
- `info_string`: Cadena informativa adicional a mostrar.

## Retorna

No retorna valor.
