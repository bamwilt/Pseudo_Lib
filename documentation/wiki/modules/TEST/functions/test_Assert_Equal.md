# test_Assert_Equal

**Módulo:** [TEST](../TEST.md)

## Descripción

Verifica que dos valores sean iguales según su tipo. Muestra un mensaje de éxito si coinciden o un error si no.

## Sintaxis

```pseudocode
Funcion test_Assert_Equal(value, value_expected, TYPE)
```

## Parámetros

- `value`: El valor actual a evaluar.
- `value_expected`: El valor esperado.
- `TYPE`: El tipo de datos (TYPE_INT, TYPE_FLOAT, TYPE_BOOLEAN, TYPE_STRING).

## Retorna

No retorna valor.
