# test_Function_Passed

**Módulo:** [TEST](../TEST.md)

## Descripción

Evalúa si una prueba fue superada, mostrando el nombre del método, y actualiza un contador de resultados.

## Sintaxis

```pseudocode
Funcion count_result <- test_Function_Passed(value, value_expected, TYPE, method_name, count_string)
```

## Parámetros

- `value`: El valor actual.
- `value_expected`: El valor esperado.
- `TYPE`: El tipo de datos.
- `method_name`: El nombre del método que se está probando.
- `count_string`: Cadena con el contador actual en formato "éxitos/fallos".

## Retorna

Cadena actualizada con el nuevo conteo de éxitos/fallos.
