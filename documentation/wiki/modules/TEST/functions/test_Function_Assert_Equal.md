# test_Function_Assert_Equal

**Módulo:** [TEST](../TEST.md)

## Descripción

Verifica que dos valores sean iguales, mostrando el nombre del método en el mensaje de resultado.

## Sintaxis

```pseudocode
Funcion test_Function_Assert_Equal(value, value_expected, TYPE, method_name)
```

## Parámetros

- `value`: El valor actual a evaluar.
- `value_expected`: El valor esperado.
- `TYPE`: El tipo de datos.
- `method_name`: El nombre del método que se está probando.

## Retorna

No retorna valor.
