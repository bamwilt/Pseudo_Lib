# message_duration

**Módulo:** [TEST](../TEST.md)

## Descripción

Muestra un mensaje formateado con el tiempo de ejecución transcurrido en formato `hh:mm:ss`.

## Sintaxis

```pseudocode
Funcion message_duration(struct_localTime)
```

## Parámetros

- `struct_localTime`: Estructura de tiempo local a mostrar.

## Retorna

No retorna valor.
