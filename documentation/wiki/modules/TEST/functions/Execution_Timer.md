# Execution_Timer

**Módulo:** [TEST](../TEST.md)

## Descripción

Mide el tiempo de ejecución de un bloque de código. Calcula la diferencia entre un tiempo de inicio y el tiempo actual.

## Sintaxis

```pseudocode
Funcion duration_Timer <- Execution_Timer(localTime_Start, funtion_return)
```

## Parámetros

- `localTime_Start`: Estructura de tiempo de inicio.
- `funtion_return`: Valor de retorno de la función medida (no se utiliza directamente).

## Retorna

Estructura de duración con la diferencia de tiempo.
