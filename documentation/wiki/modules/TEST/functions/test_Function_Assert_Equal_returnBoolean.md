# test_Function_Assert_Equal_returnBoolean

**Módulo:** [TEST](../TEST.md)

## Descripción

Verifica la igualdad entre dos valores y retorna un booleano indicando si la aserción fue exitosa. Muestra mensajes de éxito o error según el resultado.

## Sintaxis

```pseudocode
Funcion result_Boolean <- test_Function_Assert_Equal_returnBoolean(value, value_expected, TYPE, method_name)
```

## Parámetros

- `value`: El valor actual a evaluar.
- `value_expected`: El valor esperado.
- `TYPE`: El tipo de datos.
- `method_name`: El nombre del método que se está probando.

## Retorna

Verdadero si los valores son iguales, Falso en caso contrario.
