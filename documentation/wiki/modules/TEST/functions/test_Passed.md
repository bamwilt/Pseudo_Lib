# test_Passed

**Módulo:** [TEST](../TEST.md)

## Descripción

Evalúa si una prueba fue superada y actualiza un contador de resultados (éxitos/fallos) representado como cadena.

## Sintaxis

```pseudocode
Funcion count_result <- test_Passed(value, value_expected, TYPE, count_string)
```

## Parámetros

- `value`: El valor actual.
- `value_expected`: El valor esperado.
- `TYPE`: El tipo de datos.
- `count_string`: Cadena con el contador actual en formato "éxitos/fallos".

## Retorna

Cadena actualizada con el nuevo conteo de éxitos/fallos.
