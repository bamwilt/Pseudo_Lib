# user_input_options_separator

**Módulo:** [INPUT](../INPUT.md)

## Descripción

Solicita input con opciones y separador personalizado.

## Sintaxis

```pseudocode
Funcion Según TYPE <- user_input_options_separator(options_text, separator, TYPE)
```

## Parámetros

- `options_text`: Texto con las opciones separadas

- `separator`: Separador de las opciones

- `TYPE`: Tipo de dato esperado

## Retorna

Según TYPE
