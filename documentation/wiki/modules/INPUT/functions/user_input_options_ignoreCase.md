# user_input_options_ignoreCase

**Módulo:** [INPUT](../INPUT.md)

## Descripción

Solicita input con opciones sin distinguir mayúsculas/minúsculas.

## Sintaxis

```pseudocode
Funcion Según TYPE <- user_input_options_ignoreCase(options_text, TYPE)
```

## Parámetros

- `options_text`: Texto con las opciones (se comparará en minúsculas)

- `TYPE`: Tipo de dato esperado

## Retorna

Según TYPE
