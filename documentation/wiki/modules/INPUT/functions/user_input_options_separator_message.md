# user_input_options_separator_message

**Módulo:** [INPUT](../INPUT.md)

## Descripción

Solicita input con opciones separadas por un delimitador y un mensaje.

## Sintaxis

```pseudocode
Funcion Según TYPE <- user_input_options_separator_message(options_text, separator, message, TYPE)
```

## Parámetros

- `options_text`: Texto con las opciones separadas

- `separator`: Separador de las opciones

- `message`: Mensaje a mostrar

- `TYPE`: Tipo de dato esperado

## Retorna

Según TYPE
