# user_input_options

**Módulo:** [INPUT](../INPUT.md)

## Descripción

Solicita input validando contra una lista de opciones.

## Sintaxis

```pseudocode
Funcion Según TYPE <- user_input_options(options_text, TYPE)
```

## Parámetros

- `options_text`: Texto con las opciones disponibles

- `TYPE`: Tipo de dato esperado

## Retorna

Según TYPE
