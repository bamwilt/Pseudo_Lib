# user_input_options_message

**Módulo:** [INPUT](../INPUT.md)

## Descripción

Solicita input validando contra una lista de opciones y mostrando un mensaje.

## Sintaxis

```pseudocode
Funcion Según TYPE <- user_input_options_message(options_text, message, TYPE)
```

## Parámetros

- `options_text`: Texto con las opciones disponibles

- `message`: Mensaje a mostrar al usuario

- `TYPE`: Tipo de dato esperado (TYPE_STRING, TYPE_INT, TYPE_BOOLEAN, TYPE_FLOAT)

## Retorna

Según TYPE
