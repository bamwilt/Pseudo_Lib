# localDateTime_withMinute

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Establece un nuevo minuto en un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_withMinute(struct_dateTime, minute)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `minute`: Nuevo minuto (0-59)

## Retorna
LocalDateTime con el minuto modificado.
