# localDateTime_toLocalTime

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Extrae la parte de hora (LocalTime) de un LocalDateTime.

## Sintaxis
```pseudocode
Funcion struct_time <- localDateTime_toLocalTime(struct_dateTime)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime

## Retorna
Un objeto LocalTime con la hora.
