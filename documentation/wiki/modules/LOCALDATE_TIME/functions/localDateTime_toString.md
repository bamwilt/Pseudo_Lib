# localDateTime_toString

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Convierte un LocalDateTime a su representación textual en formato yyyy-MM-dd HH:mm:ss.

## Sintaxis
```pseudocode
Funcion string_dateTime <- localDateTime_toString(localDateTime)
```

## Parámetros
- `localDateTime`: Objeto LocalDateTime

## Retorna
Texto en formato yyyy-MM-dd HH:mm:ss.
