# localDateTime_getMinute

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Obtiene el minuto (0-59) de un LocalDateTime.

## Sintaxis
```pseudocode
Funcion minute <- localDateTime_getMinute(struct_dateTime)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime

## Retorna
El minuto.
