# localDateTime_truncatedToHours

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Trunca un LocalDateTime a la hora, eliminando minutos y segundos.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_truncatedToHours(struct_dateTime)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime

## Retorna
LocalDateTime truncado a la hora.
