# localDateTime_plusSeconds

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Suma segundos a un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_plusSeconds(struct_dateTime, unit_plus)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `unit_plus`: Cantidad de segundos a sumar

## Retorna
Nuevo LocalDateTime con los segundos sumados.
