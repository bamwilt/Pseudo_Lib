# localDateTime_getSecond

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Obtiene el segundo (0-59) de un LocalDateTime.

## Sintaxis
```pseudocode
Funcion second <- localDateTime_getSecond(struct_dateTime)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime

## Retorna
El segundo.
