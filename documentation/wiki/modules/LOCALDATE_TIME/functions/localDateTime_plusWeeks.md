# localDateTime_plusWeeks

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Suma semanas a un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_plusWeeks(struct_dateTime, unit_plus)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `unit_plus`: Cantidad de semanas a sumar

## Retorna
Nuevo LocalDateTime con las semanas sumadas.
