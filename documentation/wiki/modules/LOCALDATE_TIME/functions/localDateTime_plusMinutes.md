# localDateTime_plusMinutes

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Suma minutos a un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_plusMinutes(struct_dateTime, unit_plus)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `unit_plus`: Cantidad de minutos a sumar

## Retorna
Nuevo LocalDateTime con los minutos sumados.
