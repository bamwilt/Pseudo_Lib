# localDateTime_withDayOfMonth

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Establece un nuevo día del mes en un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_withDayOfMonth(struct_dateTime, dayOfMonth)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `dayOfMonth`: Nuevo día del mes

## Retorna
LocalDateTime con el día modificado.
