# localDateTime_isAfter

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Verifica si un LocalDateTime es posterior a otro.

## Sintaxis
```pseudocode
Funcion isAfter <- localDateTime_isAfter(struct_dt1, struct_dt2)
```

## Parámetros
- `struct_dt1`: Primer objeto LocalDateTime
- `struct_dt2`: Segundo objeto LocalDateTime

## Retorna
`true` si es posterior, `false` en caso contrario.
