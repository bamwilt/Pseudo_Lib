# localDateTime_isBefore

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Verifica si un LocalDateTime es anterior a otro.

## Sintaxis
```pseudocode
Funcion isBefore <- localDateTime_isBefore(struct_dt1, struct_dt2)
```

## Parámetros
- `struct_dt1`: Primer objeto LocalDateTime
- `struct_dt2`: Segundo objeto LocalDateTime

## Retorna
`true` si es anterior, `false` en caso contrario.
