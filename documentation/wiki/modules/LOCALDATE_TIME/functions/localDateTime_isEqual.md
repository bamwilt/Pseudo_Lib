# localDateTime_isEqual

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Verifica si dos LocalDateTime son iguales.

## Sintaxis
```pseudocode
Funcion isEqual <- localDateTime_isEqual(struct_dt1, struct_dt2)
```

## Parámetros
- `struct_dt1`: Primer objeto LocalDateTime
- `struct_dt2`: Segundo objeto LocalDateTime

## Retorna
`true` si son iguales, `false` en caso contrario.
