# localDateTime_minusMinutes

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Resta minutos a un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_minusMinutes(struct_dateTime, unit_minus)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `unit_minus`: Cantidad de minutos a restar

## Retorna
Nuevo LocalDateTime con los minutos restados.
