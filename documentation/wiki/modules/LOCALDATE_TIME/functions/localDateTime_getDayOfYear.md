# localDateTime_getDayOfYear

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Obtiene el día del año (1-365/366) de un LocalDateTime.

## Sintaxis
```pseudocode
Funcion dayYear <- localDateTime_getDayOfYear(struct_dateTime)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime

## Retorna
El día del año.
