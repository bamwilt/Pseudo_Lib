# localDateTime_minusYears

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Resta años a un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_minusYears(struct_dateTime, unit_minus)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `unit_minus`: Cantidad de años a restar

## Retorna
Nuevo LocalDateTime con los años restados.
