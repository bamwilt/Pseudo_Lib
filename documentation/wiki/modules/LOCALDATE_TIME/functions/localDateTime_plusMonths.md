# localDateTime_plusMonths

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Suma meses a un LocalDateTime. Ajusta el día si el mes resultante tiene menos días.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_plusMonths(struct_dateTime, unit_plus)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `unit_plus`: Cantidad de meses a sumar

## Retorna
Nuevo LocalDateTime con los meses sumados.
