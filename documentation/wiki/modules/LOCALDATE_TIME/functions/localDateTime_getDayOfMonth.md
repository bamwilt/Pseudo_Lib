# localDateTime_getDayOfMonth

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Obtiene el día del mes de un LocalDateTime.

## Sintaxis
```pseudocode
Funcion day <- localDateTime_getDayOfMonth(struct_dateTime)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime

## Retorna
El día del mes.
