# localDateTime_withHour

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Establece una nueva hora en un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_withHour(struct_dateTime, hour)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `hour`: Nueva hora (0-23)

## Retorna
LocalDateTime con la hora modificada.
