# localDateTime_minusDays

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Resta días a un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_minusDays(struct_dateTime, unit_minus)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `unit_minus`: Cantidad de días a restar

## Retorna
Nuevo LocalDateTime con los días restados.
