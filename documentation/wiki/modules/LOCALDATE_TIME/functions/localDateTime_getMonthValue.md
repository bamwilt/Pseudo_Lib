# localDateTime_getMonthValue

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Obtiene el mes (1-12) de un LocalDateTime.

## Sintaxis
```pseudocode
Funcion month <- localDateTime_getMonthValue(struct_dateTime)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime

## Retorna
El mes (1-12).
