# localDateTime_of_struct_DateAndTime

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Combina un objeto LocalDate y un LocalTime en un solo LocalDateTime.

## Sintaxis
```pseudocode
Funcion struct_dateTime <- localDateTime_of_struct_DateAndTime(localDate, localTime)
```

## Parámetros
- `localDate`: Objeto LocalDate
- `localTime`: Objeto LocalTime

## Retorna
Un objeto LocalDateTime combinado.
