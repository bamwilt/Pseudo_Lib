# localDateTime_withYear

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Establece un nuevo año en un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_withYear(struct_dateTime, year)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `year`: Nuevo año

## Retorna
LocalDateTime con el año modificado.
