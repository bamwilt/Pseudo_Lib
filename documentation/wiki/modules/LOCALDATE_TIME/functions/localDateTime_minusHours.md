# localDateTime_minusHours

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Resta horas a un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_minusHours(struct_dateTime, unit_minus)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `unit_minus`: Cantidad de horas a restar

## Retorna
Nuevo LocalDateTime con las horas restadas.
