# localDateTime_plusHours

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Suma horas a un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_plusHours(struct_dateTime, unit_plus)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `unit_plus`: Cantidad de horas a sumar

## Retorna
Nuevo LocalDateTime con las horas sumadas.
