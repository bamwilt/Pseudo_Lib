# localDateTime_minusMonths

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Resta meses a un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_minusMonths(struct_dateTime, unit_minus)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `unit_minus`: Cantidad de meses a restar

## Retorna
Nuevo LocalDateTime con los meses restados.
