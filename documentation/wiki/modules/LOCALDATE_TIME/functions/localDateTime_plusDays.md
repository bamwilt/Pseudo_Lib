# localDateTime_plusDays

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Suma días a un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_plusDays(struct_dateTime, unit_plus)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `unit_plus`: Cantidad de días a sumar

## Retorna
Nuevo LocalDateTime con los días sumados.
