# localDateTime_getDayOfWeek

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Obtiene el nombre del día de la semana de un LocalDateTime.

## Sintaxis
```pseudocode
Funcion dayName <- localDateTime_getDayOfWeek(struct_dateTime)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime

## Retorna
El nombre del día de la semana (ej: MONDAY, TUESDAY, etc.).
