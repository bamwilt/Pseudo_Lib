# localDateTime_withSecond

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Establece un nuevo segundo en un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_withSecond(struct_dateTime, second)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `second`: Nuevo segundo (0-59)

## Retorna
LocalDateTime con el segundo modificado.
