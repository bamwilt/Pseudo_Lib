# localDateTime_getHour

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Obtiene la hora (0-23) de un LocalDateTime.

## Sintaxis
```pseudocode
Funcion hour <- localDateTime_getHour(struct_dateTime)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime

## Retorna
La hora.
