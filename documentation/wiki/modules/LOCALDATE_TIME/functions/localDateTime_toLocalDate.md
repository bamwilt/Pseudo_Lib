# localDateTime_toLocalDate

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Extrae la parte de fecha (LocalDate) de un LocalDateTime.

## Sintaxis
```pseudocode
Funcion struct_date <- localDateTime_toLocalDate(struct_dateTime)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime

## Retorna
Un objeto LocalDate con la fecha.
