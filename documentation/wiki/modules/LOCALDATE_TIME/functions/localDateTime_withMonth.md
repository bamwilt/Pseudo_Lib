# localDateTime_withMonth

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Establece un nuevo mes en un LocalDateTime.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_withMonth(struct_dateTime, month)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime
- `month`: Nuevo mes (1-12)

## Retorna
LocalDateTime con el mes modificado.
