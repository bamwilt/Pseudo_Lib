# localDateTime_truncatedToMinutes

**Módulo:** [LOCALDATE_TIME](../LOCALDATE_TIME.md)

## Descripción
Trunca un LocalDateTime al minuto, eliminando los segundos.

## Sintaxis
```pseudocode
Funcion result_dateTime <- localDateTime_truncatedToMinutes(struct_dateTime)
```

## Parámetros
- `struct_dateTime`: Objeto LocalDateTime

## Retorna
LocalDateTime truncado al minuto.
