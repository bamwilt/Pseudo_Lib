# __private_isEquals_general

**Módulo:** [BOOLEAN](..\BOOLEAN.md)

## Descripción

Generic equality comparator that checks if two values are equal using the `==` operator.

## Sintaxis
```pseudocode
Funcion boolean <- __private_isEquals_general(value1, value2)
```

## Parámetros
- `value1`: First value to compare
- `value2`: Second value to compare

## Retorna
`true` if the values are equal, `false` otherwise.
