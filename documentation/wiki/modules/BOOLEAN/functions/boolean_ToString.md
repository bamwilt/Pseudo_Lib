# boolean_ToString

**Módulo:** [BOOLEAN](..\BOOLEAN.md)

## Descripción

Converts a boolean value to its string representation.

## Sintaxis
```pseudocode
Funcion text <- boolean_ToString(boolean)
```

## Parámetros
- `boolean`: The boolean value to convert

## Retorna
`"true"` if the input is true, `"false"` otherwise.
