# dualCellsCollection_mode_add

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Agrega un par de elementos (izquierdo y derecho) usando los modos de inserción especificados para cada lado.

## Sintaxis
```
Funcion result_cells <- dualCellsCollection_mode_add(struct_cells, element_left, MODE, element_right, MODE_TWO)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `element_left`: Elemento del lado izquierdo
- `MODE`: Modo de inserción para el lado izquierdo
- `element_right`: Elemento del lado derecho
- `MODE_TWO`: Modo de inserción para el lado derecho

## Retorna
La estructura con el par agregado.
