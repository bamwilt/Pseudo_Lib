# dualCellsCollection_validateFixedLength

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Valida que la longitud de un elemento no exceda la longitud de celda definida.

## Sintaxis
```
Funcion isValidLength <- dualCellsCollection_validateFixedLength(element_string, cell_length)
```

## Parámetros
- `element_string`: Elemento a validar
- `cell_length`: Longitud máxima de celda

## Retorna
`Verdadero` si el elemento cabe en la celda, `Falso` en caso contrario.
