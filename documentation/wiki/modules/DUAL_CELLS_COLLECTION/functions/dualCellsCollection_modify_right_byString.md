# dualCellsCollection_modify_right_byString

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Modifica un elemento del lado derecho en un índice específico, calculando la posición desde el final.

## Sintaxis
```
Funcion result_cells <- dualCellsCollection_modify_right_byString(struct_cells, element_string, index)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `element_string`: Nuevo valor
- `index`: Índice a modificar

## Retorna
La estructura con el elemento modificado.
