# dualCellsCollection_getStartIndex_right

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Calcula el índice de inicio del lado derecho basado en el tamaño y la longitud de celda.

## Sintaxis
```
Funcion index_start <- dualCellsCollection_getStartIndex_right(struct_cells)
```

## Parámetros
- `struct_cells`: Estructura de colección dual

## Retorna
Índice de inicio del lado derecho.
