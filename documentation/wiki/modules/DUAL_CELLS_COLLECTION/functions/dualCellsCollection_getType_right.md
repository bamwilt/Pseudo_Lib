# dualCellsCollection_getType_right

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene el tipo de dato del lado derecho desde la estructura.

## Sintaxis
```
Funcion TYPE <- dualCellsCollection_getType_right(struct_cells)
```

## Parámetros
- `struct_cells`: Estructura de colección dual

## Retorna
Tipo del lado derecho.
