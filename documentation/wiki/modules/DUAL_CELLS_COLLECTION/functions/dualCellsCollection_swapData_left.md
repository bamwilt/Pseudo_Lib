# dualCellsCollection_swapData_left

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Intercambia dos elementos del lado izquierdo en los índices especificados (wrapper).

## Sintaxis
```
Funcion result_cells <- dualCellsCollection_swapData_left(struct_cells, index, index_swap)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `index`: Primer índice
- `index_swap`: Segundo índice

## Retorna
La estructura con los elementos intercambiados.
