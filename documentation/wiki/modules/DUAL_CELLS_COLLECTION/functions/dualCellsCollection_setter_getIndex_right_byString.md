# dualCellsCollection_setter_getIndex_right_byString

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene el índice de un string en el lado derecho, validando que la longitud no exceda el tamaño de celda.

## Sintaxis
```
Funcion index_cell <- dualCellsCollection_setter_getIndex_right_byString(struct_cells, element_string)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `element_string`: String a buscar

## Retorna
Índice del string si existe, -1 en caso contrario.
