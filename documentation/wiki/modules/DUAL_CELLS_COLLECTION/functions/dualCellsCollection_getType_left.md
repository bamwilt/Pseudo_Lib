# dualCellsCollection_getType_left

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene el tipo de dato del lado izquierdo (wrapper).

## Sintaxis
```
Funcion TYPE <- dualCellsCollection_getType_left(struct_cells)
```

## Parámetros
- `struct_cells`: Estructura de colección dual

## Retorna
Tipo del lado izquierdo.
