# dualCellsCollection_getCellPair_byLeftValue

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene el elemento del lado derecho correspondiente a un valor dado del lado izquierdo.

## Sintaxis
```
Funcion element_right <- dualCellsCollection_getCellPair_byLeftValue(struct_cells, value_left)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `value_left`: Valor del lado izquierdo a buscar

## Retorna
Valor derecho asociado, tipado según el tipo del lado derecho.
