# dualCellsCollection_getCellLength_right

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene la longitud de celda del lado derecho desde los metadatos.

## Sintaxis
```
Funcion cell_length <- dualCellsCollection_getCellLength_right(struct_cells)
```

## Parámetros
- `struct_cells`: Estructura de colección dual

## Retorna
Longitud de celda del lado derecho.
