# dualCellsCollection_getSeparateString_right

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene un string separado con los elementos del lado derecho.

## Sintaxis
```
Funcion separate_string <- dualCellsCollection_getSeparateString_right(struct_cells)
```

## Parámetros
- `struct_cells`: Estructura de colección dual

## Retorna
String con elementos separados.
