# dualCellsCollection_mode_add_byType

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Agrega un par de elementos tipados usando los modos de inserción especificados.

## Sintaxis
```
Funcion result_cells <- dualCellsCollection_mode_add_byType(struct_cells, element_left, MODE, TYPE, element_right, MODE_TWO, TYPE_TWO)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `element_left`: Elemento del lado izquierdo
- `MODE`: Modo de inserción izquierdo
- `TYPE`: Tipo del elemento izquierdo
- `element_right`: Elemento del lado derecho
- `MODE_TWO`: Modo de inserción derecho
- `TYPE_TWO`: Tipo del elemento derecho

## Retorna
La estructura con el par agregado.
