# dualCellsCollection_modify_left_byString

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Modifica un elemento del lado izquierdo en un índice específico (wrapper).

## Sintaxis
```
Funcion result_cells <- dualCellsCollection_modify_left_byString(struct_cells, element_string, index)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `element_string`: Nuevo valor
- `index`: Índice a modificar

## Retorna
La estructura con el elemento modificado.
