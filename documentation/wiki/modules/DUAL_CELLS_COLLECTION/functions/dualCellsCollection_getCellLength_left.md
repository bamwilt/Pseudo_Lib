# dualCellsCollection_getCellLength_left

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene la longitud de celda del lado izquierdo (wrapper de `cellsCollection_getCellLength`).

## Sintaxis
```
Funcion cell_length <- dualCellsCollection_getCellLength_left(struct_cells)
```

## Parámetros
- `struct_cells`: Estructura de colección dual

## Retorna
Longitud de celda del lado izquierdo.
