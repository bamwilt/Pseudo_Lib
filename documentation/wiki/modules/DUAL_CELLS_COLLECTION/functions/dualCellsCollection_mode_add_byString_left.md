# dualCellsCollection_mode_add_byString_left

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Agrega un elemento al lado izquierdo según el modo de inserción, validando la longitud si es necesario.

## Sintaxis
```
Funcion result_cells <- dualCellsCollection_mode_add_byString_left(struct_cells, element_string, MODE, index_insert)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `element_string`: Elemento a agregar
- `MODE`: Modo de inserción
- `index_insert`: Índice de inserción

## Retorna
La estructura con el elemento agregado.
