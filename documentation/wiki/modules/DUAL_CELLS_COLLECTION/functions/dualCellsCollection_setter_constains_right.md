# dualCellsCollection_setter_constains_right

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Verifica si un elemento existe en el lado derecho de la colección.

## Sintaxis
```
Funcion constains_string <- dualCellsCollection_setter_constains_right(struct_cells, element_string)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `element_string`: Elemento a buscar

## Retorna
`Verdadero` si el elemento existe, `Falso` en caso contrario.
