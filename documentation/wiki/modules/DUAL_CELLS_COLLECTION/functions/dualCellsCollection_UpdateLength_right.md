# dualCellsCollection_UpdateLength_right

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Actualiza la longitud de celda del lado derecho en la estructura.

## Sintaxis
```
Funcion result_cells <- dualCellsCollection_UpdateLength_right(struct_cells, new_fixed_Length)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `new_fixed_Length`: Nueva longitud de celda

## Retorna
La estructura actualizada con la nueva longitud.
