# dualCellsCollection_Dynamic_reSize_right

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Redimensiona todas las celdas del lado derecho a una nueva longitud.

## Sintaxis
```
Funcion result_cells <- dualCellsCollection_Dynamic_reSize_right(struct_cells, new_fixed_Length)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `new_fixed_Length`: Nueva longitud de celda

## Retorna
La estructura con las celdas del lado derecho redimensionadas.
