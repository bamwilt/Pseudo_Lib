# dualCellsCollection_setter_getIndex_right_byString_force

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene el índice de un string en el lado derecho usando índices precalculados. Normaliza el resultado invirtiendo el índice.

## Sintaxis
```
Funcion index_cell <- dualCellsCollection_setter_getIndex_right_byString_force(struct_cells, element_string, cell_length)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `element_string`: String a buscar
- `cell_length`: Longitud de celda

## Retorna
Índice normalizado del elemento.
