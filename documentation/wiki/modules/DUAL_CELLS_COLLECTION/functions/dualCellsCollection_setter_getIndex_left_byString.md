# dualCellsCollection_setter_getIndex_left_byString

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene el índice de un elemento en el lado izquierdo (wrapper).

## Sintaxis
```
Funcion index_cell <- dualCellsCollection_setter_getIndex_left_byString(struct_cells, element_string)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `element_string`: Elemento a buscar

## Retorna
Índice del elemento si existe, -1 en caso contrario.
