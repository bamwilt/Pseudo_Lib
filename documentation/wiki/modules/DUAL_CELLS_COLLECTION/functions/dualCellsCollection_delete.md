# dualCellsCollection_delete

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Elimina un elemento de ambos lados (izquierdo y derecho) en el índice especificado.

## Sintaxis
```
Funcion result_cells <- dualCellsCollection_delete(struct_cells, index)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `index`: Índice del elemento a eliminar

## Retorna
La estructura sin el elemento.
