# dualCellsCollection_add_byString_left_force

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Agrega un elemento al lado izquierdo de la colección (wrapper de `cellsCollection_add_byString_force`).

## Sintaxis
```
Funcion result_cells <- dualCellsCollection_add_byString_left_force(struct_cells, element_string, index_start, index_insert, cell_length)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `element_string`: Elemento a agregar
- `index_start`: Índice de inicio de datos
- `index_insert`: Índice de inserción
- `cell_length`: Longitud de celda

## Retorna
La estructura con el elemento agregado.
