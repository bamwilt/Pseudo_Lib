# dualCellsCollection_setter_getIndex_right

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene el índice de un valor en el lado derecho, tipando el valor a string primero.

## Sintaxis
```
Funcion index_cell <- dualCellsCollection_setter_getIndex_right(struct_cells, value_search)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `value_search`: Valor a buscar

## Retorna
Índice del valor si existe, -1 en caso contrario.
