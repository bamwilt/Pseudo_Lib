# dualCellsCollection_getCell_left_toString

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene la celda izquierda en un índice como string (wrapper).

## Sintaxis
```
Funcion element_string <- dualCellsCollection_getCell_left_toString(struct_cells, index)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `index`: Índice de la celda

## Retorna
String del contenido de la celda izquierda.
