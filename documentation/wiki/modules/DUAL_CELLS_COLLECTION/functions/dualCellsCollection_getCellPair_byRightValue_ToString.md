# dualCellsCollection_getCellPair_byRightValue_ToString

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene el elemento del lado izquierdo como string, dado un valor del lado derecho.

## Sintaxis
```
Funcion element_left <- dualCellsCollection_getCellPair_byRightValue_ToString(struct_cells, value_right)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `value_right`: Valor del lado derecho a buscar

## Retorna
String del elemento izquierdo, o `string_NULL()` si no se encuentra.
