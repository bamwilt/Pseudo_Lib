# dualCellsCollection_getEndData

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene el índice del último metadata en la estructura, que marca el fin de los datos.

## Sintaxis
```
Funcion index_endData <- dualCellsCollection_getEndData(struct_cells)
```

## Parámetros
- `struct_cells`: Estructura de colección dual

## Retorna
Índice del fin de datos.
