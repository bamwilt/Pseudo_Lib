# dualCellsCollection_Dynamic_reSize_right_force

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Redimensiona el lado derecho con índices precalculados y actualiza la longitud almacenada.

## Sintaxis
```
Funcion result_cells <- dualCellsCollection_Dynamic_reSize_right_force(struct_cells, new_fixed_Length, index_endData, cells_size, cell_length)
```

## Parámetros
- `struct_cells`: Estructura de colección dual
- `new_fixed_Length`: Nueva longitud de celda
- `index_endData`: Índice de fin de datos
- `cells_size`: Tamaño de la colección
- `cell_length`: Longitud actual de celda

## Retorna
La estructura redimensionada.
