# dualCellsCollection_getSize

**Módulo:** [DUAL_CELLS_COLLECTION](../DUAL_CELLS_COLLECTION.md)

## Descripción
Obtiene la cantidad de elementos en la colección (wrapper).

## Sintaxis
```
Funcion size_dataBlock <- dualCellsCollection_getSize(struct_cells)
```

## Parámetros
- `struct_cells`: Estructura de colección dual

## Retorna
Tamaño de la colección.
