# localTime_of_HourMinute

**Módulo:** [LOCALTIME](../LOCALTIME.md)

## Descripción
Crea un objeto LocalTime solo con hora y minutos, estableciendo los segundos a 0.

## Sintaxis
```pseudocode
Funcion LocalTime_result <- localTime_of_HourMinute(hours, minutes)
```

## Parámetros
- `hours`: Horas (0-23)
- `minutes`: Minutos (0-59)

## Retorna
Un objeto LocalTime con segundos = 0.
