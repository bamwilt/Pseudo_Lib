# localTime_truncatedToHours

**Módulo:** [LOCALTIME](../LOCALTIME.md)

## Descripción
Trunca un LocalTime a la hora, eliminando minutos y segundos (los establece a 0).

## Sintaxis
```pseudocode
Funcion struct_time <- localTime_truncatedToHours(struct_localTime)
```

## Parámetros
- `struct_localTime`: Objeto LocalTime

## Retorna
LocalTime truncado a la hora.
