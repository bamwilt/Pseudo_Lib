# localTime_getHours

**Módulo:** [LOCALTIME](../LOCALTIME.md)

## Descripción
Obtiene la hora (0-23) de un objeto LocalTime.

## Sintaxis
```pseudocode
Funcion second_ofUnit <- localTime_getHours(struct_LocalTime)
```

## Parámetros
- `struct_LocalTime`: Objeto LocalTime

## Retorna
Las horas del LocalTime.
