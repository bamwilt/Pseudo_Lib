# localTime_truncatedToMinutes

**Módulo:** [LOCALTIME](../LOCALTIME.md)

## Descripción
Trunca un LocalTime al minuto, eliminando los segundos (los establece a 0).

## Sintaxis
```pseudocode
Funcion struct_time <- localTime_truncatedToMinutes(struct_localTime)
```

## Parámetros
- `struct_localTime`: Objeto LocalTime

## Retorna
LocalTime truncado al minuto.
