# localTime_getSecondsOfDay

**Módulo:** [LOCALTIME](../LOCALTIME.md)

## Descripción
Obtiene el total de segundos transcurridos desde el inicio del día.

## Sintaxis
```pseudocode
Funcion duration_ofUnit <- localTime_getSecondsOfDay(struct_LocalTime)
```

## Parámetros
- `struct_LocalTime`: Objeto LocalTime

## Retorna
El total de segundos del día (0-86399).
