# localTime_isEquals

**Módulo:** [LOCALTIME](../LOCALTIME.md)

## Descripción
Verifica si dos LocalTime son iguales.

## Sintaxis
```pseudocode
Funcion isEqual <- localTime_isEquals(struct_LocalTime, struct_LocalTime_match)
```

## Parámetros
- `struct_LocalTime`: Primer objeto LocalTime
- `struct_LocalTime_match`: Segundo objeto LocalTime

## Retorna
`true` si son iguales, `false` en caso contrario.
