# localTime_isBefore

**Módulo:** [LOCALTIME](../LOCALTIME.md)

## Descripción
Verifica si un LocalTime es anterior a otro.

## Sintaxis
```pseudocode
Funcion isBefore <- localTime_isBefore(struct_LocalTime, struct_LocalTime_match)
```

## Parámetros
- `struct_LocalTime`: Objeto LocalTime a comparar
- `struct_LocalTime_match`: Objeto LocalTime de referencia

## Retorna
`true` si es anterior, `false` en caso contrario.
