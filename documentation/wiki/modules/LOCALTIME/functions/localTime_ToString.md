# localTime_ToString

**Módulo:** [LOCALTIME](../LOCALTIME.md)

## Descripción
Convierte un LocalTime a su representación textual en formato HH:mm:ss.

## Sintaxis
```pseudocode
Funcion Time_ToString <- localTime_ToString(struct_localTime)
```

## Parámetros
- `struct_localTime`: Objeto LocalTime

## Retorna
Texto en formato HH:mm:ss.
