# localTime_isAfter

**Módulo:** [LOCALTIME](../LOCALTIME.md)

## Descripción
Verifica si un LocalTime es posterior a otro.

## Sintaxis
```pseudocode
Funcion isAfter <- localTime_isAfter(struct_LocalTime, struct_LocalTime_match)
```

## Parámetros
- `struct_LocalTime`: Objeto LocalTime a comparar
- `struct_LocalTime_match`: Objeto LocalTime de referencia

## Retorna
`true` si es posterior, `false` en caso contrario.
