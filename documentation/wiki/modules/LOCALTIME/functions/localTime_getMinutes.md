# localTime_getMinutes

**Módulo:** [LOCALTIME](../LOCALTIME.md)

## Descripción
Obtiene los minutos (0-59) de un objeto LocalTime.

## Sintaxis
```pseudocode
Funcion second_ofUnit <- localTime_getMinutes(struct_LocalTime)
```

## Parámetros
- `struct_LocalTime`: Objeto LocalTime

## Retorna
Los minutos del LocalTime.
