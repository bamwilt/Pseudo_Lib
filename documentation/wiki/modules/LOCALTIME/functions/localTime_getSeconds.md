# localTime_getSeconds

**Módulo:** [LOCALTIME](../LOCALTIME.md)

## Descripción
Obtiene los segundos (0-59) de un objeto LocalTime.

## Sintaxis
```pseudocode
Funcion second_ofUnit <- localTime_getSeconds(struct_LocalTime)
```

## Parámetros
- `struct_LocalTime`: Objeto LocalTime

## Retorna
Los segundos del LocalTime.
