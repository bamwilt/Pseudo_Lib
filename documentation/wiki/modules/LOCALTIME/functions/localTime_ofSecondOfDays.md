# localTime_ofSecondOfDays

**Módulo:** [LOCALTIME](../LOCALTIME.md)

## Descripción
Crea un objeto LocalTime a partir de los segundos transcurridos desde el inicio del día (0-86399).

## Sintaxis
```pseudocode
Funcion LocalTime_result <- localTime_ofSecondOfDays(seconds)
```

## Parámetros
- `seconds`: Segundos totales del día

## Retorna
Un objeto LocalTime.
