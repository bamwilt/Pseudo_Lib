## tui_addTComponent_newLabel()

[~~#TUI~~](../TUI.md)

**Descripción:** Crea y añade una etiqueta nueva a la TUI.

**Sintaxis:** `tui_addTComponent_newLabel(tui, name, text, x, y)`

**Parámetros:**
- `tui` - TUI
- `name` - Nombre
- `text` - Texto de la etiqueta
- `x`, `y` - Posición

**Retorno:** Void
