## tui_addTComponent_newButton()

[~~#TUI~~](../TUI.md)

**Descripción:** Crea y añade un botón nuevo a la TUI.

**Sintaxis:** `tui_addTComponent_newButton(tui, name, text, input, x, y)`

**Parámetros:**
- `tui` - TUI
- `name` - Nombre
- `text` - Texto del botón
- `input` - Input asociado
- `x`, `y` - Posición

**Retorno:** Void
