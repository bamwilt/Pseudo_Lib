# localDate_ofDayOfYear

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Crea un LocalDate a partir del año y el día del año.

## Sintaxis

```pseudocode
Funcion Date <- localDate_ofDayOfYear(year, dayOfYear)
```

## Parámetros

- `year`: Año.
- `dayOfYear`: Día del año (1-365/366).

## Retorna

Texto con el LocalDate resultante.
