# localDate_plusWeeks

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Suma una cantidad de semanas a un LocalDate.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_plusWeeks(struct_date, plus_weeks)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `plus_weeks`: Cantidad de semanas a sumar.

## Retorna

Texto con el nuevo LocalDate.
