# __private_localDate_ofDateNull

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Función privada que crea un LocalDate nulo (todos los campos en valor nulo).

## Sintaxis

```pseudocode
Funcion date_object <- __private_localDate_ofDateNull
```

## Parámetros

Ninguno.

## Retorna

Texto con la estructura LocalDate nula.
