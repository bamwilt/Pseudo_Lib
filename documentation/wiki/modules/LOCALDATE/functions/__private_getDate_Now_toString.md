# __private_getDate_Now_toString

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Función privada que obtiene la fecha actual como texto formateado.

## Sintaxis

```pseudocode
Funcion Date_String <- __private_getDate_Now_toString
```

## Parámetros

Ninguno.

## Retorna

Texto con la fecha actual en formato "AAAAMMDD".
