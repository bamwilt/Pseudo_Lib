# __private_localDate_atTime_fromSeconds

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Función privada que crea un LocalDateTime a partir de un LocalDate y segundos del día.

## Sintaxis

```pseudocode
Funcion struct_dateTime <- __private_localDate_atTime_fromSeconds(struct_date, seconds)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `seconds`: Segundos del día.

## Retorna

Texto con la estructura LocalDateTime.
