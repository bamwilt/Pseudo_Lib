# localDate_isEqual

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Verifica si dos LocalDate son iguales.

## Sintaxis

```pseudocode
Funcion isEqual <- localDate_isEqual(struct_LocalDate, struct_LocalDate_match)
```

## Parámetros

- `struct_LocalDate`: Primera fecha.
- `struct_LocalDate_match`: Segunda fecha.

## Retorna

Verdadero si las fechas son iguales, falso en caso contrario.
