# __private_getDate_Now

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Función privada que obtiene la fecha actual del sistema en formato numérico (AAAAMMDD).

## Sintaxis

```pseudocode
Funcion Date_num <- __private_getDate_Now
```

## Parámetros

Ninguno.

## Retorna

Número entero con la fecha actual (ej. 20260407).
