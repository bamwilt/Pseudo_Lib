# localDate_isBefore

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Verifica si un LocalDate es anterior a otro.

## Sintaxis

```pseudocode
Funcion isBefore <- localDate_isBefore(struct_LocalDate, struct_LocalDate_match)
```

## Parámetros

- `struct_LocalDate`: Fecha a comparar.
- `struct_LocalDate_match`: Fecha de referencia.

## Retorna

Verdadero si la primera fecha es anterior, falso en caso contrario.
