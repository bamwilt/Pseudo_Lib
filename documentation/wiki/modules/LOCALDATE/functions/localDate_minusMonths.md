# localDate_minusMonths

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Resta una cantidad de meses a un LocalDate.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_minusMonths(struct_date, minus_month)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `minus_month`: Cantidad de meses a restar.

## Retorna

Texto con el nuevo LocalDate.
