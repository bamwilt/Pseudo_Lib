# localDate_atStartOfDay

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Combina un LocalDate con la medianoche (00:00:00) para crear un LocalDateTime.

## Sintaxis

```pseudocode
Funcion struct_dateTime <- localDate_atStartOfDay(struct_date)
```

## Parámetros

- `struct_date`: Estructura LocalDate.

## Retorna

Texto con la estructura LocalDateTime.
