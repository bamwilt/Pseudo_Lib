# localDate_minusYears

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Resta una cantidad de años a un LocalDate.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_minusYears(struct_date, minus_years)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `minus_years`: Cantidad de años a restar.

## Retorna

Texto con el nuevo LocalDate.
