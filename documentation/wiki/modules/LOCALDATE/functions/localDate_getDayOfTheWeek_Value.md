# localDate_getDayOfTheWeek_Value

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Obtiene el valor numérico del día de la semana (1=Lunes, 7=Domingo).

## Sintaxis

```pseudocode
Funcion day_value <- localDate_getDayOfTheWeek_Value(struct_date)
```

## Parámetros

- `struct_date`: Estructura LocalDate.

## Retorna

Número entero con el día de la semana.
