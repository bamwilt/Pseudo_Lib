# __private_localDate_getDaysFromYears

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Función privada que calcula los días transcurridos desde el año 0 hasta el año especificado, considerando años bisiestos.

## Sintaxis

```pseudocode
Funcion total_days_years <- __private_localDate_getDaysFromYears(year_int)
```

## Parámetros

- `year_int`: Año.

## Retorna

Número real con los días transcurridos.
