# localDate_of

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Crea un LocalDate validando año, mes y día.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_of(year, month, day)
```

## Parámetros

- `year`: Año.
- `month`: Mes (1-12).
- `day`: Día del mes.

## Retorna

Texto con la estructura LocalDate. Retorna fecha nula si la fecha no es válida.
