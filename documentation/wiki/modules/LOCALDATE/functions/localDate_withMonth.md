# localDate_withMonth

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Cambia el mes de un LocalDate, manteniendo el año y día.

## Sintaxis

```pseudocode
Funcion date_with <- localDate_withMonth(struct_date, month_int)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `month_int`: Nuevo mes (1-12).

## Retorna

Texto con el LocalDate modificado.
