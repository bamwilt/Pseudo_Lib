# localDate_plus

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Suma una cantidad a un LocalDate en una unidad temporal específica.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_plus(struct_date, num_plus, temporal_unit)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `num_plus`: Cantidad a sumar.
- `temporal_unit`: Unidad temporal (YEARS, MONTHS, WEEKS, DAYS).

## Retorna

Texto con el nuevo LocalDate.
