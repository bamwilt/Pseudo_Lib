# localDate_withDayOfYear

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Cambia el día del año de un LocalDate.

## Sintaxis

```pseudocode
Funcion date_with <- localDate_withDayOfYear(struct_date, dayOfYear)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `dayOfYear`: Nuevo día del año.

## Retorna

Texto con el LocalDate modificado.
