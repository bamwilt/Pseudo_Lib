# localDate_lengthOfYear

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Obtiene la cantidad de días del año de un LocalDate (365 o 366).

## Sintaxis

```pseudocode
Funcion lengthOfYear <- localDate_lengthOfYear(struct_date)
```

## Parámetros

- `struct_date`: Estructura LocalDate.

## Retorna

Número entero con la cantidad de días del año.
