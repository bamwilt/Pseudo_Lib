# localDate_getDayOfMonth

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Obtiene el día del mes de un LocalDate.

## Sintaxis

```pseudocode
Funcion day_int <- localDate_getDayOfMonth(struct_date)
```

## Parámetros

- `struct_date`: Estructura LocalDate.

## Retorna

Número entero con el día del mes.
