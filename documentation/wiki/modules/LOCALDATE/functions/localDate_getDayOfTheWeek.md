# localDate_getDayOfTheWeek

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Obtiene el nombre del día de la semana de un LocalDate.

## Sintaxis

```pseudocode
Funcion day_name <- localDate_getDayOfTheWeek(struct_date)
```

## Parámetros

- `struct_date`: Estructura LocalDate.

## Retorna

Texto con el nombre del día en inglés.
