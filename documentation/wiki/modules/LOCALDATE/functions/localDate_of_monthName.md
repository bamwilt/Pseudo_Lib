# localDate_of_monthName

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Crea un LocalDate usando el nombre del mes en lugar del número.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_of_monthName(year, MONTH_NAME, day)
```

## Parámetros

- `year`: Año.
- `MONTH_NAME`: Nombre del mes en inglés (ej. "JANUARY").
- `day`: Día del mes.

## Retorna

Texto con la estructura LocalDate.
