# localDate_format

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Formatea un LocalDate a partir de un patrón de texto. Reemplaza 'Y' por el año, 'M' por el mes y 'D' por el día.

## Sintaxis

```pseudocode
Funcion Date <- localDate_format(text)
```

## Parámetros

- `text`: Patrón de formato (ej. "Y-M-D").

## Retorna

Texto con la fecha formateada según el patrón.
