# localDate_minusDays

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Resta una cantidad de días a un LocalDate.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_minusDays(struct_date, minus_days)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `minus_days`: Cantidad de días a restar.

## Retorna

Texto con el nuevo LocalDate.
