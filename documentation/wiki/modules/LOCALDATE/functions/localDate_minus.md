# localDate_minus

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Resta una cantidad a un LocalDate en una unidad temporal específica.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_minus(struct_date, num_minus, temporal_unit)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `num_minus`: Cantidad a restar.
- `temporal_unit`: Unidad temporal (YEARS, MONTHS, WEEKS, DAYS).

## Retorna

Texto con el nuevo LocalDate.
