# localDate_withYear

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Cambia el año de un LocalDate.

## Sintaxis

```pseudocode
Funcion date_with <- localDate_withYear(struct_date, year_int)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `year_int`: Nuevo año.

## Retorna

Texto con el LocalDate modificado.
