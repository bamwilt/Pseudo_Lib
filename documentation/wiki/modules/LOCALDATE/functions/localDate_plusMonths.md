# localDate_plusMonths

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Suma una cantidad de meses a un LocalDate.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_plusMonths(struct_date, plus_months)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `plus_months`: Cantidad de meses a sumar.

## Retorna

Texto con el nuevo LocalDate.
