# localDate_getMonth

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Obtiene el nombre del mes de un LocalDate.

## Sintaxis

```pseudocode
Funcion month_name <- localDate_getMonth(struct_date)
```

## Parámetros

- `struct_date`: Estructura LocalDate.

## Retorna

Texto con el nombre del mes en inglés.
