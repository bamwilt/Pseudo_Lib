# localDate_plusYears

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Suma una cantidad de años a un LocalDate.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_plusYears(struct_date, plus_years)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `plus_years`: Cantidad de años a sumar.

## Retorna

Texto con el nuevo LocalDate.
