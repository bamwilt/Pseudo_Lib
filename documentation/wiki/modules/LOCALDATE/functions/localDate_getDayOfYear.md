# localDate_getDayOfYear

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Calcula el día del año (1-365/366) para una fecha dada.

## Sintaxis

```pseudocode
Funcion numDay <- localDate_getDayOfYear(year, month, day)
```

## Parámetros

- `year`: Año.
- `month`: Mes.
- `day`: Día.

## Retorna

Número entero con el día del año.
