# __private_localDate_getMonthFromDays

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Función privada que obtiene el mes correspondiente a partir de días acumulados del año.

## Sintaxis

```pseudocode
Funcion month_total <- __private_localDate_getMonthFromDays(year, days)
```

## Parámetros

- `year`: Año.
- `days`: Días acumulados.

## Retorna

Número entero con el mes (1-12).
