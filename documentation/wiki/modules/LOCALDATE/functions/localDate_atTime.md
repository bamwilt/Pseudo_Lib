# localDate_atTime

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Combina un LocalDate con hora, minuto y segundo para crear un LocalDateTime.

## Sintaxis

```pseudocode
Funcion struct_dateTime <- localDate_atTime(struct_date, hour, minute, second)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `hour`: Hora.
- `minute`: Minuto.
- `second`: Segundo.

## Retorna

Texto con la estructura LocalDateTime.
