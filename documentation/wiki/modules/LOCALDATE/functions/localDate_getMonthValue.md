# localDate_getMonthValue

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Obtiene el mes de un LocalDate como número.

## Sintaxis

```pseudocode
Funcion month_int <- localDate_getMonthValue(struct_date)
```

## Parámetros

- `struct_date`: Estructura LocalDate.

## Retorna

Número entero con el mes (1-12).
