# localDate_toEpochDay

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Convierte un LocalDate al número de días desde la epoch (1970-01-01).

## Sintaxis

```pseudocode
Funcion epoch_days_result <- localDate_toEpochDay(struct_date)
```

## Parámetros

- `struct_date`: Estructura LocalDate.

## Retorna

Número entero con los días desde la epoch.
