# localDate_until_Days

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Calcula la cantidad de días entre dos fechas.

## Sintaxis

```pseudocode
Funcion total <- localDate_until_Days(struct_date_start, struct_date_end)
```

## Parámetros

- `struct_date_start`: Fecha de inicio.
- `struct_date_end`: Fecha de fin.

## Retorna

Número entero con los días de diferencia.
