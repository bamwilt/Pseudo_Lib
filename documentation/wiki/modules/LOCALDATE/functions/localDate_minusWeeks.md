# localDate_minusWeeks

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Resta una cantidad de semanas a un LocalDate.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_minusWeeks(struct_date, minus_weeks)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `minus_weeks`: Cantidad de semanas a restar.

## Retorna

Texto con el nuevo LocalDate.
