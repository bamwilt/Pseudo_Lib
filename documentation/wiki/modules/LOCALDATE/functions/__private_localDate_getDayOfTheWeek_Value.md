# __private_localDate_getDayOfTheWeek_Value

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Función privada que calcula el valor del día de la semana usando el algoritmo de congruencia.

## Sintaxis

```pseudocode
Funcion numDay <- __private_localDate_getDayOfTheWeek_Value(year, month, day)
```

## Parámetros

- `year`: Año.
- `month`: Mes.
- `day`: Día.

## Retorna

Número entero con el día de la semana (1-7).
