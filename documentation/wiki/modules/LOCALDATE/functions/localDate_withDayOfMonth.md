# localDate_withDayOfMonth

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Cambia el día del mes de un LocalDate.

## Sintaxis

```pseudocode
Funcion date_with <- localDate_withDayOfMonth(struct_date, day_int)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `day_int`: Nuevo día del mes.

## Retorna

Texto con el LocalDate modificado.
