# __private_localDate_getDateUnixEpoch

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Función privada que obtiene la fecha correspondiente a la epoch Unix (1970-01-01).

## Sintaxis

```pseudocode
Funcion date_object <- __private_localDate_getDateUnixEpoch
```

## Parámetros

Ninguno.

## Retorna

Texto con la estructura LocalDate del 1 de enero de 1970.
