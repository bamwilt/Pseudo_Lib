# localDate_atTime_HourMinute

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Combina un LocalDate con hora y minuto (segundos=0) para crear un LocalDateTime.

## Sintaxis

```pseudocode
Funcion struct_dateTime <- localDate_atTime_HourMinute(struct_date, hour, minute)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `hour`: Hora.
- `minute`: Minuto.

## Retorna

Texto con la estructura LocalDateTime.
