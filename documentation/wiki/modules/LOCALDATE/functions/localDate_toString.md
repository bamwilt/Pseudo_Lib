# localDate_toString

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Convierte un LocalDate a su representación en texto con formato AAAA-MM-DD.

## Sintaxis

```pseudocode
Funcion date_string <- localDate_toString(struct_date)
```

## Parámetros

- `struct_date`: Estructura LocalDate.

## Retorna

Texto con la fecha en formato "AAAA-MM-DD".
