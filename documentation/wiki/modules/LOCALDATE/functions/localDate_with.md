# localDate_with

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Cambia un campo específico de un LocalDate según la unidad temporal indicada.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_with(struct_date, new_value, temporal_unit)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `new_value`: Nuevo valor para el campo.
- `temporal_unit`: Unidad temporal a modificar (YEARS, MONTHS, DAYS).

## Retorna

Texto con el LocalDate modificado.
