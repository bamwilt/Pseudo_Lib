# localDate_plusDays

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Suma una cantidad de días a un LocalDate.

## Sintaxis

```pseudocode
Funcion date_object <- localDate_plusDays(struct_date, plus_days)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `plus_days`: Cantidad de días a sumar.

## Retorna

Texto con el nuevo LocalDate.
