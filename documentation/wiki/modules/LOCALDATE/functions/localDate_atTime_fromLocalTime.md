# localDate_atTime_fromLocalTime

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Combina un LocalDate con un LocalTime para crear un LocalDateTime.

## Sintaxis

```pseudocode
Funcion struct_dateTime <- localDate_atTime_fromLocalTime(struct_date, struct_time)
```

## Parámetros

- `struct_date`: Estructura LocalDate.
- `struct_time`: Estructura LocalTime.

## Retorna

Texto con la estructura LocalDateTime.
