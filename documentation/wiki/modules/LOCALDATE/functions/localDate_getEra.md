# localDate_getEra

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Obtiene la era de un LocalDate (CE para años >= 1, BCE en caso contrario).

## Sintaxis

```pseudocode
Funcion era_result <- localDate_getEra(struct_date)
```

## Parámetros

- `struct_date`: Estructura LocalDate.

## Retorna

Texto "CE" o "BCE".
