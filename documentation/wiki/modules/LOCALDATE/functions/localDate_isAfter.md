# localDate_isAfter

**Módulo:** [LOCALDATE](../LOCALDATE.md)

## Descripción

Verifica si un LocalDate es posterior a otro.

## Sintaxis

```pseudocode
Funcion isAfter <- localDate_isAfter(struct_LocalDate, struct_LocalDate_match)
```

## Parámetros

- `struct_LocalDate`: Fecha a comparar.
- `struct_LocalDate_match`: Fecha de referencia.

## Retorna

Verdadero si la primera fecha es posterior, falso en caso contrario.
