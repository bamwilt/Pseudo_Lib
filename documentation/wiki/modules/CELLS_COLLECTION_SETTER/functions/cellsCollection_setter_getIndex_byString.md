# cellsCollection_setter_getIndex_byString

**Módulo:** [CELLS_COLLECTION_SETTER](../CELLS_COLLECTION_SETTER.md)

## Descripción
Obtiene el índice de un string dentro de la colección, buscando en todos los elementos.

## Sintaxis
```
index_cell <- cellsCollection_setter_getIndex_byString(struct_cells, element_string)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element_string`: Texto con el valor a buscar

## Retorna
Número con el índice del elemento, o -1 si no se encuentra.
