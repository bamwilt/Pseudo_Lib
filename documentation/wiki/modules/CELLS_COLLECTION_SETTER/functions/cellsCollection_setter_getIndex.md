# cellsCollection_setter_getIndex

**Módulo:** [CELLS_COLLECTION_SETTER](../CELLS_COLLECTION_SETTER.md)

## Descripción
Obtiene el índice de un valor dentro de la colección, detectando automáticamente el tipo.

## Sintaxis
```
index_cell <- cellsCollection_setter_getIndex(struct_cells, value_search)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `value_search`: Valor a buscar

## Retorna
Número con el índice del elemento, o -1 si no se encuentra.
