# cellsCollection_Setter_add

**Módulo:** [CELLS_COLLECTION_SETTER](../CELLS_COLLECTION_SETTER.md)

## Descripción
Añade un elemento a la colección solo si no existe previamente, comportándose como un conjunto (set).

## Sintaxis
```
result_cells <- cellsCollection_Setter_add(struct_cells, element)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element`: Elemento a añadir

## Retorna
Texto con la estructura modificada o la original si el elemento ya existe.
