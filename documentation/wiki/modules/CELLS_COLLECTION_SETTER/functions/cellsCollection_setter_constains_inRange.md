# cellsCollection_setter_constains_inRange

**Módulo:** [CELLS_COLLECTION_SETTER](../CELLS_COLLECTION_SETTER.md)

## Descripción
Verifica si un string existe dentro de un rango específico de índices.

## Sintaxis
```
constains_string <- cellsCollection_setter_constains_inRange(struct_cells, element_string, index_start, index_end)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element_string`: Texto con el valor a buscar
- `index_start`: Número con el índice inicial del rango
- `index_end`: Número con el índice final del rango

## Retorna
Lógico: verdadero si el elemento existe en el rango.
