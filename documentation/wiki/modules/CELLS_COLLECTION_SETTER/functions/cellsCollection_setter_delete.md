# cellsCollection_setter_delete

**Módulo:** [CELLS_COLLECTION_SETTER](../CELLS_COLLECTION_SETTER.md)

## Descripción
Elimina un valor específico de la colección, buscándolo por su tipo.

## Sintaxis
```
result_cells <- cellsCollection_setter_delete(struct_cells, value)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `value`: Valor a eliminar

## Retorna
Texto con la estructura sin el elemento eliminado.
