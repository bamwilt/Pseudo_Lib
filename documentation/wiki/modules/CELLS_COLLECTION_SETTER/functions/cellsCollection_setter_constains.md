# cellsCollection_setter_constains

**Módulo:** [CELLS_COLLECTION_SETTER](../CELLS_COLLECTION_SETTER.md)

## Descripción
Verifica si un string existe dentro de la colección.

## Sintaxis
```
constains_string <- cellsCollection_setter_constains(struct_cells, element_string)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element_string`: Texto con el valor a buscar

## Retorna
Lógico: verdadero si el elemento existe.
