# cellsCollection_Setter_add_byType

**Módulo:** [CELLS_COLLECTION_SETTER](../CELLS_COLLECTION_SETTER.md)

## Descripción
Añade un elemento tipado a la colección solo si no existe.

## Sintaxis
```
result_cells <- cellsCollection_Setter_add_byType(struct_cells, element, TYPE)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element`: Elemento a añadir
- `TYPE`: Texto con el tipo del elemento

## Retorna
Texto con la estructura modificada o la original si ya existe.
