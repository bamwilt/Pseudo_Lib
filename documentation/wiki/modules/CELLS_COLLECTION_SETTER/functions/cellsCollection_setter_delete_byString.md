# cellsCollection_setter_delete_byString

**Módulo:** [CELLS_COLLECTION_SETTER](../CELLS_COLLECTION_SETTER.md)

## Descripción
Elimina un valor string específico de la colección, buscando su índice y eliminándolo si existe.

## Sintaxis
```
result_cells <- cellsCollection_setter_delete_byString(struct_cells, value_string)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `value_string`: Texto con el valor a eliminar

## Retorna
Texto con la estructura sin el elemento eliminado.
