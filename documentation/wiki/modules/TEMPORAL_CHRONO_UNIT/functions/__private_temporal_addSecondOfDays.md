# __private_temporal_addSecondOfDays

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Función privada que agrega segundos a una estructura de tiempo.

## Sintaxis

```pseudocode
Funcion time_result <- __private_temporal_addSecondOfDays(struct_time, seconds)
```

## Parámetros

- `struct_time`: Estructura de tiempo.
- `seconds`: Segundos a agregar.

## Retorna

Texto con la estructura de tiempo actualizada.
