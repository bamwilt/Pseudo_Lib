# temporal_with

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Establece un campo específico de una estructura temporal a un nuevo valor.

## Sintaxis

```pseudocode
Funcion struct_time <- temporal_with(struct_temporal, num_define, type_temporal)
```

## Parámetros

- `struct_temporal`: Estructura temporal.
- `num_define`: Nuevo valor para el campo.
- `type_temporal`: Tipo de unidad temporal a modificar.

## Retorna

Texto con la estructura temporal modificada.
