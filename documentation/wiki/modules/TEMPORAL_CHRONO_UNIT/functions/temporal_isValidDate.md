# temporal_isValidDate

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Valida si una fecha completa (año, mes, día) es válida.

## Sintaxis

```pseudocode
Funcion isValid <- temporal_isValidDate(year, month, day)
```

## Parámetros

- `year`: Año.
- `month`: Mes (1-12).
- `day`: Día (1-31 según el mes).

## Retorna

Verdadero si la fecha es válida, falso en caso contrario.
