# temporal_PlusSeconds

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Suma una cantidad específica de segundos a una estructura temporal.

## Sintaxis

```pseudocode
Funcion struct_temporal_result <- temporal_PlusSeconds(struct_temporal, num_increment)
```

## Parámetros

- `struct_temporal`: Estructura temporal.
- `num_increment`: Cantidad de segundos a sumar.

## Retorna

Texto con la estructura temporal resultante.
