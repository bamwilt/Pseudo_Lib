# duration_minutesToSeconds

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Convierte minutos a segundos.

## Sintaxis

```pseudocode
Funcion second_ofUnit <- duration_minutesToSeconds(unit_second)
```

## Parámetros

- `unit_second`: Cantidad de minutos.

## Retorna

Número real con los segundos equivalentes.
