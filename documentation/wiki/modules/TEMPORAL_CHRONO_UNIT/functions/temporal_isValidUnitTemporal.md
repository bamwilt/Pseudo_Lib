# temporal_isValidUnitTemporal

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Valida si un valor de unidad temporal es válido para el tipo especificado.

## Sintaxis

```pseudocode
Funcion isValidUnitTemporal <- temporal_isValidUnitTemporal(unit_temporal, type_temporal)
```

## Parámetros

- `unit_temporal`: Valor de la unidad a validar.
- `type_temporal`: Tipo de unidad temporal.

## Retorna

Verdadero si el valor es válido, falso en caso contrario.
