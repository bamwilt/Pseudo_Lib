# duration_secondsToTemporalUnitPart

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Obtiene la parte correspondiente de una unidad temporal a partir de segundos totales. Aplica módulo para obtener la porción dentro del rango de la unidad.

## Sintaxis

```pseudocode
Funcion second_UnitTemp <- duration_secondsToTemporalUnitPart(unit_second, Temporal_Type)
```

## Parámetros

- `unit_second`: Segundos totales.
- `Temporal_Type`: Tipo de unidad temporal destino.

## Retorna

Número real con la parte de la unidad.
