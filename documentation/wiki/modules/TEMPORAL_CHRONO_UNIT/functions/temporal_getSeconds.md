# temporal_getSeconds

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Obtiene la cantidad de segundos almacenada en una estructura temporal.

## Sintaxis

```pseudocode
Funcion seconds <- temporal_getSeconds(struct_temporal)
```

## Parámetros

- `struct_temporal`: Estructura temporal (Texto).

## Retorna

Número real con los segundos.
