# duration_secondsToTemporalUnit

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Convierte una cantidad de segundos a una unidad temporal específica.

## Sintaxis

```pseudocode
Funcion second_UnitTemp <- duration_secondsToTemporalUnit(unit_second, Temporal_Type)
```

## Parámetros

- `unit_second`: Segundos a convertir.
- `Temporal_Type`: Tipo de unidad temporal destino.

## Retorna

Número real con la cantidad convertida.
