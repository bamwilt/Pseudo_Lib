# __private_temporalTime_setTimeNull

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Función privada que establece un tiempo como nulo.

## Sintaxis

```pseudocode
Funcion LocalTime_result <- __private_temporalTime_setTimeNull(struct_time)
```

## Parámetros

- `struct_time`: Estructura de tiempo.

## Retorna

Texto con la estructura de tiempo nula.
