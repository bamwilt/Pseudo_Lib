# __private_temporalDate_set

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Función privada que establece año, mes y día en una estructura de fecha.

## Sintaxis

```pseudocode
Funcion date_object <- __private_temporalDate_set(struct_date, year, month, day)
```

## Parámetros

- `struct_date`: Estructura de fecha.
- `year`: Año a establecer.
- `month`: Mes a establecer.
- `day`: Día a establecer.

## Retorna

Texto con la estructura de fecha actualizada.
