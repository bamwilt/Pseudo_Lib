# chronoUnit_isSupportedTo

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Verifica si una unidad cronológica es soportada por una estructura temporal específica.

## Sintaxis

```pseudocode
Funcion isSupported <- chronoUnit_isSupportedTo(struct_temporal, chronoUnit_type)
```

## Parámetros

- `struct_temporal`: Estructura temporal a consultar (Texto).
- `chronoUnit_type`: Tipo de unidad cronológica.

## Retorna

Verdadero si la unidad es soportada, falso en caso contrario.
