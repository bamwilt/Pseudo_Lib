# temporal_isValidHours

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Valida si un valor de horas está dentro del rango (0-23).

## Sintaxis

```pseudocode
Funcion isValid <- temporal_isValidHours(hours)
```

## Parámetros

- `hours`: Horas a validar.

## Retorna

Verdadero si las horas son válidas, falso en caso contrario.
