# temporal_isValidMonth

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Valida si un mes está dentro del rango válido (1-12).

## Sintaxis

```pseudocode
Funcion isValid <- temporal_isValidMonth(month)
```

## Parámetros

- `month`: Mes a validar.

## Retorna

Verdadero si el mes es válido, falso en caso contrario.
