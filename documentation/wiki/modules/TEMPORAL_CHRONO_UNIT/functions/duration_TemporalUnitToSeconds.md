# duration_TemporalUnitToSeconds

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Convierte una cantidad en una unidad temporal específica a segundos.

## Sintaxis

```pseudocode
Funcion second_ofUnit <- duration_TemporalUnitToSeconds(unit_seconds, Temporal_Type)
```

## Parámetros

- `unit_seconds`: Cantidad en la unidad origen.
- `Temporal_Type`: Tipo de unidad temporal (días, horas, minutos, segundos).

## Retorna

Número real con los segundos equivalentes.
