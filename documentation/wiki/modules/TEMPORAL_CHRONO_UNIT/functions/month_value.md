# month_value

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Obtiene el número del mes a partir de su nombre.

## Sintaxis

```pseudocode
Funcion value <- month_value(name_month)
```

## Parámetros

- `name_month`: Nombre del mes en inglés.

## Retorna

Número entero del mes (1-12).
