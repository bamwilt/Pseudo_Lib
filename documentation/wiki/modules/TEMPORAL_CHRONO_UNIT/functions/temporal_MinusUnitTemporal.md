# temporal_MinusUnitTemporal

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Resta una cantidad en una unidad temporal específica a una estructura temporal.

## Sintaxis

```pseudocode
Funcion struct_temporal_result <- temporal_MinusUnitTemporal(struct_temporal, num_decrement, Temporal_Type)
```

## Parámetros

- `struct_temporal`: Estructura temporal.
- `num_decrement`: Cantidad a restar.
- `Temporal_Type`: Tipo de unidad temporal.

## Retorna

Texto con la estructura temporal resultante.
