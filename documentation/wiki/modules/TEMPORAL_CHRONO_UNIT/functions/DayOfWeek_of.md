# DayOfWeek_of

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Obtiene el nombre del día de la semana a partir de su número (1-7).

## Sintaxis

```pseudocode
Funcion day_name <- DayOfWeek_of(number_day)
```

## Parámetros

- `number_day`: Número del día (1=Lunes, 7=Domingo).

## Retorna

Texto con el nombre del día en inglés.
