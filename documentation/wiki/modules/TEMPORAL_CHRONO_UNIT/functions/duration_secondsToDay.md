# duration_secondsToDay

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Convierte segundos a días.

## Sintaxis

```pseudocode
Funcion unit_Res <- duration_secondsToDay(unit_second)
```

## Parámetros

- `unit_second`: Segundos a convertir.

## Retorna

Número real con los días equivalentes.
