# temporal_PlusUnitTemporal

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Suma una cantidad en una unidad temporal específica a una estructura temporal.

## Sintaxis

```pseudocode
Funcion struct_temporal_result <- temporal_PlusUnitTemporal(struct_temporal, num_increment, Temporal_Type)
```

## Parámetros

- `struct_temporal`: Estructura temporal.
- `num_increment`: Cantidad a sumar.
- `Temporal_Type`: Tipo de unidad temporal.

## Retorna

Texto con la estructura temporal resultante.
