# __private_temporal_setSecondOfDays

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Función privada que establece los segundos en una estructura de tiempo.

## Sintaxis

```pseudocode
Funcion time_result <- __private_temporal_setSecondOfDays(struct_time, seconds)
```

## Parámetros

- `struct_time`: Estructura de tiempo.
- `seconds`: Nuevos segundos.

## Retorna

Texto con la estructura de tiempo actualizada.
