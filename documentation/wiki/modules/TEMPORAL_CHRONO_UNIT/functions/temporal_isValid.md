# temporal_isValid

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Valida si una hora completa (horas, minutos, segundos) es válida.

## Sintaxis

```pseudocode
Funcion isValid <- temporal_isValid(hours, minutes, seconds)
```

## Parámetros

- `hours`: Horas.
- `minutes`: Minutos.
- `seconds`: Segundos.

## Retorna

Verdadero si la hora es válida, falso en caso contrario.
