# month_of

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Obtiene el nombre del mes a partir de su número (1-12).

## Sintaxis

```pseudocode
Funcion month_name <- month_of(number_month)
```

## Parámetros

- `number_month`: Número del mes (1-12).

## Retorna

Texto con el nombre del mes en inglés.
