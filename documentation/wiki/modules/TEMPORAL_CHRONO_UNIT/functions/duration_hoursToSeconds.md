# duration_hoursToSeconds

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Convierte horas a segundos.

## Sintaxis

```pseudocode
Funcion second_ofUnit <- duration_hoursToSeconds(unit_second)
```

## Parámetros

- `unit_second`: Cantidad de horas.

## Retorna

Número real con los segundos equivalentes.
