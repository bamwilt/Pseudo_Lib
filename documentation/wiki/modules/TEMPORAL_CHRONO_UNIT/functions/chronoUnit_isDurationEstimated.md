# chronoUnit_isDurationEstimated

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Verifica si la duración de la unidad cronológica es estimada (días, semanas, meses, años, décadas).

## Sintaxis

```pseudocode
Funcion isEstimated <- chronoUnit_isDurationEstimated(chronoUnit_type)
```

## Parámetros

- `chronoUnit_type`: Tipo de unidad cronológica.

## Retorna

Verdadero si la duración es estimada, falso en caso contrario.
