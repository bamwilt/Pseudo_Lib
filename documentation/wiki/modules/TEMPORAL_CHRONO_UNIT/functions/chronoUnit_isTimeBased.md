# chronoUnit_isTimeBased

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Verifica si la unidad cronológica está basada en tiempo (segundos, minutos, horas).

## Sintaxis

```pseudocode
Funcion isTimeBased <- chronoUnit_isTimeBased(chronoUnit_type)
```

## Parámetros

- `chronoUnit_type`: Tipo de unidad cronológica.

## Retorna

Verdadero si la unidad es basada en tiempo, falso en caso contrario.
