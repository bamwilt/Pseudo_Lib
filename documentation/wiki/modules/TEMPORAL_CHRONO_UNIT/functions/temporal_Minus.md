# temporal_Minus

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Resta dos estructuras temporales.

## Sintaxis

```pseudocode
Funcion struct_temporal_result <- temporal_Minus(struct_temporal, struct_temporal_minus)
```

## Parámetros

- `struct_temporal`: Primera estructura temporal.
- `struct_temporal_minus`: Segunda estructura temporal a restar.

## Retorna

Texto con la estructura temporal resultante.
