# temporal_daysToSecond

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Convierte una cantidad de días a segundos.

## Sintaxis

```pseudocode
Funcion second_ofUnit <- temporal_daysToSecond(unit_second)
```

## Parámetros

- `unit_second`: Cantidad de días.

## Retorna

Número real con los segundos equivalentes.
