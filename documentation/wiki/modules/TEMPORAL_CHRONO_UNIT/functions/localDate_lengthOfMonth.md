# localDate_lengthOfMonth

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Obtiene la cantidad de días de un mes específico considerando año bisiesto.

## Sintaxis

```pseudocode
Funcion days <- localDate_lengthOfMonth(year, month)
```

## Parámetros

- `year`: Año.
- `month`: Mes (1-12).

## Retorna

Número entero con la cantidad de días del mes.
