# __private_temporalDate_add

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Función privada que agrega año, mes y día a una estructura de fecha.

## Sintaxis

```pseudocode
Funcion date_object <- __private_temporalDate_add(struct_date, year, month, day)
```

## Parámetros

- `struct_date`: Estructura de fecha base.
- `year`: Año a agregar.
- `month`: Mes a agregar.
- `day`: Día a agregar.

## Retorna

Texto con la estructura de fecha actualizada.
