# duration_secondsToHours

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Convierte segundos a horas.

## Sintaxis

```pseudocode
Funcion unit_Res <- duration_secondsToHours(unit_second)
```

## Parámetros

- `unit_second`: Segundos a convertir.

## Retorna

Número real con las horas equivalentes.
