# __private_temporalDate_setDateNull

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Función privada que establece una fecha como nula (todos los campos en 0).

## Sintaxis

```pseudocode
Funcion date_object <- __private_temporalDate_setDateNull(struct_date)
```

## Parámetros

- `struct_date`: Estructura de fecha.

## Retorna

Texto con la estructura de fecha nula.
