# temporal_PlusNumber

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Suma un número de segundos directamente a una estructura temporal.

## Sintaxis

```pseudocode
Funcion struct_temporal_result <- temporal_PlusNumber(struct_temporal, number_plus)
```

## Parámetros

- `struct_temporal`: Estructura temporal.
- `number_plus`: Número de segundos a sumar.

## Retorna

Texto con la estructura temporal resultante.
