# chronoUnit_isDateBased

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Verifica si la unidad cronológica está basada en fecha (días, semanas, meses, años, décadas).

## Sintaxis

```pseudocode
Funcion isDateBased <- chronoUnit_isDateBased(chronoUnit_type)
```

## Parámetros

- `chronoUnit_type`: Tipo de unidad cronológica.

## Retorna

Verdadero si la unidad es basada en fecha, falso en caso contrario.
