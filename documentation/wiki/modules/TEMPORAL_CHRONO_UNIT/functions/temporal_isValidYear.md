# temporal_isValidYear

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Valida si un año está dentro del rango permitido (-999999999 a 999999999).

## Sintaxis

```pseudocode
Funcion isValid <- temporal_isValidYear(year)
```

## Parámetros

- `year`: Año a validar.

## Retorna

Verdadero si el año es válido, falso en caso contrario.
