# temporal_isValidMinutes

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Valida si un valor de minutos está dentro del rango (0-59).

## Sintaxis

```pseudocode
Funcion isValid <- temporal_isValidMinutes(minutes)
```

## Parámetros

- `minutes`: Minutos a validar.

## Retorna

Verdadero si los minutos son válidos, falso en caso contrario.
