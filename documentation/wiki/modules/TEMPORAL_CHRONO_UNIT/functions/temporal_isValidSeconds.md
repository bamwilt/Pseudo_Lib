# temporal_isValidSeconds

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Valida si un valor de segundos está dentro del rango (0-59).

## Sintaxis

```pseudocode
Funcion isValid <- temporal_isValidSeconds(seconds)
```

## Parámetros

- `seconds`: Segundos a validar.

## Retorna

Verdadero si los segundos son válidos, falso en caso contrario.
