# duration_secondsToMinutes

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Convierte segundos a minutos.

## Sintaxis

```pseudocode
Funcion unit_Res <- duration_secondsToMinutes(unit_second)
```

## Parámetros

- `unit_second`: Segundos a convertir.

## Retorna

Número real con los minutos equivalentes.
