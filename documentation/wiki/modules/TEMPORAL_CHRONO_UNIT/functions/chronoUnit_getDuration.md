# chronoUnit_getDuration

**Módulo:** [TEMPORAL_CHRONO_UNIT](../TEMPORAL_CHRONO_UNIT.md)

## Descripción

Obtiene la duración en segundos de una unidad cronológica.

## Sintaxis

```pseudocode
Funcion second_units <- chronoUnit_getDuration(chronoUnit_type)
```

## Parámetros

- `chronoUnit_type`: Tipo de unidad cronológica.

## Retorna

Número entero con la cantidad de segundos.
