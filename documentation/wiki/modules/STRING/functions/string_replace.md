# string_replace

**Módulo:** [STRING](../STRING.md)

## Descripción

Reemplaza todas las ocurrencias de un texto por otro.

## Sintaxis

```pseudocode
Funcion Texto <- string_replace(text, text_match, text_Replace)
```

## Parámetros

- `text`: Texto base

- `text_match`: Texto a buscar

- `text_Replace`: Texto de reemplazo

## Retorna

Texto
