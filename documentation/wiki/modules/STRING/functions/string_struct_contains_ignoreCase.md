# string_struct_contains_ignoreCase

**Módulo:** [STRING](../STRING.md)

## Descripción

Verifica si una estructura de opciones contiene un texto, ignorando mayúsculas.

## Sintaxis

```pseudocode
Funcion Logico <- string_struct_contains_ignoreCase(text_search, string_struct, separator)
```

## Parámetros

- `text_search`: Texto a buscar

- `string_struct`: Estructura de texto con opciones

- `separator`: Separador de opciones

## Retorna

Logico
