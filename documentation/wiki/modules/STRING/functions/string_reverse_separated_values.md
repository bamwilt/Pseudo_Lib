# string_reverse_separated_values

**Módulo:** [STRING](../STRING.md)

## Descripción

Invierte el orden de los valores separados por un delimitador.

## Sintaxis

```pseudocode
Funcion Texto <- string_reverse_separated_values(text, separator)
```

## Parámetros

- `text`: Texto con valores separados

- `separator`: Separador de valores

## Retorna

Texto
