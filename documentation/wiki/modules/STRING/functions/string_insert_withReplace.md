# string_insert_withReplace

**Módulo:** [STRING](../STRING.md)

## Descripción

Inserta un texto en una posición reemplazando el contenido existente.

## Sintaxis

```pseudocode
Funcion Texto <- string_insert_withReplace(text, text_insert, index)
```

## Parámetros

- `text`: Texto base

- `text_insert`: Texto a insertar (reemplaza)

- `index`: Posición donde insertar

## Retorna

Texto
