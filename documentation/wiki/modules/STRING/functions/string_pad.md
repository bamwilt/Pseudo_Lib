# string_pad

**Módulo:** [STRING](../STRING.md)

## Descripción

Rellena un texto al inicio con un patrón (usa la longitud del patrón como límite).

## Sintaxis

```pseudocode
Funcion Texto <- string_pad(text, text_pad)
```

## Parámetros

- `text`: Texto a rellenar

- `text_pad`: Texto de relleno

## Retorna

Texto
