# string_fit

**Módulo:** [STRING](../STRING.md)

## Descripción

Ajusta un texto a un patrón rellenando al inicio y recortando al final si es necesario.

## Sintaxis

```pseudocode
Funcion Texto <- string_fit(text, text_pad)
```

## Parámetros

- `text`: Texto a ajustar

- `text_pad`: Patrón de ajuste

## Retorna

Texto
