# string_occurrences_overlap

**Módulo:** [STRING](../STRING.md)

## Descripción

Cuenta las ocurrencias solapadas de un texto dentro de otro.

## Sintaxis

```pseudocode
Funcion Numero <- string_occurrences_overlap(text, text_match)
```

## Parámetros

- `text`: Texto donde buscar

- `text_match`: Texto a contar

## Retorna

Numero
