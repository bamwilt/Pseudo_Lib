# string_repeatText

**Módulo:** [STRING](../STRING.md)

## Descripción

Repite un texto N veces usando duplicación exponencial para eficiencia.

## Sintaxis

```pseudocode
Funcion Texto <- string_repeatText(text, repeats)
```

## Parámetros

- `text`: Texto a repetir

- `repeats`: Número de repeticiones

## Retorna

Texto
