# string_struct_contains

**Módulo:** [STRING](../STRING.md)

## Descripción

Verifica si una estructura de opciones contiene un texto específico.

## Sintaxis

```pseudocode
Funcion Logico <- string_struct_contains(text_search, string_struct, separator)
```

## Parámetros

- `text_search`: Texto a buscar

- `string_struct`: Estructura de texto con opciones separadas

- `separator`: Separador de opciones

## Retorna

Logico
