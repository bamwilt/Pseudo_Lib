# string_Strip_Right

**Módulo:** [STRING](../STRING.md)

## Descripción

Elimina un símbolo específico solo al final del texto.

## Sintaxis

```pseudocode
Funcion Texto <- string_Strip_Right(text, strip_symbol)
```

## Parámetros

- `text`: Texto a recortar

- `strip_symbol`: Símbolo a eliminar

## Retorna

Texto
