# string_isEquals_ignoreCase

**Módulo:** [STRING](../STRING.md)

## Descripción

Compara dos textos ignorando diferencias de mayúsculas/minúsculas.

## Sintaxis

```pseudocode
Funcion Logico <- string_isEquals_ignoreCase(str1, str2)
```

## Parámetros

- `str1`: Primer texto

- `str2`: Segundo texto

## Retorna

Logico
