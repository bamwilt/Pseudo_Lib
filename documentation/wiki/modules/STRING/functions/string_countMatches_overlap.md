# string_countMatches_overlap

**Módulo:** [STRING](../STRING.md)

## Descripción

Cuenta las coincidencias solapadas de un patrón en un texto.

## Sintaxis

```pseudocode
Funcion Numero <- string_countMatches_overlap(text, text_matcher)
```

## Parámetros

- `text`: Texto donde buscar

- `text_matcher`: Patrón a buscar

## Retorna

Numero
