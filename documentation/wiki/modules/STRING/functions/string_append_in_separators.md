# string_append_in_separators

**Módulo:** [STRING](../STRING.md)

## Descripción

Inserta un texto después de cada ocurrencia de un separador.

## Sintaxis

```pseudocode
Funcion Texto <- string_append_in_separators(text, text_append, separator)
```

## Parámetros

- `text`: Texto base con separadores

- `text_append`: Texto a insertar

- `separator`: Separador a buscar

## Retorna

Texto
