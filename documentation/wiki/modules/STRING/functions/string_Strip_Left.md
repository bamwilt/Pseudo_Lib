# string_Strip_Left

**Módulo:** [STRING](../STRING.md)

## Descripción

Elimina un símbolo específico solo al inicio del texto.

## Sintaxis

```pseudocode
Funcion Texto <- string_Strip_Left(text, strip_symbol)
```

## Parámetros

- `text`: Texto a recortar

- `strip_symbol`: Símbolo a eliminar

## Retorna

Texto
