# string_insert_from_End

**Módulo:** [STRING](../STRING.md)

## Descripción

Inserta un texto al final de otro.

## Sintaxis

```pseudocode
Funcion Texto <- string_insert_from_End(text, text_insert)
```

## Parámetros

- `text`: Texto base

- `text_insert`: Texto a insertar al final

## Retorna

Texto
