# string_toNumber

**Módulo:** [STRING](../STRING.md)

## Descripción

Convierte un texto a número. Si no es válido retorna -1.

## Sintaxis

```pseudocode
Funcion Numero <- string_toNumber(result_string)
```

## Parámetros

- `result_string`: Texto a convertir

## Retorna

Numero
