# string_delete

**Módulo:** [STRING](../STRING.md)

## Descripción

Elimina un rango de caracteres de un texto.

## Sintaxis

```pseudocode
Funcion Texto <- string_delete(text, start, end)
```

## Parámetros

- `text`: Texto base

- `start`: Índice inicial

- `end`: Índice final

## Retorna

Texto
