# string_lastIndexOf

**Módulo:** [STRING](../STRING.md)

## Descripción

Busca la última aparición de un texto. Retorna -1 si no se encuentra.

## Sintaxis

```pseudocode
Funcion Numero <- string_lastIndexOf(text, text_match)
```

## Parámetros

- `text`: Texto donde buscar

- `text_match`: Texto a buscar

## Retorna

Numero
