# string_indexOf_fromIndex

**Módulo:** [STRING](../STRING.md)

## Descripción

Busca un texto desde un índice específico. Retorna -1 si no se encuentra.

## Sintaxis

```pseudocode
Funcion Numero <- string_indexOf_fromIndex(text, match, index_Start)
```

## Parámetros

- `text`: Texto donde buscar

- `match`: Texto a buscar

- `index_Start`: Índice desde el cual empezar la búsqueda

## Retorna

Numero
