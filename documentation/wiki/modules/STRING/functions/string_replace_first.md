# string_replace_first

**Módulo:** [STRING](../STRING.md)

## Descripción

Reemplaza solo la primera ocurrencia de un texto.

## Sintaxis

```pseudocode
Funcion Texto <- string_replace_first(text, text_match, text_Replace)
```

## Parámetros

- `text`: Texto base

- `text_match`: Texto a buscar

- `text_Replace`: Texto de reemplazo

## Retorna

Texto
