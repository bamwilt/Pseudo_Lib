# string_fit_end

**Módulo:** [STRING](../STRING.md)

## Descripción

Ajusta un texto a un patrón rellenando al final y recortando al final si es necesario.

## Sintaxis

```pseudocode
Funcion Texto <- string_fit_end(text, text_pad)
```

## Parámetros

- `text`: Texto a ajustar

- `text_pad`: Patrón de ajuste

## Retorna

Texto
