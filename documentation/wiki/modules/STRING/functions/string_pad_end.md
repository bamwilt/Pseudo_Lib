# string_pad_end

**Módulo:** [STRING](../STRING.md)

## Descripción

Rellena un texto al final con un patrón.

## Sintaxis

```pseudocode
Funcion Texto <- string_pad_end(text, text_pad)
```

## Parámetros

- `text`: Texto a rellenar

- `text_pad`: Texto de relleno

## Retorna

Texto
