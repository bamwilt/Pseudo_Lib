# string_substring_from

**Módulo:** [STRING](../STRING.md)

## Descripción

Extrae una subcadena desde un índice hasta el final.

## Sintaxis

```pseudocode
Funcion Texto <- string_substring_from(result_string, start)
```

## Parámetros

- `result_string`: Texto de origen

- `start`: Índice desde el cual extraer

## Retorna

Texto
