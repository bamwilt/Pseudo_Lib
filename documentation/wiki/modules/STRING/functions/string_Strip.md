# string_Strip

**Módulo:** [STRING](../STRING.md)

## Descripción

Elimina un símbolo específico al inicio y final del texto.

## Sintaxis

```pseudocode
Funcion Texto <- string_Strip(text, strip_symbol)
```

## Parámetros

- `text`: Texto a recortar

- `strip_symbol`: Símbolo a eliminar

## Retorna

Texto
