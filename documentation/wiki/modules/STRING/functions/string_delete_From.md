# string_delete_From

**Módulo:** [STRING](../STRING.md)

## Descripción

Elimina desde una posición hasta el final del texto.

## Sintaxis

```pseudocode
Funcion Texto <- string_delete_From(text, start)
```

## Parámetros

- `text`: Texto base

- `start`: Índice desde el cual eliminar

## Retorna

Texto
