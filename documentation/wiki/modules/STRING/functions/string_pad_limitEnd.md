# string_pad_limitEnd

**Módulo:** [STRING](../STRING.md)

## Descripción

Rellena un texto al final con otro texto hasta alcanzar una longitud.

## Sintaxis

```pseudocode
Funcion Texto <- string_pad_limitEnd(text, text_pad, pad_length)
```

## Parámetros

- `text`: Texto a rellenar

- `text_pad`: Texto de relleno

- `pad_length`: Longitud total deseada

## Retorna

Texto
