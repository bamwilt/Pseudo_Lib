# string_insert

**Módulo:** [STRING](../STRING.md)

## Descripción

Inserta un texto en una posición específica.

## Sintaxis

```pseudocode
Funcion Texto <- string_insert(text, text_insert, index)
```

## Parámetros

- `text`: Texto base

- `text_insert`: Texto a insertar

- `index`: Posición donde insertar

## Retorna

Texto
