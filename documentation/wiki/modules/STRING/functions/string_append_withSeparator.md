# string_append_withSeparator

**Módulo:** [STRING](../STRING.md)

## Descripción

Concatena dos textos insertando un separador entre ellos.

## Sintaxis

```pseudocode
Funcion Texto <- string_append_withSeparator(str1, str2, separator)
```

## Parámetros

- `str1`: Primer texto

- `str2`: Segundo texto

- `separator`: Separador a insertar entre ambos

## Retorna

Texto
