# char_At

**Módulo:** [STRING](../STRING.md)

## Descripción

Retorna el carácter en la posición indicada.

## Sintaxis

```pseudocode
Funcion Texto <- char_At(text, index)
```

## Parámetros

- `text`: Texto de origen

- `index`: Índice del carácter

## Retorna

Texto
