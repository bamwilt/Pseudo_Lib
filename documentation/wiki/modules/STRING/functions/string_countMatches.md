# string_countMatches

**Módulo:** [STRING](../STRING.md)

## Descripción

Cuenta las coincidencias de un patrón en un texto (no solapado).

## Sintaxis

```pseudocode
Funcion Numero <- string_countMatches(text, text_matcher)
```

## Parámetros

- `text`: Texto donde buscar

- `text_matcher`: Patrón a buscar

## Retorna

Numero
