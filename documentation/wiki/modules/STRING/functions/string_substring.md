# string_substring

**Módulo:** [STRING](../STRING.md)

## Descripción

Extrae una subcadena entre dos índices. Si start == end retorna vacío.

## Sintaxis

```pseudocode
Funcion Texto <- string_substring(result_string, start, end)
```

## Parámetros

- `result_string`: Texto de origen

- `start`: Índice inicial

- `end`: Índice final (no inclusivo)

## Retorna

Texto
