# string_FindInterruption_Right

**Módulo:** [STRING](../STRING.md)

## Descripción

Encuentra el índice del primer carácter que no sea el símbolo indicado, desde la derecha.

## Sintaxis

```pseudocode
Funcion Entero <- string_FindInterruption_Right(text, strip_symbol)
```

## Parámetros

- `text`: Texto a examinar

- `strip_symbol`: Símbolo a ignorar

## Retorna

Entero
