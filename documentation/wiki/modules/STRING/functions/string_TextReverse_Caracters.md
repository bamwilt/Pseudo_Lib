# string_TextReverse_Caracters

**Módulo:** [STRING](../STRING.md)

## Descripción

Invierte un texto reemplazando caracteres según un array de pares (útil para caracteres espejo).

## Sintaxis

```pseudocode
Funcion Texto <- string_TextReverse_Caracters(text, array_Carathers, array_size)
```

## Parámetros

- `text`: Texto a invertir

- `array_Carathers`: Array de pares de caracteres para reemplazo

- `array_size`: Tamaño del array

## Retorna

Texto
