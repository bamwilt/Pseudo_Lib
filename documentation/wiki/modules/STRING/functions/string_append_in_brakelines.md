# string_append_in_brakelines

**Módulo:** [STRING](../STRING.md)

## Descripción

Inserta un texto entre cada línea de un texto multilínea.

## Sintaxis

```pseudocode
Funcion Texto <- string_append_in_brakelines(text, text_append)
```

## Parámetros

- `text`: Texto base con líneas separadas por \n

- `text_append`: Texto a insertar entre cada línea

## Retorna

Texto
