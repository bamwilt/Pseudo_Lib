# number_IsInRange

**Módulo:** [NUMBER](..\NUMBER.md)

## Descripción

Checks whether a numeric value falls within a specified inclusive range.

## Sintaxis
```pseudocode
Funcion IsInRange <- number_IsInRange(value, min_val, max_val)
```

## Parámetros
- `value`: The value to check
- `min_val`: Lower bound (inclusive)
- `max_val`: Upper bound (inclusive)

## Retorna
`true` if `value >= min_val` and `value <= max_val`, `false` otherwise.
