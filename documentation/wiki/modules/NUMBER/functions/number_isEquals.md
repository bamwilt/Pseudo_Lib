# number_isEquals

**Módulo:** [NUMBER](..\NUMBER.md)

## Descripción

Checks whether two numeric values are equal using the generic equality comparator.

## Sintaxis
```pseudocode
Funcion boolean <- number_isEquals(num, num2)
```

## Parámetros
- `num`: First number to compare
- `num2`: Second number to compare

## Retorna
`true` if the numbers are equal, `false` otherwise.
