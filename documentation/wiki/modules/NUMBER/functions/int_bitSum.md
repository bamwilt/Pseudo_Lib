# int_bitSum

**Módulo:** [NUMBER](..\NUMBER.md)

## Descripción

Adds two integers by converting them to binary strings, performing binary addition, and converting the result back to an integer.

## Sintaxis
```pseudocode
Funcion int_result <- int_bitSum(A_int, B_int)
```

## Parámetros
- `A_int`: First integer addend
- `B_int`: Second integer addend

## Retorna
The sum of `A_int` and `B_int`.
