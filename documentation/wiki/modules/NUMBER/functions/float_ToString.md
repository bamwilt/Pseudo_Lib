# float_ToString

**Módulo:** [NUMBER](..\NUMBER.md)

## Descripción

Converts a number to its string representation and validates that the result represents a float. Raises an error if the string is not a valid float.

## Sintaxis
```pseudocode
Funcion result_string <- float_ToString(num)
```

## Parámetros
- `num`: The number to convert

## Retorna
A string representation of the float value.
