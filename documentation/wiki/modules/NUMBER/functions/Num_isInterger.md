# Num_isInterger

**Módulo:** [NUMBER](..\NUMBER.md)

## Descripción

Checks whether a numeric value is an integer (has no fractional part).

## Sintaxis
```pseudocode
Funcion boolean <- Num_isInterger(num)
```

## Parámetros
- `num`: The number to check

## Retorna
`true` if the number is an integer, `false` otherwise.
