# Int_BitMoveRight

**Módulo:** [NUMBER](..\NUMBER.md)

## Descripción

Shifts the bits of an integer to the right by a given number of positions using binary string operations.

## Sintaxis
```pseudocode
Funcion int_result <- Int_BitMoveRight(int_num, num_movements)
```

## Parámetros
- `int_num`: The integer to shift
- `num_movements`: Number of positions to shift right

## Retorna
The result of shifting `int_num` right by `num_movements` bits.
