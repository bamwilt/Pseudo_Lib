# int_CompareTo

**Módulo:** [NUMBER](..\NUMBER.md)

## Descripción

Compares two numbers and returns -1 if the first is less, 1 if the first is greater, or 0 if they are equal.

## Sintaxis
```pseudocode
Funcion int_result <- int_CompareTo(number0, number1)
```

## Parámetros
- `number0`: The first number
- `number1`: The second number

## Retorna
`-1` if `number0 < number1`, `1` if `number0 > number1`, `0` if equal.
