# interger_ToString

**Módulo:** [NUMBER](..\NUMBER.md)

## Descripción

Converts a number to its string representation and validates that the result represents an integer. Raises an error if the string is not a valid integer.

## Sintaxis
```pseudocode
Funcion result_string <- interger_ToString(num)
```

## Parámetros
- `num`: The number to convert

## Retorna
A string representation of the integer value.
