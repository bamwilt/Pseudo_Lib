# int_ToBinaryString

**Módulo:** [NUMBER](..\NUMBER.md)

## Descripción

Converts a positive integer to its binary string representation, padded to at least 4 bits.

## Sintaxis
```pseudocode
Funcion binaryString <- int_ToBinaryString(num)
```

## Parámetros
- `num`: The integer to convert

## Retorna
A string containing the binary representation of `num`.
