# Int_BitMoveLeft

**Módulo:** [NUMBER](..\NUMBER.md)

## Descripción

Shifts the bits of an integer to the left by a given number of positions using binary string operations.

## Sintaxis
```pseudocode
Funcion int_result <- Int_BitMoveLeft(int_num, num_movements)
```

## Parámetros
- `int_num`: The integer to shift
- `num_movements`: Number of positions to shift left

## Retorna
The result of shifting `int_num` left by `num_movements` bits.
