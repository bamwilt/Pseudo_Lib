# value_stringToType

**Módulo:** [VALUE](../VALUE.md)

## Descripción

Convierte un string al tipo de dato especificado (int, float, boolean, string).

## Sintaxis

```pseudocode
Funcion element_Result <- value_stringToType(element_String, TYPE)
```

## Parámetros

- `element_String`: Texto a convertir
- `TYPE`: Tipo de destino (TYPE_INT, TYPE_FLOAT, TYPE_BOOLEAN, etc.)

## Retorna

El valor convertido al tipo especificado.
