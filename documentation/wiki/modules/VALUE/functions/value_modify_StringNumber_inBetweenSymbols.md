# value_modify_StringNumber_inBetweenSymbols

**Módulo:** [VALUE](../VALUE.md)

## Descripción

Modifica (suma un valor) un número encontrado entre dos símbolos en un texto.

## Sintaxis

```pseudocode
Funcion string_Increment <- value_modify_StringNumber_inBetweenSymbols(Text, num_sum, symbol_start, symbol_end)
```

## Parámetros

- `Text`: Texto original
- `num_sum`: Valor a sumar al número
- `symbol_start`: Símbolo delimitador inicial
- `symbol_end`: Símbolo delimitador final

## Retorna

Texto con el número modificado entre los símbolos.
