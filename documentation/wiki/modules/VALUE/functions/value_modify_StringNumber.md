# value_modify_StringNumber

**Módulo:** [VALUE](../VALUE.md)

## Descripción

Suma un valor numérico a un número representado como string y retorna el resultado como string.

## Sintaxis

```pseudocode
Funcion string_Increment <- value_modify_StringNumber(string_number, num_sum)
```

## Parámetros

- `string_number`: Número en formato string
- `num_sum`: Valor a sumar

## Retorna

String con el resultado de la suma.
