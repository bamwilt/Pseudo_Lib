# value_type_isValid

**Módulo:** [VALUE](../VALUE.md)

## Descripción

Verifica si un tipo de dato es válido dentro del sistema (int, float, boolean, string).

## Sintaxis

```pseudocode
Funcion isValid <- value_type_isValid(TYPE)
```

## Parámetros

- `TYPE`: Tipo a validar

## Retorna

Verdadero si el tipo es válido.
