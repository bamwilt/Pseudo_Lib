# value_isNull

**Módulo:** [VALUE](../VALUE.md)

## Descripción

Verifica si un valor es considerado nulo según su tipo de dato.

## Sintaxis

```pseudocode
Funcion boolean <- value_isNull(value, TYPE)
```

## Parámetros

- `value`: Valor a evaluar
- `TYPE`: Tipo de dato del valor

## Retorna

Verdadero si el valor es nulo para el tipo especificado.
