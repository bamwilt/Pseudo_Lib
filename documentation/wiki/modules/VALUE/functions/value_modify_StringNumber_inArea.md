# value_modify_StringNumber_inArea

**Módulo:** [VALUE](../VALUE.md)

## Descripción

Modifica (suma un valor) un número dentro de un área delimitada por índices en un texto.

## Sintaxis

```pseudocode
Funcion string_Increment <- value_modify_StringNumber_inArea(Text, num_sum, index_start, index_end)
```

## Parámetros

- `Text`: Texto original
- `num_sum`: Valor a sumar
- `index_start`: Índice inicial
- `index_end`: Índice final

## Retorna

Texto con el número modificado en esa área.
