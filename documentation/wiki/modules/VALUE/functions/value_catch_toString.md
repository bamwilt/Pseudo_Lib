# value_catch_toString

**Módulo:** [VALUE](../VALUE.md)

## Descripción

Versión toString de value_catch. Retorna la representación string del valor capturado.

## Sintaxis

```pseudocode
Funcion result <- value_catch_toString(expected_value, method, message, TYPE)
```

## Parámetros

- `expected_value`: Valor esperado
- `method`: Nombre del método
- `message`: Mensaje de error
- `TYPE`: Tipo de dato

## Retorna

String del valor capturado.
