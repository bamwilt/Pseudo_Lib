# value_getNullType_toString

**Módulo:** [VALUE](../VALUE.md)

## Descripción

Retorna la representación string del valor nulo por defecto de un tipo.

## Sintaxis

```pseudocode
Funcion result <- value_getNullType_toString(TYPE)
```

## Parámetros

- `TYPE`: Tipo de dato

## Retorna

String del valor nulo del tipo especificado.
