# value_TypeToString

**Módulo:** [VALUE](../VALUE.md)

## Descripción

Convierte un valor de cualquier tipo a su representación como string.

## Sintaxis

```pseudocode
Funcion result <- value_TypeToString(data, TYPE)
```

## Parámetros

- `data`: Valor a convertir
- `TYPE`: Tipo del valor (TYPE_INT, TYPE_FLOAT, TYPE_BOOLEAN, etc.)

## Retorna

Representación string del valor.
