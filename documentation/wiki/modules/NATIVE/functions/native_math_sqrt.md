# native_math_sqrt

**Módulo:** [NATIVE](../NATIVE.md)

## Descripción

Retorna la raíz cuadrada. Si el número es negativo retorna 0.

## Sintaxis

```pseudocode
Funcion Numero <- native_math_sqrt(num)
```

## Parámetros

- `num`: Número del cual obtener la raíz cuadrada

## Retorna

Numero
