# native_math_module

**Módulo:** [NATIVE](../NATIVE.md)

## Descripción

Retorna el resto de la división entre dos números.

## Sintaxis

```pseudocode
Funcion Numero <- native_math_module(number1, number2)
```

## Parámetros

- `number1`: Dividendo

- `number2`: Divisor

## Retorna

Numero
