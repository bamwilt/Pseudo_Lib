# native_math_ln

**Módulo:** [NATIVE](../NATIVE.md)

## Descripción

Retorna el logaritmo natural. Si el número es <= 0 retorna 0.

## Sintaxis

```pseudocode
Funcion Numero <- native_math_ln(num)
```

## Parámetros

- `num`: Número del cual obtener el logaritmo natural

## Retorna

Numero
