# native_string_substring

**Módulo:** [NATIVE](../NATIVE.md)

## Descripción

Extrae una subcadena de un texto.

## Sintaxis

```pseudocode
Funcion Texto <- native_string_substring(result_string, start, end)
```

## Parámetros

- `result_string`: Texto del cual extraer la subcadena

- `start`: Índice inicial (0-based)

- `end`: Índice final (no inclusivo)

## Retorna

Texto
