# array_ofString

**Módulo:** [ARRAY](../ARRAY.md)

## Descripción

Convierte un arreglo a una cadena de texto utilizando el separador simple (coma). Es una envoltura de `array_ofstring_separator` con el separador por defecto.

## Sintaxis

```pseudocode
Funcion str_array <- array_ofString(array, Size, type)
```

## Parámetros

- `array`: El arreglo a convertir.
- `Size`: El tamaño del arreglo.
- `type`: El tipo de datos de los elementos (TYPE_INT, TYPE_FLOAT, TYPE_BOOLEAN, TYPE_STRING).

## Retorna

Una cadena de texto con los elementos del arreglo separados por comas.
