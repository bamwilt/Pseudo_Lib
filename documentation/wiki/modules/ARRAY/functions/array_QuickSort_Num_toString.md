# array_QuickSort_Num_toString

**Módulo:** [ARRAY](../ARRAY.md)

## Descripción

Convierte un arreglo numérico a una cadena de texto utilizando el algoritmo QuickSort. Actualmente funciona como envoltura de `array_ofString`.

## Sintaxis

```pseudocode
Funcion str_array <- array_QuickSort_Num_toString(array, Size)
```

## Parámetros

- `array`: Arreglo de números a convertir.
- `Size`: Tamaño del arreglo.

## Retorna

Una cadena de texto con los elementos del arreglo.
