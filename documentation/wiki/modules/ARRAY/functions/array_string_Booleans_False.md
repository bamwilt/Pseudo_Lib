# array_string_Booleans_False

**Módulo:** [ARRAY](../ARRAY.md)

## Descripción

Devuelve las representaciones textuales del valor booleano "false" según un índice. Soporta múltiples formatos como "false", "falso", "no", "f", "n", "0".

## Sintaxis

```pseudocode
Funcion value <- array_string_Booleans_False(index)
```

## Parámetros

- `index`: Índice numérico que selecciona la representación textual (0-5).

## Retorna

Una cadena de texto con la representación de "false". Retorna `string_NULL()` si el índice está fuera de rango.
