# array_string_Booleans_True

**Módulo:** [ARRAY](../ARRAY.md)

## Descripción

Devuelve las representaciones textuales del valor booleano "true" según un índice. Soporta múltiples formatos como "true", "verdadero", "yes", "sí", "t", "v", "y", "s", "1".

## Sintaxis

```pseudocode
Funcion value <- array_string_Booleans_True(index)
```

## Parámetros

- `index`: Índice numérico que selecciona la representación textual (0-8).

## Retorna

Una cadena de texto con la representación de "true". Retorna `string_NULL()` si el índice está fuera de rango.
