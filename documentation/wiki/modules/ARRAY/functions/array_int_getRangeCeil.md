# array_int_getRangeCeil

**Módulo:** [ARRAY](../ARRAY.md)

## Descripción

Obtiene el valor techo (ceiling) de un número dentro de un arreglo de rangos numéricos ordenados. Retorna el primer elemento del arreglo que sea mayor o igual al número dado.

## Sintaxis

```pseudocode
Funcion num_range <- array_int_getRangeCeil(array, Size, num)
```

## Parámetros

- `array`: Arreglo de números enteros ordenados.
- `Size`: Tamaño del arreglo.
- `num`: El número a evaluar.

## Retorna

El primer valor del arreglo que es mayor o igual a `num`.
