# array_bitChar_LogicalOperations

**Módulo:** [ARRAY](../ARRAY.md)

## Descripción

Realiza operaciones lógicas bit a bit entre dos caracteres binarios. Soporta AND, OR, XOR y NOT según el índice especificado.

## Sintaxis

```pseudocode
Funcion bitChar <- array_bitChar_LogicalOperations(bitChar1, bitChar2, index)
```

## Parámetros

- `bitChar1`: Primer carácter binario ("0" o "1").
- `bitChar2`: Segundo carácter binario ("0" o "1").
- `index`: Índice de la operación (0=AND, 1=OR, 2=XOR, otro=NOT sobre bitChar1).

## Retorna

El resultado de la operación lógica como carácter binario ("0" o "1").
