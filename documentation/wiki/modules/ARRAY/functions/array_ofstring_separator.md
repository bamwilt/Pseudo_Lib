# array_ofstring_separator

**Módulo:** [ARRAY](../ARRAY.md)

## Descripción

Convierte un arreglo a una cadena de texto utilizando un separador personalizado entre cada elemento.

## Sintaxis

```pseudocode
Funcion str_array <- array_ofstring_separator(array, Size, separator, type)
```

## Parámetros

- `array`: El arreglo a convertir.
- `Size`: El tamaño del arreglo.
- `separator`: El separador a insertar entre elementos.
- `type`: El tipo de datos de los elementos (TYPE_INT, TYPE_FLOAT, TYPE_BOOLEAN, TYPE_STRING).

## Retorna

Una cadena de texto con los elementos del arreglo unidos por el separador especificado.
