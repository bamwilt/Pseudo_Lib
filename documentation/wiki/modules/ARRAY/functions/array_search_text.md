# array_search_text

**Módulo:** [ARRAY](../ARRAY.md)

## Descripción

Busca un texto dentro de un arreglo de cadenas y devuelve el índice de la primera coincidencia.

## Sintaxis

```pseudocode
Funcion index <- array_search_text(array, Size, text)
```

## Parámetros

- `array`: Arreglo de textos en el que buscar.
- `Size`: Tamaño del arreglo.
- `text`: El texto a buscar.

## Retorna

El índice de la primera coincidencia, o -1 si no se encuentra.
