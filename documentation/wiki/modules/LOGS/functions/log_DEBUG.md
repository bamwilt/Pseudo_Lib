# log_DEBUG

**Módulo:** [LOGS](../LOGS.md)

## Descripción

Registra un mensaje de depuración con la etiqueta "DEBUG:" y color azul.

## Sintaxis

```pseudocode
Funcion log_DEBUG(message)
```

## Parámetros

- `message`: El mensaje de depuración a registrar.

## Retorna

No retorna valor.
