# __private_general_log

**Módulo:** [LOGS](../LOGS.md)

## Descripción

Función interna que formatea y muestra un mensaje de log con una etiqueta y color personalizados. Es la base de todas las funciones de logging.

## Sintaxis

```pseudocode
Funcion __private_general_log(message, start_tag, SELECTED_COLOR)
```

## Parámetros

- `message`: El mensaje a registrar.
- `start_tag`: La etiqueta de prefijo (ej. "ERROR:", "INFO:").
- `SELECTED_COLOR`: El código de color ANSI para el mensaje.

## Retorna

No retorna valor.
