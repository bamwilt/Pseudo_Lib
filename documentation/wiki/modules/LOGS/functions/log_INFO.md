# log_INFO

**Módulo:** [LOGS](../LOGS.md)

## Descripción

Registra un mensaje informativo con la etiqueta "INFO:" y color blanco.

## Sintaxis

```pseudocode
Funcion log_INFO(message)
```

## Parámetros

- `message`: El mensaje informativo a registrar.

## Retorna

No retorna valor.
