# log_TRACE

**Módulo:** [LOGS](../LOGS.md)

## Descripción

Registra un mensaje de trazabilidad con la etiqueta "TRACE:" y color cian.

## Sintaxis

```pseudocode
Funcion log_TRACE(message)
```

## Parámetros

- `message`: El mensaje de trazabilidad a registrar.

## Retorna

No retorna valor.
