# log_ERROR

**Módulo:** [LOGS](../LOGS.md)

## Descripción

Registra un mensaje de error con la etiqueta "ERROR:" y color rojo.

## Sintaxis

```pseudocode
Funcion log_ERROR(message)
```

## Parámetros

- `message`: El mensaje de error a registrar.

## Retorna

No retorna valor.
