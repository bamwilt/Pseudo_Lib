# log_WARNING

**Módulo:** [LOGS](../LOGS.md)

## Descripción

Registra un mensaje de advertencia con la etiqueta "WARNING:" y color amarillo.

## Sintaxis

```pseudocode
Funcion log_WARNING(message)
```

## Parámetros

- `message`: El mensaje de advertencia a registrar.

## Retorna

No retorna valor.
