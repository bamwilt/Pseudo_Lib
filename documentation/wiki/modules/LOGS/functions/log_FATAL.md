# log_FATAL

**Módulo:** [LOGS](../LOGS.md)

## Descripción

Registra un mensaje fatal con la etiqueta "FATAL:" y color magenta.

## Sintaxis

```pseudocode
Funcion log_FATAL(message)
```

## Parámetros

- `message`: El mensaje fatal a registrar.

## Retorna

No retorna valor.
