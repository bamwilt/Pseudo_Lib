# util_queue_DeleteFirst

**Módulo:** [QUEUE](../QUEUE.md)

## Descripción

Elimina el primer elemento de la cola.

## Sintaxis

```pseudocode
Funcion collection_result <- util_queue_DeleteFirst(struct_Queue)
```

## Parámetros

- `struct_Queue`: La estructura de cola (Texto).

## Retorna

Texto con la estructura de la cola actualizada.
