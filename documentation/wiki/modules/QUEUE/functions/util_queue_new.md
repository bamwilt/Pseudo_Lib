# util_queue_new

**Módulo:** [QUEUE](../QUEUE.md)

## Descripción

Crea una nueva cola vacía.

## Sintaxis

```pseudocode
Funcion new_Queue <- util_queue_new(TYPE)
```

## Parámetros

- `TYPE`: Tipo de dato que almacenará la cola. Valores: `TYPE_INT()`, `TYPE_FLOAT()`, `TYPE_BOOLEAN()`, `TYPE_STRING()`.

## Retorna

Texto representando la estructura interna de la cola.
