# util_queue_Size

**Módulo:** [QUEUE](../QUEUE.md)

## Descripción

Obtiene la cantidad de elementos en la cola.

## Sintaxis

```pseudocode
Funcion Size_int <- util_queue_Size(struct_Queue)
```

## Parámetros

- `struct_Queue`: La estructura de cola a consultar (Texto).

## Retorna

Número entero con la cantidad de elementos.
