# util_queue_Peek

**Módulo:** [QUEUE](../QUEUE.md)

## Descripción

Obtiene el primer elemento de la cola sin eliminarlo.

## Sintaxis

```pseudocode
Funcion element_Result <- util_queue_Peek(struct_Queue)
```

## Parámetros

- `struct_Queue`: La estructura de cola (Texto).

## Retorna

El primer elemento de la cola en el tipo correspondiente.
