# util_queue_println

**Módulo:** [QUEUE](../QUEUE.md)

## Descripción

Imprime en consola el contenido completo de la cola.

## Sintaxis

```pseudocode
Funcion util_queue_println(struct_Queue)
```

## Parámetros

- `struct_Queue`: La estructura de cola a imprimir (Texto).

## Retorna

Nada. Imprime el contenido directamente en consola.
