# util_queue_Poll

**Módulo:** [QUEUE](../QUEUE.md)

## Descripción

Obtiene y elimina el primer elemento de la cola en una sola operación.

## Sintaxis

```pseudocode
Funcion element_Result <- util_queue_Poll(struct_Queue Por Referencia)
```

## Parámetros

- `struct_Queue Por Referencia`: La estructura de cola pasada por referencia (se modifica in situ).

## Retorna

El primer elemento de la cola en el tipo correspondiente.
