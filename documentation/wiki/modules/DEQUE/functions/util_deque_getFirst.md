# util_deque_getFirst

**Módulo:** [DEQUE](../DEQUE.md)

## Descripción

Obtiene el primer elemento del deque sin eliminarlo.

## Sintaxis

```pseudocode
Funcion element_Result <- util_deque_getFirst(struct_Deque)
```

## Parámetros

- `struct_Deque`: La estructura de deque (Texto).

## Retorna

El primer elemento del deque en el tipo correspondiente.
