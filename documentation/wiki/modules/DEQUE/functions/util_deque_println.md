# util_deque_println

**Módulo:** [DEQUE](../DEQUE.md)

## Descripción

Imprime en consola el contenido completo del deque.

## Sintaxis

```pseudocode
Funcion util_deque_println(struct_Deque)
```

## Parámetros

- `struct_Deque`: La estructura de deque a imprimir (Texto).

## Retorna

Nada. Imprime el contenido directamente en consola.
