# util_deque_getLast

**Módulo:** [DEQUE](../DEQUE.md)

## Descripción

Obtiene el último elemento del deque sin eliminarlo.

## Sintaxis

```pseudocode
Funcion element_Result <- util_deque_getLast(struct_Deque)
```

## Parámetros

- `struct_Deque`: La estructura de deque (Texto).

## Retorna

El último elemento del deque en el tipo correspondiente.
