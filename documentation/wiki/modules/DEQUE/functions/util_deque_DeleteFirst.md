# util_deque_DeleteFirst

**Módulo:** [DEQUE](../DEQUE.md)

## Descripción

Elimina el primer elemento del deque.

## Sintaxis

```pseudocode
Funcion collection_result <- util_deque_DeleteFirst(struct_Deque)
```

## Parámetros

- `struct_Deque`: La estructura de deque (Texto).

## Retorna

Texto con la estructura del deque actualizada.
