# util_deque_DeleteLast

**Módulo:** [DEQUE](../DEQUE.md)

## Descripción

Elimina el último elemento del deque.

## Sintaxis

```pseudocode
Funcion collection_result <- util_deque_DeleteLast(struct_Deque)
```

## Parámetros

- `struct_Deque`: La estructura de deque (Texto).

## Retorna

Texto con la estructura del deque actualizada.
