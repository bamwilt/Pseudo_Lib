# util_deque_Size

**Módulo:** [DEQUE](../DEQUE.md)

## Descripción

Obtiene la cantidad de elementos almacenados en el deque.

## Sintaxis

```pseudocode
Funcion Size_int <- util_deque_Size(struct_Deque)
```

## Parámetros

- `struct_Deque`: La estructura de deque a consultar (Texto).

## Retorna

Número entero con la cantidad de elementos.
