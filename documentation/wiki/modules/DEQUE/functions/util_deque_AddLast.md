# util_deque_AddLast

**Módulo:** [DEQUE](../DEQUE.md)

## Descripción

Agrega un elemento al final del deque.

## Sintaxis

```pseudocode
Funcion deque_Result <- util_deque_AddLast(struct_Deque, element)
```

## Parámetros

- `struct_Deque`: La estructura de deque (Texto).
- `element`: Elemento a agregar (tipo según la colección).

## Retorna

Texto con la estructura del deque actualizada.
