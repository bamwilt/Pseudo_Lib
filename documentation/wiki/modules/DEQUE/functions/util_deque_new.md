# util_deque_new

**Módulo:** [DEQUE](../DEQUE.md)

## Descripción

Crea una nueva estructura de deque vacía.

## Sintaxis

```pseudocode
Funcion new_Deque <- util_deque_new(TYPE)
```

## Parámetros

- `TYPE`: Tipo de dato que almacenará el deque (Text). Valores: `TYPE_INT()`, `TYPE_FLOAT()`, `TYPE_BOOLEAN()`, `TYPE_STRING()`.

## Retorna

Texto representando la estructura interna del deque.
