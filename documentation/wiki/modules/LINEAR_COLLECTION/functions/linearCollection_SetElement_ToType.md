# linearCollection_SetElement_ToType

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Establece el valor de un elemento en una posición específica con tipo explícito.

## Sintaxis

```pseudocode
Funcion collection_result <- linearCollection_SetElement_ToType(struct_Collection, index_element, new_value, TYPE)
```

## Parámetros

- `struct_Collection`: Colección original
- `index_element`: Índice del elemento
- `new_value`: Nuevo valor
- `TYPE`: Tipo de dato del nuevo valor

## Retorna

Colección con el elemento modificado.
