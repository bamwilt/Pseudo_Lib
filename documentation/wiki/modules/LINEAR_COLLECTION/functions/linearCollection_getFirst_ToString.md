# linearCollection_getFirst_ToString

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Obtiene el primer elemento de la colección como string.

## Sintaxis

```pseudocode
Funcion element_String <- linearCollection_getFirst_ToString(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección a consultar

## Retorna

String del primer elemento.
