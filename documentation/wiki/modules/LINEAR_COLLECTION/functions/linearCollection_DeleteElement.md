# linearCollection_DeleteElement

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Elimina un elemento de la colección en el índice especificado.

## Sintaxis

```pseudocode
Funcion collection_result <- linearCollection_DeleteElement(struct_Collection, index_element)
```

## Parámetros

- `struct_Collection`: Colección original
- `index_element`: Índice del elemento a eliminar

## Retorna

Colección sin el elemento en la posición indicada.
