# linearCollection_getSize

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Obtiene el número de elementos (tamaño) de la colección lineal.

## Sintaxis

```pseudocode
Funcion Size_int <- linearCollection_getSize(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección a consultar

## Retorna

Número entero con la cantidad de elementos.
