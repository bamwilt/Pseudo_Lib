# linearCollection_addFirst

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Agrega un elemento al inicio de la colección lineal.

## Sintaxis

```pseudocode
Funcion collection_result <- linearCollection_addFirst(struct_Collection, Element)
```

## Parámetros

- `struct_Collection`: Colección original
- `Element`: Elemento a agregar

## Retorna

Colección con el elemento agregado al inicio.
