# linearCollection_getElement_toType

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Obtiene un elemento por índice con conversión a un tipo específico.

## Sintaxis

```pseudocode
Funcion element_Result <- linearCollection_getElement_toType(struct_Collection, index_element, TYPE)
```

## Parámetros

- `struct_Collection`: Colección a consultar
- `index_element`: Índice del elemento
- `TYPE`: Tipo de dato de destino

## Retorna

Elemento convertido al tipo especificado.
