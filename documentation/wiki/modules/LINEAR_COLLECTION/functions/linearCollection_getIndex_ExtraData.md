# linearCollection_getIndex_ExtraData

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Obtiene el índice del símbolo extraData en la colección lineal.

## Sintaxis

```pseudocode
Funcion index_extraData <- linearCollection_getIndex_ExtraData(struct_LinearCollection)
```

## Parámetros

- `struct_LinearCollection`: Colección a consultar

## Retorna

Índice entero del símbolo extraData.
