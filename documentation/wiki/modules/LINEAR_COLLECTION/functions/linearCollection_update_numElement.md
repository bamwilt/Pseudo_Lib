# linearCollection_update_numElement

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Actualiza el contador de elementos sumando un valor (positivo o negativo).

## Sintaxis

```pseudocode
Funcion collection_result <- linearCollection_update_numElement(struct_List, num_sum)
```

## Parámetros

- `struct_List`: Colección a modificar
- `num_sum`: Valor a sumar al contador

## Retorna

Colección con el contador actualizado.
