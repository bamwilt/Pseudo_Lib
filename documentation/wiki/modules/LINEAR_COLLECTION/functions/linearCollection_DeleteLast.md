# linearCollection_DeleteLast

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Elimina el último elemento de la colección lineal.

## Sintaxis

```pseudocode
Funcion collection_result <- linearCollection_DeleteLast(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección original

## Retorna

Colección sin el último elemento.
