# linearCollection_SetElement

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Establece el valor de un elemento en una posición específica de la colección.

## Sintaxis

```pseudocode
Funcion collection_result <- linearCollection_SetElement(struct_Collection, index_element, new_value)
```

## Parámetros

- `struct_Collection`: Colección original
- `index_element`: Índice del elemento a modificar
- `new_value`: Nuevo valor

## Retorna

Colección con el elemento modificado.
