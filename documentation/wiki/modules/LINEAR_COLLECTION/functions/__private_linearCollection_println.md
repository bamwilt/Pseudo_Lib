# __private_linearCollection_println

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Función privada que imprime los datos de la colección separando área de datos y longitudes.

## Sintaxis

```pseudocode
Funcion __private_linearCollection_println(linearCollection, isnewLine)
```

## Parámetros

- `linearCollection`: Colección a imprimir
- `isnewLine`: Si es verdadero imprime con saltos de línea

## Retorna

No retorna valor.
