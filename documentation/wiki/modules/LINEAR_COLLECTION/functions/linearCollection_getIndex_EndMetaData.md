# linearCollection_getIndex_EndMetaData

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Obtiene el índice final del metaData (posición del símbolo ExtraData) en la colección.

## Sintaxis

```pseudocode
Funcion End_index <- linearCollection_getIndex_EndMetaData(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección a consultar

## Retorna

Índice entero del símbolo ExtraData.
