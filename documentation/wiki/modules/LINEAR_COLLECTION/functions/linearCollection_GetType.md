# linearCollection_GetType

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Obtiene el tipo de datos almacenado en la colección lineal.

## Sintaxis

```pseudocode
Funcion type_result <- linearCollection_GetType(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección a consultar

## Retorna

String con el tipo de la colección.
