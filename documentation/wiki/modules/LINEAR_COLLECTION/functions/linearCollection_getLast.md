# linearCollection_getLast

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Obtiene el último elemento de la colección con el tipo de dato correspondiente.

## Sintaxis

```pseudocode
Funcion element_Result <- linearCollection_getLast(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección a consultar

## Retorna

Último elemento de la colección.
