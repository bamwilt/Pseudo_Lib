# linearCollection_getElement_toString

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Obtiene un elemento de la colección como string por su índice, usando managerData_get_toString.

## Sintaxis

```pseudocode
Funcion element_String <- linearCollection_getElement_toString(struct_linearCollection, index_element)
```

## Parámetros

- `struct_linearCollection`: Colección lineal a consultar
- `index_element`: Índice del elemento

## Retorna

String del elemento en la posición indicada.
