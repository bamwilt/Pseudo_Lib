# linearCollection_DeleteFirst

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Elimina el primer elemento de la colección lineal.

## Sintaxis

```pseudocode
Funcion collection_result <- linearCollection_DeleteFirst(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección original

## Retorna

Colección sin el primer elemento.
