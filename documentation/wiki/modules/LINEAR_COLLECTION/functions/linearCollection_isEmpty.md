# linearCollection_isEmpty

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Verifica si la colección lineal está vacía (tamaño menor a 1).

## Sintaxis

```pseudocode
Funcion struct_IsEmpty <- linearCollection_isEmpty(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección a evaluar

## Retorna

Verdadero si la colección no tiene elementos.
