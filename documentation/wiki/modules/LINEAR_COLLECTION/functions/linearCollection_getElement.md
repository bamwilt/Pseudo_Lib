# linearCollection_getElement

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Obtiene un elemento de la colección por su índice, con conversión automática al tipo de la colección.

## Sintaxis

```pseudocode
Funcion element_Result <- linearCollection_getElement(struct_Collection, index_element)
```

## Parámetros

- `struct_Collection`: Colección a consultar
- `index_element`: Índice del elemento

## Retorna

Elemento en la posición indicada, con el tipo de dato de la colección.
