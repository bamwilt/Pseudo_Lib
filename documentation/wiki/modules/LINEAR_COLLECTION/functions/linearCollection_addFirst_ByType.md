# linearCollection_addFirst_ByType

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Agrega un elemento al inicio de la colección con tipo explícito.

## Sintaxis

```pseudocode
Funcion collection_result <- linearCollection_addFirst_ByType(struct_Collection, Element, TYPE)
```

## Parámetros

- `struct_Collection`: Colección original
- `Element`: Elemento a agregar
- `TYPE`: Tipo de dato del elemento

## Retorna

Colección con el elemento agregado al inicio.
