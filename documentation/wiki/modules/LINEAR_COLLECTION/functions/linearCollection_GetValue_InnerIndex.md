# linearCollection_GetValue_InnerIndex

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Busca el índice interno de un valor string dentro de la colección lineal.

## Sintaxis

```pseudocode
Funcion innerIndex <- linearCollection_GetValue_InnerIndex(linearCollection, data_string)
```

## Parámetros

- `linearCollection`: Colección lineal a buscar
- `data_string`: String a encontrar

## Retorna

Índice interno del valor encontrado, o number_NULL si no existe.
