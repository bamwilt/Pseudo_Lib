# linearCollection_decrement_numElement

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Decrementa en 1 el contador de elementos de la colección.

## Sintaxis

```pseudocode
Funcion collection_result <- linearCollection_decrement_numElement(struct_List)
```

## Parámetros

- `struct_List`: Colección a modificar

## Retorna

Colección con el contador decrementado.
