# linearCollection_getLast_toType

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Obtiene el último elemento de la colección con conversión a un tipo específico.

## Sintaxis

```pseudocode
Funcion element_Result <- linearCollection_getLast_toType(struct_Collection, TYPE)
```

## Parámetros

- `struct_Collection`: Colección a consultar
- `TYPE`: Tipo de dato de destino

## Retorna

Último elemento convertido al tipo especificado.
