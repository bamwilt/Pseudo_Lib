# linearCollection_addFirst_byString

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Agrega un elemento representado como string al inicio de la colección.

## Sintaxis

```pseudocode
Funcion collection_result <- linearCollection_addFirst_byString(struct_Collection, element_String)
```

## Parámetros

- `struct_Collection`: Colección original
- `element_String`: Elemento en formato string

## Retorna

Colección con el string agregado al inicio.
