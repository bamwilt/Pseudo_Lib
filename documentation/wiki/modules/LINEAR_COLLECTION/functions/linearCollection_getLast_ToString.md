# linearCollection_getLast_ToString

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Obtiene el último elemento de la colección como string.

## Sintaxis

```pseudocode
Funcion element_String <- linearCollection_getLast_ToString(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección a consultar

## Retorna

String del último elemento.
