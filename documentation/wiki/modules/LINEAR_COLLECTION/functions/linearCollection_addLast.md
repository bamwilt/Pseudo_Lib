# linearCollection_addLast

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Agrega un elemento al final de la colección lineal.

## Sintaxis

```pseudocode
Funcion collection_result <- linearCollection_addLast(struct_Collection, Element)
```

## Parámetros

- `struct_Collection`: Colección original
- `Element`: Elemento a agregar

## Retorna

Colección con el elemento agregado al final.
