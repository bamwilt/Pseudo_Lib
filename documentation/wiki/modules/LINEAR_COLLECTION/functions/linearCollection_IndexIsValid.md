# linearCollection_IndexIsValid

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Verifica si un índice es válido dentro de la colección lineal.

## Sintaxis

```pseudocode
Funcion index_isValid <- linearCollection_IndexIsValid(struct_Collection, index_element)
```

## Parámetros

- `struct_Collection`: Colección a evaluar
- `index_element`: Índice a validar

## Retorna

Verdadero si el índice está dentro del rango de la colección.
