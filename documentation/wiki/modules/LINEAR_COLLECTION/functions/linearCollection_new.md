# linearCollection_new

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Crea una nueva colección lineal a partir de una colección base y un tipo.

## Sintaxis

```pseudocode
Funcion new_LinearColletion <- linearCollection_new(struct_Collection, TYPE)
```

## Parámetros

- `struct_Collection`: Tipo de estructura
- `TYPE`: Tipo de datos

## Retorna

String con la colección lineal serializada, con contador de elementos inicializado en 0.
