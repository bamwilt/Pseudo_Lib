# linearCollection_GetValues_ToSeparatedString

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Convierte todos los valores de la colección en un string separado por un delimitador.

## Sintaxis

```pseudocode
Funcion separated_String <- linearCollection_GetValues_ToSeparatedString(linearCollection, separator)
```

## Parámetros

- `linearCollection`: Colección lineal
- `separator`: Separador entre valores

## Retorna

String con todos los valores separados.
