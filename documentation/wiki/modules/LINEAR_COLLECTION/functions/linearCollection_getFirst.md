# linearCollection_getFirst

**Módulo:** [LINEAR_COLLECTION](../LINEAR_COLLECTION.md)

## Descripción

Obtiene el primer elemento de la colección con el tipo de dato correspondiente.

## Sintaxis

```pseudocode
Funcion element_Result <- linearCollection_getFirst(struct_Collection)
```

## Parámetros

- `struct_Collection`: Colección a consultar

## Retorna

Primer elemento de la colección.
