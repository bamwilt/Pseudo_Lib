# util_map_remove

**Módulo:** [MAP](../MAP.md)

## Descripción
Elimina un elemento del mapa por su clave.

## Sintaxis
```
Funcion result_Map <- util_map_remove(struct_map, key)
```

## Parámetros
- `struct_map`: Estructura del mapa
- `key`: Clave del elemento a eliminar

## Retorna
El mapa sin el elemento.
