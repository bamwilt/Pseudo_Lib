# util_map_Put

**Módulo:** [MAP](../MAP.md)

## Descripción
Inserta o actualiza un par clave-valor en el mapa. Si la clave ya existe, actualiza el valor.

## Sintaxis
```
Funcion result_Map <- util_map_Put(struct_map, key, value)
```

## Parámetros
- `struct_map`: Estructura del mapa
- `key`: Clave
- `value`: Valor a asociar

## Retorna
El mapa actualizado.
