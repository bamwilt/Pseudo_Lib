# util_map_Get

**Módulo:** [MAP](../MAP.md)

## Descripción
Obtiene el valor asociado a una clave, tipado según el tipo del mapa.

## Sintaxis
```
Funcion element_Result <- util_map_Get(struct_map, key)
```

## Parámetros
- `struct_map`: Estructura del mapa
- `key`: Clave a buscar

## Retorna
Valor asociado a la clave.
