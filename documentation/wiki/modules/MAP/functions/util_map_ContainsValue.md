# util_map_ContainsValue

**Módulo:** [MAP](../MAP.md)

## Descripción
Verifica si un valor específico existe dentro del mapa.

## Sintaxis
```
Funcion mapConstains <- util_map_ContainsValue(struct_map, value_match)
```

## Parámetros
- `struct_map`: Estructura del mapa
- `value_match`: Valor a buscar

## Retorna
`Verdadero` si el valor existe, `Falso` en caso contrario.
