# util_map_new

**Módulo:** [MAP](../MAP.md)

## Descripción
Crea un nuevo mapa vacío con los tipos especificados para clave y valor.

## Sintaxis
```
Funcion new_Map <- util_map_new(TYPE, TYPE_VALUE)
```

## Parámetros
- `TYPE`: Tipo de dato de las claves
- `TYPE_VALUE`: Tipo de dato de los valores

## Retorna
Una nueva estructura de mapa vacío.
