# util_map_ContainsKey

**Módulo:** [MAP](../MAP.md)

## Descripción
Verifica si una clave específica existe dentro del mapa.

## Sintaxis
```
Funcion mapConstains <- util_map_ContainsKey(struct_map, key_match)
```

## Parámetros
- `struct_map`: Estructura del mapa
- `key_match`: Clave a buscar

## Retorna
`Verdadero` si la clave existe, `Falso` en caso contrario.
