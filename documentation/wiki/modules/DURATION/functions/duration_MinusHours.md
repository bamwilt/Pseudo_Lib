# duration_MinusHours

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Resta horas a la duración.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_MinusHours(struct_duration, num_decrement)
```

## Parámetros
- `struct_duration`: Objeto Duration
- `num_decrement`: Cantidad de horas

## Retorna
La duración con las horas restadas.
