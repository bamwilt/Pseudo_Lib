# duration_Negated

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Invierte el signo de la duración (la hace negativa si era positiva y viceversa).

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_Negated(struct_duration)
```

## Parámetros
- `struct_duration`: Objeto Duration

## Retorna
La duración con el signo invertido.
