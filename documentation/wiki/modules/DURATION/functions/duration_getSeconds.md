# duration_getSeconds

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Obtiene el total de segundos de una duración.

## Sintaxis
```pseudocode
Funcion duration_ofUnit <- duration_getSeconds(struct_Duration)
```

## Parámetros
- `struct_Duration`: Objeto Duration

## Retorna
El total de segundos.
