# duration_PlusHours

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Suma horas a la duración.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_PlusHours(struct_duration, num_increment)
```

## Parámetros
- `struct_duration`: Objeto Duration
- `num_increment`: Cantidad de horas

## Retorna
La duración con las horas sumadas.
