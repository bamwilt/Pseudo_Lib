# duration_of

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Crea una duración a partir de una cantidad y una unidad temporal (días, horas, minutos o segundos).

## Sintaxis
```pseudocode
Funcion duration_ofUnit <- duration_of(number_Units, Temporal_Type)
```

## Parámetros
- `number_Units`: Cantidad de unidades
- `Temporal_Type`: Tipo de unidad (chronoUnit_DAYS(), chronoUnit_HOURS(), chronoUnit_MINUTES(), chronoUnit_SECONDS())

## Retorna
Un objeto Duration.
