# duration_MinusSeconds

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Resta segundos a la duración.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_MinusSeconds(struct_duration, num_decrement)
```

## Parámetros
- `struct_duration`: Objeto Duration
- `num_decrement`: Cantidad de segundos

## Retorna
La duración con los segundos restados.
