# duration_ToMinutes

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Convierte la duración a minutos (valor decimal).

## Sintaxis
```pseudocode
Funcion second_ofUnit <- duration_ToMinutes(struct_temporal)
```

## Parámetros
- `struct_temporal`: Objeto Duration

## Retorna
La duración en minutos.
