# duration_PlusMinutes

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Suma minutos a la duración.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_PlusMinutes(struct_duration, num_increment)
```

## Parámetros
- `struct_duration`: Objeto Duration
- `num_increment`: Cantidad de minutos

## Retorna
La duración con los minutos sumados.
