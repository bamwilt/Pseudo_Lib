# duration_PlusDays

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Suma días a la duración.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_PlusDays(struct_duration, num_increment)
```

## Parámetros
- `struct_duration`: Objeto Duration
- `num_increment`: Cantidad de días

## Retorna
La duración con los días sumados.
