# duration_PlusSeconds

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Suma segundos a la duración.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_PlusSeconds(struct_duration, num_increment)
```

## Parámetros
- `struct_duration`: Objeto Duration
- `num_increment`: Cantidad de segundos

## Retorna
La duración con los segundos sumados.
