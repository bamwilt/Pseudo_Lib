# duration_ToMinutesPart

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Obtiene la parte entera de minutos de la duración (0-59).

## Sintaxis
```pseudocode
Funcion second_ofUnit <- duration_ToMinutesPart(struct_temporal)
```

## Parámetros
- `struct_temporal`: Objeto Duration

## Retorna
La parte entera de minutos.
