# duration_ToHoursPart

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Obtiene la parte entera de horas de la duración (0-23).

## Sintaxis
```pseudocode
Funcion value_part <- duration_ToHoursPart(struct_temporal)
```

## Parámetros
- `struct_temporal`: Objeto Duration

## Retorna
La parte entera de horas.
