# duration_DividedBy

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Divide la duración por un escalar.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_DividedBy(struct_duration, num_Div)
```

## Parámetros
- `struct_duration`: Objeto Duration
- `num_Div`: Divisor

## Retorna
La duración dividida por el escalar.
