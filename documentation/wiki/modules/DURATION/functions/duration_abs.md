# duration_abs

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Obtiene el valor absoluto de la duración.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_abs(struct_duration)
```

## Parámetros
- `struct_duration`: Objeto Duration

## Retorna
La duración con valor absoluto.
