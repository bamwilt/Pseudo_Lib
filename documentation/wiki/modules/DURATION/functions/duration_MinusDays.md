# duration_MinusDays

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Resta días a la duración.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_MinusDays(struct_duration, num_decrement)
```

## Parámetros
- `struct_duration`: Objeto Duration
- `num_decrement`: Cantidad de días

## Retorna
La duración con los días restados.
