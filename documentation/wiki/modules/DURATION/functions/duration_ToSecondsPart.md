# duration_ToSecondsPart

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Obtiene la parte entera de segundos de la duración (0-59).

## Sintaxis
```pseudocode
Funcion second_ofUnit <- duration_ToSecondsPart(struct_temporal)
```

## Parámetros
- `struct_temporal`: Objeto Duration

## Retorna
La parte entera de segundos.
