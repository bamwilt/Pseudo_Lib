# duration_isZero

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Verifica si la duración es cero.

## Sintaxis
```pseudocode
Funcion isBetween <- duration_isZero(struct_duration)
```

## Parámetros
- `struct_duration`: Objeto Duration

## Retorna
`true` si es cero, `false` en caso contrario.
