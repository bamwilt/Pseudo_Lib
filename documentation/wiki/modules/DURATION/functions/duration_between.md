# duration_between

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Calcula la duración entre dos instantes (diferencia).

## Sintaxis
```pseudocode
Funcion struct_difference <- duration_between(duration_Start, duration_End)
```

## Parámetros
- `duration_Start`: Duración de inicio
- `duration_End`: Duración de fin

## Retorna
La duración resultante (End - Start).
