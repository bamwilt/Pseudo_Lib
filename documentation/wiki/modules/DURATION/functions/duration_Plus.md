# duration_Plus

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Suma dos duraciones.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_Plus(struct_duration, struct_duration_minus)
```

## Parámetros
- `struct_duration`: Primera duración
- `struct_duration_minus`: Segunda duración

## Retorna
La suma de las duraciones.
