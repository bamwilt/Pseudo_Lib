# duration_MinusMinutes

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Resta minutos a la duración.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_MinusMinutes(struct_duration, num_decrement)
```

## Parámetros
- `struct_duration`: Objeto Duration
- `num_decrement`: Cantidad de minutos

## Retorna
La duración con los minutos restados.
