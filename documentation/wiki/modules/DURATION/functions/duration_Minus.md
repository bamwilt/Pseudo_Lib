# duration_Minus

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Resta dos duraciones.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_Minus(struct_duration, struct_duration_minus)
```

## Parámetros
- `struct_duration`: Primera duración
- `struct_duration_minus`: Segunda duración

## Retorna
La diferencia de las duraciones.
