# duration_CompareTo

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Compara dos duraciones.

## Sintaxis
```pseudocode
Funcion int_result <- duration_CompareTo(struct_duration, struct_duration_match)
```

## Parámetros
- `struct_duration`: Primera duración
- `struct_duration_match`: Segunda duración

## Retorna
-1 si la primera es menor, 0 si son iguales, 1 si la primera es mayor.
