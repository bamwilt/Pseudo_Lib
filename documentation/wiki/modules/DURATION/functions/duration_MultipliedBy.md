# duration_MultipliedBy

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Multiplica la duración por un escalar.

## Sintaxis
```pseudocode
Funcion struct_duration_result <- duration_MultipliedBy(struct_duration, num_Mult)
```

## Parámetros
- `struct_duration`: Objeto Duration
- `num_Mult`: Escalar multiplicador

## Retorna
La duración multiplicada por el escalar.
