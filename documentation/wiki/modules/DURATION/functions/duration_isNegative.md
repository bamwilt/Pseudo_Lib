# duration_isNegative

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Verifica si la duración es negativa.

## Sintaxis
```pseudocode
Funcion isBetween <- duration_isNegative(struct_duration)
```

## Parámetros
- `struct_duration`: Objeto Duration

## Retorna
`true` si es negativa, `false` en caso contrario.
