# duration_ToDaysPart

**Módulo:** [DURATION](../DURATION.md)

## Descripción
Obtiene la parte entera de días de la duración.

## Sintaxis
```pseudocode
Funcion value_part <- duration_ToDaysPart(struct_temporal)
```

## Parámetros
- `struct_temporal`: Objeto Duration

## Retorna
La parte entera de días.
