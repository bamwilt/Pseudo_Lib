# util_stack_Size

**Módulo:** [STACK](../STACK.md)

## Descripción

Obtiene la cantidad de elementos en la pila.

## Sintaxis

```pseudocode
Funcion Size_int <- util_stack_Size(struct_Stack)
```

## Parámetros

- `struct_Stack`: La estructura de pila a consultar (Texto).

## Retorna

Número entero con la cantidad de elementos.
