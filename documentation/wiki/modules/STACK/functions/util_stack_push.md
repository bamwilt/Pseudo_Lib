# util_stack_push

**Módulo:** [STACK](../STACK.md)

## Descripción

Apila un elemento en la cima de la pila.

## Sintaxis

```pseudocode
Funcion stack_Result <- util_stack_push(struct_Stack, element)
```

## Parámetros

- `struct_Stack`: La estructura de pila (Texto).
- `element`: Elemento a apilar.

## Retorna

Texto con la estructura de la pila actualizada.
