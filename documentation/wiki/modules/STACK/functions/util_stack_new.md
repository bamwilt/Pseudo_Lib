# util_stack_new

**Módulo:** [STACK](../STACK.md)

## Descripción

Crea una nueva pila vacía.

## Sintaxis

```pseudocode
Funcion new_Stack <- util_stack_new(TYPE)
```

## Parámetros

- `TYPE`: Tipo de dato que almacenará la pila. Valores: `TYPE_INT()`, `TYPE_FLOAT()`, `TYPE_BOOLEAN()`, `TYPE_STRING()`.

## Retorna

Texto representando la estructura interna de la pila.
