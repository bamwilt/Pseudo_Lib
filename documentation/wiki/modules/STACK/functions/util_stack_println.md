# util_stack_println

**Módulo:** [STACK](../STACK.md)

## Descripción

Imprime en consola el contenido completo de la pila.

## Sintaxis

```pseudocode
Funcion util_stack_println(struct_Stack)
```

## Parámetros

- `struct_Stack`: La estructura de pila a imprimir (Texto).

## Retorna

Nada. Imprime el contenido directamente en consola.
