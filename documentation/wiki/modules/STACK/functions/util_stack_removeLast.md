# util_stack_removeLast

**Módulo:** [STACK](../STACK.md)

## Descripción

Elimina el último elemento (cima) de la pila.

## Sintaxis

```pseudocode
Funcion stack_Result <- util_stack_removeLast(struct_Stack)
```

## Parámetros

- `struct_Stack`: La estructura de pila (Texto).

## Retorna

Texto con la estructura de la pila actualizada.
