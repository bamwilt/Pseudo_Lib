# util_stack_Top

**Módulo:** [STACK](../STACK.md)

## Descripción

Obtiene el elemento de la cima de la pila sin eliminarlo.

## Sintaxis

```pseudocode
Funcion element_Result <- util_stack_Top(struct_Stack)
```

## Parámetros

- `struct_Stack`: La estructura de pila (Texto).

## Retorna

El elemento de la cima en el tipo correspondiente.
