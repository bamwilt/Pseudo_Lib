# util_List_get

**Módulo:** [LIST](../LIST.md)

## Descripción
Obtiene un elemento de la lista por su índice.

## Sintaxis
```pseudocode
Funcion element_Result <- util_List_get(struct_list, index_element)
```

## Parámetros
- `struct_list`: Lista
- `index_element`: Índice del elemento

## Retorna
El elemento en la posición indicada.
