# util_List_set

**Módulo:** [LIST](../LIST.md)

## Descripción
Modifica el valor de un elemento en la posición indicada.

## Sintaxis
```pseudocode
Funcion list_Result <- util_List_set(struct_list, index_element, new_Value)
```

## Parámetros
- `struct_list`: Lista
- `index_element`: Índice del elemento a modificar
- `new_Value`: Nuevo valor

## Retorna
La lista con el elemento modificado.
