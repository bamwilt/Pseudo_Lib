# util_List_delete

**Módulo:** [LIST](../LIST.md)

## Descripción
Elimina un elemento de la lista por su índice.

## Sintaxis
```pseudocode
Funcion element_Result <- util_List_delete(struct_list, index_element)
```

## Parámetros
- `struct_list`: Lista
- `index_element`: Índice del elemento a eliminar

## Retorna
La lista sin el elemento eliminado.
