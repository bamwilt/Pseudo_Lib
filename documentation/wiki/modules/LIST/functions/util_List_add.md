# util_List_add

**Módulo:** [LIST](../LIST.md)

## Descripción
Agrega un elemento al final de la lista.

## Sintaxis
```pseudocode
Funcion list_result <- util_List_add(struct_list, element)
```

## Parámetros
- `struct_list`: Lista
- `element`: Elemento a agregar

## Retorna
La lista con el elemento agregado.
