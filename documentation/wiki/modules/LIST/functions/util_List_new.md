# util_List_new

**Módulo:** [LIST](../LIST.md)

## Descripción
Crea una nueva lista vacía del tipo especificado.

## Sintaxis
```pseudocode
Funcion new_list <- util_List_new(TYPE)
```

## Parámetros
- `TYPE`: Tipo de los elementos (TYPE_INT, TYPE_FLOAT, TYPE_BOOLEAN, TYPE_STRING)

## Retorna
Una nueva lista vacía.
