# storageCellsCollection_getCellIndex

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Obtiene el índice de una clave en la colección.

## Sintaxis
```
Funcion index_target <- storageCellsCollection_getCellIndex(struct_storageCells, value_search)
```

## Parámetros
- `struct_storageCells`: Estructura de almacenamiento
- `value_search`: Clave a buscar

## Retorna
Índice de la clave, o -1 si no existe.
