# storageCellsCollection_modifyData_byCell

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Modifica el valor asociado a una clave específica.

## Sintaxis
```
Funcion result_storage <- storageCellsCollection_modifyData_byCell(struct_storageCells, value_search, value)
```

## Parámetros
- `struct_storageCells`: Estructura de almacenamiento
- `value_search`: Clave a buscar
- `value`: Nuevo valor

## Retorna
La estructura con el valor modificado.
