# storageCellsCollection_getSeparateString

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Obtiene el string separado de las claves (wrapper).

## Sintaxis
```
Funcion separate_string <- storageCellsCollection_getSeparateString(struct_cells)
```

## Parámetros
- `struct_cells`: Estructura de almacenamiento

## Retorna
String con claves separadas.
