# storageCellsCollection_delete_byString

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Elimina un par clave-valor a partir del string de la clave, eliminando tanto la clave como el valor asociado.

## Sintaxis
```
Funcion result_storage <- storageCellsCollection_delete_byString(struct_storageCells, string_search)
```

## Parámetros
- `struct_storageCells`: Estructura de almacenamiento
- `string_search`: String de la clave

## Retorna
La estructura sin el par.
