# storageCellsCollection_constainsValue

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Verifica si un valor existe en el almacenamiento.

## Sintaxis
```
Funcion constainsValue <- storageCellsCollection_constainsValue(struct_storageCells, value_search)
```

## Parámetros
- `struct_storageCells`: Estructura de almacenamiento
- `value_search`: Valor a buscar

## Retorna
`Verdadero` si el valor existe, `Falso` en caso contrario.
