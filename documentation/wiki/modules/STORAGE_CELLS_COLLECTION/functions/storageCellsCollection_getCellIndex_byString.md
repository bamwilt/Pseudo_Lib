# storageCellsCollection_getCellIndex_byString

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Obtiene el índice de una clave a partir de su representación en string.

## Sintaxis
```
Funcion index_target <- storageCellsCollection_getCellIndex_byString(struct_storageCells, string_search)
```

## Parámetros
- `struct_storageCells`: Estructura de almacenamiento
- `string_search`: String de la clave

## Retorna
Índice de la clave.
