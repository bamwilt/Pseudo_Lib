# storageCellsCollection_getSize

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Obtiene la cantidad de pares clave-valor almacenados.

## Sintaxis
```
Funcion collection_size <- storageCellsCollection_getSize(struct_storageCells)
```

## Parámetros
- `struct_storageCells`: Estructura de almacenamiento

## Retorna
Número de pares almacenados.
