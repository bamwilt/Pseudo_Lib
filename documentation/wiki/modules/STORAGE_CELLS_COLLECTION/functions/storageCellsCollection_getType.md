# storageCellsCollection_getType

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Obtiene el tipo de dato de las claves (wrapper).

## Sintaxis
```
Funcion TYPE <- storageCellsCollection_getType(struct_storageCells)
```

## Parámetros
- `struct_storageCells`: Estructura de almacenamiento

## Retorna
Tipo de las claves.
