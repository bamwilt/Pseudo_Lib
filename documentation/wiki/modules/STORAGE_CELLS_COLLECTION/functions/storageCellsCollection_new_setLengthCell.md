# storageCellsCollection_new_setLengthCell

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Crea un nuevo almacenamiento clave-valor con una longitud de celda personalizada.

## Sintaxis
```
Funcion collection_storage <- storageCellsCollection_new_setLengthCell(struct_name, TYPE_CELL, TYPE_LINEAR, fixed_Length)
```

## Parámetros
- `struct_name`: Nombre de la estructura
- `TYPE_CELL`: Tipo de dato de las claves
- `TYPE_LINEAR`: Tipo de dato de los valores
- `fixed_Length`: Longitud de celda para las claves

## Retorna
Una nueva estructura de almacenamiento.
