# storageCellsCollection_new

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Crea un nuevo almacenamiento clave-valor con longitud de celda predeterminada (1).

## Sintaxis
```
Funcion collection_storage <- storageCellsCollection_new(struct_name, TYPE_CELL, TYPE_LINEAR)
```

## Parámetros
- `struct_name`: Nombre de la estructura
- `TYPE_CELL`: Tipo de dato de las claves
- `TYPE_LINEAR`: Tipo de dato de los valores

## Retorna
Una nueva estructura de almacenamiento.
