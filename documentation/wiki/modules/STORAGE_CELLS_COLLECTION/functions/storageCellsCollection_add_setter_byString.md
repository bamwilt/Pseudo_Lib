# storageCellsCollection_add_setter_byString

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Agrega un par clave-valor con setter dinámico a partir de strings.

## Sintaxis
```
Funcion result_storage <- storageCellsCollection_add_setter_byString(struct_storage, value_string, data_string)
```

## Parámetros
- `struct_storage`: Estructura de almacenamiento
- `value_string`: String de la clave
- `data_string`: String del valor

## Retorna
La estructura con el nuevo par si no existía.
