# storageCellsCollection_constainsCell

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Verifica si una clave existe en el almacenamiento.

## Sintaxis
```
Funcion constainsValue <- storageCellsCollection_constainsCell(struct_storageCells, value_search)
```

## Parámetros
- `struct_storageCells`: Estructura de almacenamiento
- `value_search`: Clave a buscar

## Retorna
`Verdadero` si la clave existe, `Falso` en caso contrario.
