# storageCellsCollection_delete

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Elimina un par clave-valor a partir del valor de la clave.

## Sintaxis
```
Funcion result_storage <- storageCellsCollection_delete(struct_storageCells, value_search)
```

## Parámetros
- `struct_storageCells`: Estructura de almacenamiento
- `value_search`: Clave a eliminar

## Retorna
La estructura sin el par.
