# storageCellsCollection_getCellLength

**Módulo:** [STORAGE_CELLS_COLLECTION](../STORAGE_CELLS_COLLECTION.md)

## Descripción
Obtiene la longitud de celda de las claves (wrapper).

## Sintaxis
```
Funcion cell_length <- storageCellsCollection_getCellLength(struct_storageCells)
```

## Parámetros
- `struct_storageCells`: Estructura de almacenamiento

## Retorna
Longitud de celda.
