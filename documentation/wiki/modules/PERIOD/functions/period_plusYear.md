# period_plusYear

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Suma años al Period.

## Sintaxis
```pseudocode
Funcion result_period <- period_plusYear(struct_period, unit_plus)
```

## Parámetros
- `struct_period`: Objeto Period
- `unit_plus`: Cantidad de años a sumar

## Retorna
Period con los años sumados.
