# period_plusMonths

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Suma meses al Period.

## Sintaxis
```pseudocode
Funcion result_period <- period_plusMonths(struct_period, unit_plus)
```

## Parámetros
- `struct_period`: Objeto Period
- `unit_plus`: Cantidad de meses a sumar

## Retorna
Period con los meses sumados.
