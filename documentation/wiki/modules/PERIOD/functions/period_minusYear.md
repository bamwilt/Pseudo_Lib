# period_minusYear

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Resta años al Period.

## Sintaxis
```pseudocode
Funcion result_period <- period_minusYear(struct_period, unit_minus)
```

## Parámetros
- `struct_period`: Objeto Period
- `unit_minus`: Cantidad de años a restar

## Retorna
Period con los años restados.
