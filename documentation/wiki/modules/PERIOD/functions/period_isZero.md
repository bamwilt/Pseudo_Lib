# period_isZero

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Verifica si el Period es cero (todas las componentes son 0).

## Sintaxis
```pseudocode
Funcion boolean <- period_isZero(struct_period)
```

## Parámetros
- `struct_period`: Objeto Period

## Retorna
`true` si es cero, `false` en caso contrario.
