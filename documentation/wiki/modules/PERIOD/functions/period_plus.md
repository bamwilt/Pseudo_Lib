# period_plus

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Suma dos Periods (componente a componente).

## Sintaxis
```pseudocode
Funcion struct_period_res <- period_plus(struct_period_A, struct_period_B)
```

## Parámetros
- `struct_period_A`: Primer Period
- `struct_period_B`: Segundo Period

## Retorna
La suma de los Periods.
