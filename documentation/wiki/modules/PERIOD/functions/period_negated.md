# period_negated

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Invierte el signo del Period (todas sus componentes).

## Sintaxis
```pseudocode
Funcion struct_period_res <- period_negated(struct_period)
```

## Parámetros
- `struct_period`: Objeto Period

## Retorna
Period con todas sus componentes negadas.
