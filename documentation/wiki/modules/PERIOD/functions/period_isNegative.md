# period_isNegative

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Verifica si el Period es negativo (alguna componente negativa).

## Sintaxis
```pseudocode
Funcion boolean <- period_isNegative(struct_period)
```

## Parámetros
- `struct_period`: Objeto Period

## Retorna
`true` si es negativo, `false` en caso contrario.
