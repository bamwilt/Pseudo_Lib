# period_minus

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Resta dos Periods.

## Sintaxis
```pseudocode
Funcion struct_period_res <- period_minus(struct_period_A, struct_period_B)
```

## Parámetros
- `struct_period_A`: Primer Period
- `struct_period_B`: Segundo Period

## Retorna
La diferencia de los Periods.
