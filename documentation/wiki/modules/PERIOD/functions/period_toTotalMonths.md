# period_toTotalMonths

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Convierte el Period a meses totales (años * 12 + meses).

## Sintaxis
```pseudocode
Funcion total_months <- period_toTotalMonths(struct_period)
```

## Parámetros
- `struct_period`: Objeto Period

## Retorna
El total de meses.
