# period_toString

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Convierte el Period a su representación textual.

## Sintaxis
```pseudocode
Funcion period_string <- period_toString(struct_period)
```

## Parámetros
- `struct_period`: Objeto Period

## Retorna
Texto en formato "Y: años M: meses D: días".
