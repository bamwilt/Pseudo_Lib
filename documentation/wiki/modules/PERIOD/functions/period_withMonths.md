# period_withMonths

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Establece los meses del Period.

## Sintaxis
```pseudocode
Funcion struct_period_res <- period_withMonths(struct_period, months)
```

## Parámetros
- `struct_period`: Objeto Period
- `months`: Nuevos meses

## Retorna
Period con los meses modificados.
