# period_plusDays

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Suma días al Period.

## Sintaxis
```pseudocode
Funcion result_period <- period_plusDays(struct_period, unit_plus)
```

## Parámetros
- `struct_period`: Objeto Period
- `unit_plus`: Cantidad de días a sumar

## Retorna
Period con los días sumados.
