# period_withDays

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Establece los días del Period.

## Sintaxis
```pseudocode
Funcion struct_period_res <- period_withDays(struct_period, days)
```

## Parámetros
- `struct_period`: Objeto Period
- `days`: Nuevos días

## Retorna
Period con los días modificados.
