# period_minusMonths

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Resta meses al Period.

## Sintaxis
```pseudocode
Funcion result_period <- period_minusMonths(struct_period, unit_minus)
```

## Parámetros
- `struct_period`: Objeto Period
- `unit_minus`: Cantidad de meses a restar

## Retorna
Period con los meses restados.
