# period_minusDays

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Resta días al Period.

## Sintaxis
```pseudocode
Funcion result_period <- period_minusDays(struct_period, unit_minus)
```

## Parámetros
- `struct_period`: Objeto Period
- `unit_minus`: Cantidad de días a restar

## Retorna
Period con los días restados.
