# period_multipliedBy

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Multiplica el Period por un escalar.

## Sintaxis
```pseudocode
Funcion struct_period_result <- period_multipliedBy(struct_period, scalar)
```

## Parámetros
- `struct_period`: Objeto Period
- `scalar`: Escalar multiplicador

## Retorna
Period multiplicado por el escalar.
