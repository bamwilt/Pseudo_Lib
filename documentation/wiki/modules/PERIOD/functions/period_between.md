# period_between

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Calcula el Period entre dos fechas (considerando años, meses y días).

## Sintaxis
```pseudocode
Funcion struct_period <- period_between(struct_date_start, struct_date_end)
```

## Parámetros
- `struct_date_start`: Fecha de inicio
- `struct_date_end`: Fecha de fin

## Retorna
El Period que representa la diferencia entre las fechas.
