# period_normalized

**Módulo:** [PERIOD](../PERIOD.md)

## Descripción
Normaliza el Period ajustando los meses al rango 0-11 y sumando los años excedentes.

## Sintaxis
```pseudocode
Funcion result_period <- period_normalized(struct_period)
```

## Parámetros
- `struct_period`: Objeto Period

## Retorna
Period normalizado.
