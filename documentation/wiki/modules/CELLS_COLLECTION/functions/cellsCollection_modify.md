# cellsCollection_modify

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Modifica un elemento en la posición especificada, detectando automáticamente el tipo.

## Sintaxis
```
result_cells <- cellsCollection_modify(struct_cells, element_remplace, index)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element_remplace`: Nuevo valor
- `index`: Número con el índice del elemento a modificar

## Retorna
Texto con la estructura modificada.
