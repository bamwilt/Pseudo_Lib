# cellsCollection_delete_byIndex

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Elimina un elemento de la colección por su índice, validando que el índice sea válido.

## Sintaxis
```
result_cells <- cellsCollection_delete_byIndex(struct, index)
```

## Parámetros
- `struct`: Texto con la estructura de celdas
- `index`: Número con el índice del elemento a eliminar

## Retorna
Texto con la estructura sin el elemento eliminado.
