# cellsCollection_getCell

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Obtiene un elemento de la colección en el índice especificado, retornándolo en el tipo de datos correspondiente.

## Sintaxis
```
element_type <- cellsCollection_getCell(struct_cells, index)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `index`: Número con el índice del elemento

## Retorna
Valor del elemento en su tipo nativo (Numero, Real, Logico, Texto).
