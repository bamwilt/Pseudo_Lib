# cellsCollection_getCell_toString

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Obtiene un elemento de la colección como string, limpiando los caracteres nulos de relleno.

## Sintaxis
```
element_string <- cellsCollection_getCell_toString(struct_cells, index)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `index`: Número con el índice del elemento

## Retorna
Texto con el contenido del elemento.
