# cellsCollection_swapData_force

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Intercambia dos elementos utilizando índices precalculados.

## Sintaxis
```
result_cells <- cellsCollection_swapData_force(struct_cells, index, index_swap, index_start_swap, cell_length)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `index`: Número con el índice del primer elemento
- `index_swap`: Número con el índice del segundo elemento
- `index_start_swap`: Número con el índice de inicio de datos
- `cell_length`: Número con la longitud de celda

## Retorna
Texto con la estructura con los elementos intercambiados.
