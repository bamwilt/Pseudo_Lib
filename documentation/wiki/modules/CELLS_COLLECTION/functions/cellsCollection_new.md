# cellsCollection_new

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Crea una nueva colección de celdas con un nombre de estructura, tipo de datos y longitud fija de celda.

## Sintaxis
```
new_cellsCollection <- cellsCollection_new(struct_name, TYPE, fixed_Length)
```

## Parámetros
- `struct_name`: Texto con el nombre de la estructura
- `TYPE`: Texto con el tipo de datos (int, float, boolean, string)
- `fixed_Length`: Número con la longitud fija de cada celda

## Retorna
Texto con la nueva colección de celdas inicializada.
