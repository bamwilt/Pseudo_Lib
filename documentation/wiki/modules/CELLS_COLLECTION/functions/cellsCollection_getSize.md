# cellsCollection_getSize

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Obtiene la cantidad de elementos almacenados en la colección de celdas.

## Sintaxis
```
size_dataBlock <- cellsCollection_getSize(struct_name)
```

## Parámetros
- `struct_name`: Texto con la estructura de celdas

## Retorna
Número con la cantidad de elementos.
