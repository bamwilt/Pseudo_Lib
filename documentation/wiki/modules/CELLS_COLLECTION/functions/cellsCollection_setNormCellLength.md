# cellsCollection_setNormCellLength

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Normaliza y valida la longitud de celda, asegurando que no sea menor que el mínimo permitido.

## Sintaxis
```
length_result <- cellsCollection_setNormCellLength(fixed_Length)
```

## Parámetros
- `fixed_Length`: Número con la longitud a normalizar

## Retorna
Texto con la longitud válida como string.
