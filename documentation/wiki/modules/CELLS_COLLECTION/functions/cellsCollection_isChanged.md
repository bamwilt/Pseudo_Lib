# cellsCollection_isChanged

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Verifica si la longitud de la estructura de celdas ha cambiado respecto a un valor anterior.

## Sintaxis
```
isChanged <- cellsCollection_isChanged(struct_cell, last_length)
```

## Parámetros
- `struct_cell`: Texto con la estructura de celda
- `last_length`: Número con la longitud anterior

## Retorna
Lógico: verdadero si la longitud actual es mayor que la anterior.
