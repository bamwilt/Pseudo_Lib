# cellsCollection_modify_byType

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Modifica un elemento tipado en la posición especificada.

## Sintaxis
```
result_cells <- cellsCollection_modify_byType(struct_cells, element_remplace, index, TYPE)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element_remplace`: Nuevo valor
- `index`: Número con el índice del elemento
- `TYPE`: Texto con el tipo del valor

## Retorna
Texto con la estructura modificada.
