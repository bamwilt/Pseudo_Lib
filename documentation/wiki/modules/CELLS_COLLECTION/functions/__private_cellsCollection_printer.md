# __private_cellsCollection_printer

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Función interna que imprime los datos de la colección elemento por elemento, con opción de salto de línea.

## Sintaxis
```
__private_cellsCollection_printer(struct_cells, isBreakLine)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `isBreakLine`: Lógico que indica salto de línea

## Retorna
Nada. Imprime en consola.
