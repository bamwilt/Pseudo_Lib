# cellsCollection_calcule_indexBlock_atEnd

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Calcula la posición de un bloque desde el final de los datos, utilizando un índice de fin y el tamaño de celda.

## Sintaxis
```
cells_index <- cellsCollection_calcule_indexBlock_atEnd(index_end, index_search, cell_length)
```

## Parámetros
- `index_end`: Número con el índice de fin de datos
- `index_search`: Número con el índice del elemento
- `cell_length`: Número con la longitud de cada celda

## Retorna
Número con la posición absoluta del bloque desde el final.
