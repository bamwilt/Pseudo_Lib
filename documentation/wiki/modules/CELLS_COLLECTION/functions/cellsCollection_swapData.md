# cellsCollection_swapData

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Intercambia dos elementos de la colección por sus índices.

## Sintaxis
```
result_cells <- cellsCollection_swapData(struct_cells, index, index_swap)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `index`: Número con el índice del primer elemento
- `index_swap`: Número con el índice del segundo elemento

## Retorna
Texto con la estructura con los elementos intercambiados.
