# cellsCollection_println

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Imprime el contenido de la colección de celdas en consola, con salto de línea después de cada elemento.

## Sintaxis
```
cellsCollection_println(struct_cells)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas

## Retorna
Nada. Imprime en consola.
