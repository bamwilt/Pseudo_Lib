# cellsCollection_add

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Añade un elemento a la colección de celdas, detectando automáticamente el tipo.

## Sintaxis
```
result_cells <- cellsCollection_add(struct_cells, element)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element`: Elemento a añadir

## Retorna
Texto con la estructura modificada.
