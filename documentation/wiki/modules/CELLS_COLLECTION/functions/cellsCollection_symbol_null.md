# cellsCollection_symbol_null

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Retorna el carácter especial utilizado como símbolo nulo de relleno en las celdas.

## Sintaxis
```
symbol <- cellsCollection_symbol_null
```

## Parámetros
Ninguno.

## Retorna
Texto con el símbolo nulo (0x16).
