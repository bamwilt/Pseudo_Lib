# cellsCollection_getCell_toType

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Obtiene un elemento de la colección y lo convierte al tipo de datos especificado.

## Sintaxis
```
element_type <- cellsCollection_getCell_toType(struct_cells, index, TYPE)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `index`: Número con el índice del elemento
- `TYPE`: Texto con el tipo al que convertir

## Retorna
Valor del elemento convertido al tipo especificado.
