# cellsCollection_clear_cellString

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Limpia los caracteres nulos de relleno al final de un string de celda, retornando solo el dato real.

## Sintaxis
```
result_string <- cellsCollection_clear_cellString(element_string, cell_length)
```

## Parámetros
- `element_string`: Texto con el contenido de la celda
- `cell_length`: Número con la longitud de la celda

## Retorna
Texto sin los caracteres nulos finales.
