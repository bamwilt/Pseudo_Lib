# cellsCollection_add_byString_force

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Añade un elemento string en una posición específica, normalizando el string a la longitud de bloque.

## Sintaxis
```
result_cells <- cellsCollection_add_byString_force(struct_cells, element_string, index_start, index_insert, cell_length)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element_string`: Texto con el valor a añadir
- `index_start`: Número con el índice de inicio de datos
- `index_insert`: Número con la posición de inserción
- `cell_length`: Número con la longitud de celda

## Retorna
Texto con la estructura modificada.
