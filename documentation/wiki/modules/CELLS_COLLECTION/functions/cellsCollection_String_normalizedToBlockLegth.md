# cellsCollection_String_normalizedToBlockLegth

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Normaliza un string a la longitud de bloque especificada, rellenando con el carácter nulo si es necesario.

## Sintaxis
```
element_cells <- cellsCollection_String_normalizedToBlockLegth(element_string, cell_length)
```

## Parámetros
- `element_string`: Texto con el string a normalizar
- `cell_length`: Número con la longitud objetivo

## Retorna
Texto del string ajustado a la longitud de bloque.
