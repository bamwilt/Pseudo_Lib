# cellsCollection_modify_byString

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Modifica un elemento por índice utilizando un string, validando que el índice sea válido.

## Sintaxis
```
result_cells <- cellsCollection_modify_byString(struct_cells, element_string, index)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element_string`: Texto con el nuevo valor
- `index`: Número con el índice del elemento

## Retorna
Texto con la estructura modificada.
