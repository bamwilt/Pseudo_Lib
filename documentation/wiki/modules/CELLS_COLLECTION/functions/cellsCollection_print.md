# cellsCollection_print

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Imprime el contenido de la colección de celdas en consola, sin saltos de línea entre elementos.

## Sintaxis
```
cellsCollection_print(struct_cells)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas

## Retorna
Nada. Imprime en consola.
