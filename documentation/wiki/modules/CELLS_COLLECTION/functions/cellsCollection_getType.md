# cellsCollection_getType

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Obtiene el tipo de datos almacenado en la colección de celdas.

## Sintaxis
```
TYPE <- cellsCollection_getType(struct_cells)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas

## Retorna
Texto con el tipo de datos (int, float, boolean, string).
