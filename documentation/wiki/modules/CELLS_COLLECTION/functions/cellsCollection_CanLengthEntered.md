# cellsCollection_CanLengthEntered

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Verifica si un elemento de una longitud determinada cabe dentro de una celda de la colección.

## Sintaxis
```
canEntered <- cellsCollection_CanLengthEntered(struct_cells, element_length)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element_length`: Número con la longitud del elemento

## Retorna
Lógico: verdadero si el elemento cabe en la celda.
