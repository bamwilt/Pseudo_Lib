# cellsCollection_getSeparateString

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Obtiene todos los datos de la colección como un string separado por el símbolo separador.

## Sintaxis
```
separate_string <- cellsCollection_getSeparateString(struct_cells)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas

## Retorna
Texto con los elementos separados.
