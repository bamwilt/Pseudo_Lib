# cellsCollection_getStartData

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Obtiene el índice absoluto donde comienzan los datos dentro de la estructura de celdas.

## Sintaxis
```
index_startData <- cellsCollection_getStartData(struct_cells)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas

## Retorna
Número con el índice de inicio de datos.
