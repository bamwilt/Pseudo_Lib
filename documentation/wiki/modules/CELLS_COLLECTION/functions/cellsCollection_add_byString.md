# cellsCollection_add_byString

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Añade un elemento string a la colección, validando que no exceda la longitud de celda configurada.

## Sintaxis
```
result_cells <- cellsCollection_add_byString(struct_cells, element_string)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element_string`: Texto con el valor a añadir

## Retorna
Texto con la estructura modificada.
