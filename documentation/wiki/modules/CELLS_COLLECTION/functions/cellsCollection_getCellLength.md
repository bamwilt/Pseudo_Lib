# cellsCollection_getCellLength

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Obtiene la longitud fija de celda configurada en la colección.

## Sintaxis
```
cell_length <- cellsCollection_getCellLength(struct_cells)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas

## Retorna
Número con la longitud de cada celda.
