# cellsCollection_add_byType

**Módulo:** [CELLS_COLLECTION](../CELLS_COLLECTION.md)

## Descripción
Añade un elemento tipado a la colección, convirtiéndolo a string según el tipo especificado.

## Sintaxis
```
result_cells <- cellsCollection_add_byType(struct_cells, element, TYPE)
```

## Parámetros
- `struct_cells`: Texto con la estructura de celdas
- `element`: Elemento a añadir
- `TYPE`: Texto con el tipo del elemento

## Retorna
Texto con la estructura modificada.
