# managerData_getSeparateString

**Módulo:** [MANAGER_DATA](../MANAGER_DATA.md)

## Descripción

Separa los datos secuenciales en un string único delimitado por un separador.

## Sintaxis

```pseudocode
Funcion separated_String <- managerData_getSeparateString(sequential_data, sequential_lengths, separator)
```

## Parámetros

- `sequential_data`: Bloque de datos secuenciales
- `sequential_lengths`: Longitudes de cada elemento
- `separator`: Separador a insertar entre elementos

## Retorna

String con todos los elementos separados por el delimitador.
