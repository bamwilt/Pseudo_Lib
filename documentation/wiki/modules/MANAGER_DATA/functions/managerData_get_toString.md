# managerData_get_toString

**Módulo:** [MANAGER_DATA](../MANAGER_DATA.md)

## Descripción

Obtiene un elemento de datos secuenciales como string por su índice.

## Sintaxis

```pseudocode
Funcion value_string <- managerData_get_toString(sequential_data, sequential_lengths, index_getter)
```

## Parámetros

- `sequential_data`: Bloque de datos secuenciales
- `sequential_lengths`: Longitudes de cada elemento
- `index_getter`: Índice del elemento a obtener

## Retorna

String del elemento en la posición indicada.
