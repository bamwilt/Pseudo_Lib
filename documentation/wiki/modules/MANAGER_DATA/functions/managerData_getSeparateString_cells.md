# managerData_getSeparateString_cells

**Módulo:** [MANAGER_DATA](../MANAGER_DATA.md)

## Descripción

Separa celdas de tamaño fijo en un string, limpiando los caracteres nulos de relleno.

## Sintaxis

```pseudocode
Funcion separated_String <- managerData_getSeparateString_cells(struct_cells, count_size, cell_length)
```

## Parámetros

- `struct_cells`: Bloque de celdas de tamaño fijo
- `count_size`: Número de celdas
- `cell_length`: Longitud de cada celda

## Retorna

String con las celdas separadas.
