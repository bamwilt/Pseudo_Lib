# managerData_printer_color

**Módulo:** [MANAGER_DATA](../MANAGER_DATA.md)

## Descripción

Imprime datos secuenciales aplicando un decorador (ej. color) a cada elemento.

## Sintaxis

```pseudocode
Funcion managerData_printer_color(sequential_data, sequential_lengths, isnewLine, decorator)
```

## Parámetros

- `sequential_data`: Bloque de datos secuenciales
- `sequential_lengths`: Longitudes de cada elemento
- `isnewLine`: Si es verdadero imprime cada elemento en una línea
- `decorator`: String decorador a anteponer a cada elemento

## Retorna

No retorna valor.
