# managerData_printer_cells

**Módulo:** [MANAGER_DATA](../MANAGER_DATA.md)

## Descripción

Imprime celdas de tamaño fijo, limpiando caracteres nulos de relleno.

## Sintaxis

```pseudocode
Funcion managerData_printer_cells(struct_cells, count_size, data_length, isBreakLine)
```

## Parámetros

- `struct_cells`: Bloque de celdas
- `count_size`: Número de celdas
- `data_length`: Longitud de cada celda
- `isBreakLine`: Si es verdadero imprime cada celda en una línea

## Retorna

No retorna valor.
