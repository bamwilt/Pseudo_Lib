# managerData_printer_cells_decorator

**Módulo:** [MANAGER_DATA](../MANAGER_DATA.md)

## Descripción

Imprime celdas de tamaño fijo con un decorador personalizado (ej. color).

## Sintaxis

```pseudocode
Funcion managerData_printer_cells_decorator(struct_cells, count_size, data_length, decorator, isBreakLine)
```

## Parámetros

- `struct_cells`: Bloque de celdas
- `count_size`: Número de celdas
- `data_length`: Longitud de cada celda
- `decorator`: String decorador a anteponer
- `isBreakLine`: Si es verdadero imprime cada celda en una línea

## Retorna

No retorna valor.
